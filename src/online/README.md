# Online transport notes

`src/online` はゲームを知らず、DataChannel上の `Uint8Array` を解釈しません。ゲーム側は次の契約を守ってください。

- `unreliable` はunorderedです。古いスナップショットが後から届くため、ペイロードにゲーム側の連番を入れ、古いものを棄却してください。ロス率もその連番からゲーム側で算出します。DataChannelだけでは有用な `packetsLost` を提供できません。
- `onMessage` に渡す `Uint8Array` は受信した `ArrayBuffer` に被せた短寿命のviewです。コールバックを抜けた後まで保持せず、必要な場合だけゲーム側でコピーしてください。送信側も転送層ではコピーしません。
- キープアライブは専用の `maintenance` チャネルに隔離され、`onMessage` へ転送層のバイトが混ざることはありません。
- `stats()` は毎回同じオブジェクトを返し、値は1秒ごとに上書きされます。参照を前フレーム用に保持すると差分が常に0になるため、必要な数値は呼んだ時点で読み取ってください。未測定のRTTは `-1` です。
- `connected` の5秒後にシグナリングWebSocketを閉じます。それ以降はICE restartや再交渉ができません。切断からの復帰経路もなく、ゲーム側はAIへ戻して終了してください。タブが背面に回った場合の扱いもゲーム側で決めます。
