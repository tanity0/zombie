# スキルアイコンのシート置き場

- ファイル名は **`skills-sheet.png`** 固定(`src/utils/useSkillIconSheet.ts` が読む唯一のパス)。
- 中身は **38個のスキルアイコン**。並び順は `src/data/skillIcons.ts` の `SKILL_ICON_ORDER`
  (社長指定=「左上から右方向へ、1段ずつ下に進む順番」)。
- **段組み(何列×何段か)はコードに書かない。** 画像の実寸から自動判定する(`skillSheetGrid`)。
  1段×38列でも、8列×5段でも、そのまま置けば正しく切り出される。マス目が正方形であることだけが条件。
- **同名で差し替えればOK**。挿絵URLの `?v=` は内容ハッシュなので、`ASSET_VERSION` の手バンプは不要。
- このファイルが無い間は、表示は従来どおり**絵文字**にフォールバックする(壊れない)。
