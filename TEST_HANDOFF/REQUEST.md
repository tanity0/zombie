# テスト依頼: AIディレクターの指標計測(2026-08-15・設計チャット)

## 目的
AIディレクター(L4D2型の緩急管理)の**未定パラメータを裁定できる数字**を取る。
社長指示「aiディレクター用の未定の項目を埋める指標を、n数ある程度信用できる回数ずつ取りたい」。
埋めたいのは `AI_DIRECTOR_HANDOFF.md`「3. まだやっていない」の数値詰め:
Intensity/Performanceの係数・**RELAXの効き**(`RELAX_ESC_MULT/INTERVAL/CAP`)・**BUILDUPの効き**
(`BUILDUP_ESC_BOOST_MAX`)・**既定ON化してよいか**。
※**数字の分析・裁定は設計チャット**。テスト側は実行と記録だけでよい。

## 大前提
- **ヘッドレスは回さない**(社長指示)。**AIの実機テストで回す**。
- **必ず `git pull` してから**。1ラン目で画面左下の版が **v0.25.3482 以降**であることを確認して記録。

## 実行: 3条件 × 各10ラン(計30ラン)
**同じ手順・同じステージ・同じ尺**で、URLのフラグだけを変える。条件は**交互ではなく条件ごとにまとめて**回してよい。

| 条件 | URL | 意味 |
|---|---|---|
| **A(基準)** | `?director=1` | 読むだけ(挙動は基準点と同じ) |
| **B** | `?director=1&directorApply=relax` | RELAX中だけ湧きを緩める |
| **C** | `?director=1&directorApply=all` | RELAX + Performance高でBuildUp強化 |

- **`?director=1` は3条件すべてに付ける**(付けないと計測用の表示・記録が動かない)。
- ステージ・キャラ・初期装備は**3条件で揃える**(揃えた内容を記録に明記)。
- **1ランの尺は「死亡まで、最大10分」**。10分に達したら終了扱いでよい。
- N=10でばらつきが大きすぎる指標があれば、その旨を記録に書く(設計チャットが増やすか判断する)。

## 記録するもの(1ランごと)
1. **リザルト画面の緊張曲線と難易度スコア**(`?director=1` で死亡/クリア時に出る)の**スクリーンショット**。
2. `[BOT_REPORT]` の生JSON全文(いつもの形式)。
3. 左上のディレクター表示から、可能なら**終了時点の値**(state / Intensity / Performance)を1行。
4. **生存時間・到達レベル・総キル・被弾回数**(BOT_REPORTに含まれていればそれでよい)。
5. consoleエラー全文(なければ「0件」)。

## 設計チャットが後で読む指標(テスト側は集計しなくてよい)
- DirectorStateの滞在比率(BUILD_UP/PEAK/RELAX)・**PEAK回数と間隔**・RELAXの平均滞在
- Intensityの平均と**天井張り付き率**・Performanceの平均
- 湧き数/分・画面内の敵数・被弾間隔・生存時間
→ **条件Aとの差**を見て、RELAX/BUILDUPが効いているか、効きすぎていないかを判定する。

## 目安
1ラン最大10分 + 準備。**30ランで3〜5時間**を想定。**分割して構わない**(条件ごとに区切って記録を出す)。
途中でも、**条件Aの10ランが終わった時点で一度記録を出してよい**(基準が先に揃うと分析を始められる)。

## 注意
- **ゲームの数値・仕様は一切変更しない**(フラグの付け外しだけ)。
- 版が混ざらないこと(途中で新しい版が出ても、**1つの条件は同じ版で通す**。版はランごとに記録)。

# 追記: 実機AIテストの全体計画(2026-08-15・設計チャット)

**順番が大事**: ①先に「絵と挙動の確認(短時間)」→ ②その後に「ディレクター計測(長時間)」。
見た目や挙動が壊れていると、②の30ランが丸ごと無駄になるため。

## ① 先にやる: 今日入った変更の確認(1〜2ラン+ボス練習で30〜60分)
**変異体対策室(ボス練習)**を使うと目当てのボスをすぐ出せる。各項目は**スクショ1枚+一言**でよい。

| 見るもの | 何が正しいか |
|---|---|
| **赤い帯・線の予告**(全ボス) | 流星が描かれ→**後ろから消え**→**消え切った瞬間に当たる**。消える前に当たる/消えた後に当たるならズレ。 |
| **城ボスの翼(コウモリの羽)・滑空2撃目** | 同上(直したばかり。**ここが一番怪しい**) |
| **斬撃の弧** | 剣の振りに合った向き(切っ先の円弧)。**出る前に薄く見えない**こと。 |
| **突き技の白い風圧** | 切っ先から手元へ扇。突き出しに合わせて伸びる。 |
| **噛みつき(裏ボス/城ボス)** | 開いたまま震える→**一気にガツン**→**反動で少し浮いてまた閉じる**。 |
| **舞妓の毬回し** | 回しながら**前へ踏み込む**(避けなければ当たる)。横に歩けば避けられる。 |
| **舞妓の手毬打ち/水鳥乱舞** | 手毬打ちは距離・速さ2倍。乱舞の着地円は2倍。中断されたら毬は**落ちて転がって消える**。 |
| **馬乗り** | 突進が3倍速→**直後に360度の鞭薙ぎ**。鞭は**柄を軸に**振られる(真ん中で回らない)。 |
| **バス停** | 撃ち方が3種(3点バースト/扇3発/溜め1発)で緩急がある。**新技=三段突き**(中距離で左→中→右、踏み込みあり)。 |
| **★ハメの確認** | **自動タレットやサブマシンガンLv3をボスに撃ち続ける**。**止まりっぱなしにならない**(揺れるが動く)/**技のエフェクトが固まらない**こと。 |
| **自動タレット** | Lv1=10秒 / Lv2=13秒 / Lv3=15秒。**Lv3だけ時々爆発弾**。 |
| **商人** | 装備に絵と枠アイコン(体🧍/銃🔫/小物🎒)。スキルの説明が「次のLvで何が強くなるか」。 |

**バグを見つけたら**: 版・技名・状況・スクショを記録。**そこで止めて報告**(以降のランが無駄になるため)。
