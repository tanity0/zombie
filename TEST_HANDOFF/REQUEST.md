各ステージを `?smoke&stage=<id>&zoomlock=0.4` で開き、開始地点+30秒ほど歩いた地点で**スクショ各1枚**。
対象: stage-1 / stage-2(★社長報告「ひどい」=重点。屋外ラボ廊下) / stage-3 / stage-4 / stage-5 / stage-7。
見る観点(スクショに写す。判断はしない=絵を残すのが仕事):
1. 上接合(遠景と森の間に真っ黒な帯が無いか)
2. 下接合(床の下端と前景の間に黒帯が無いか)
3. 左右(横パン中に背景が切れないか)
4. アクター可視(周囲の敵が透明・マスク切れになっていないか)
5. M5のみ: 戦場の炎・砲火の照明が見えているか(監査指摘1の修正確認)
6. stage-2のみ: ラボの窓・什器・窓外ゾンビの位置が**ズームを変えても滑らない**か
   (`?zoomlock=0.4` と `?zoomlock=1` の同地点スクショ2枚を比較できる形で)

8. **遠景の伸び**: 各ステージで、遠景(街・空・山)の絵が**縦に引き伸ばされて見えないか**

## D. 技エフェクトの発火確認(FX-V2a/V2b・スクショ各1〜2枚)
- スリィエル: `?smoke&stage=stage-6&gateboss=1` — sweep時に**環が振り抜かれる**か/gaze発射時に**金の視線閃光**が出るか。
- アクラシエル: `?smoke&stage=stage-ex1&gateboss=1` — spike時に**槍が地面から突き上がる**か/burst時に槍の断片が飛ぶか/warpの消失・出現に金フラッシュが出るか。
- グレン: `?smoke&stage=stage-7` — nihil(虚無の三唱)の3唱リングが**唱ごとに濃く・大きく**なるか。
