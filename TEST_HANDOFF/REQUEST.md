- 所要時間の目安: **パートA+B(スイープ)約60分 → パートC(回帰ボットラン)約35分 → 合計約100分**
  +ビルド。放置で回る。途中で落ちたら、落ちた地点までの結果とconsole/スクショを残してくれれば十分。

## ★これは「ではない」(労力をかけなくてよい)
- **バランス・強さ・勝率の評価はしない**(ボットが負けても失敗ではない。記録だけ)。
- **原因調査・コード修正はしない**(判定・分析は設計チャットの仕事)。
- 見た目の美醜の評価は不要(「絵が残る/消える」等の事実だけ)。
- スクショはランナーが撮る最大4枚+任意の気づき1枚まで(掟: 1テスト5枚まで)。

## パートC: 回帰ボットラン(従来どおり1コマンド)
```
node scripts/botrun-local.mjs
```
`request.config.json` は設定済み(stage-1 標準 / stage-5 標準・各15分)。通常ラン全体の回帰
(フリーズ・エラー・死因の妥当性)を見る。

## 記録してほしいこと
1. ★スイープの **`<stamp>-e2e-sweep-raw.json`**(自動生成)と、各シナリオの `summary` 行の転記
   (監視/構え/成立/棄却/無境地系/arrival/departure/エラー数)。
2. ★パートCの **`[BOT_REPORT]` 生JSON**と `deathCause`(2本ぶん)。
3. **consoleエラー全文**(無ければ「0件」)。
4. 60秒以上進まなくなった場面(textTimelineが変化しない等)があれば時刻。
5. 気づき(任意・1〜3行)。**判定はしなくてよい**(「成立が0だった」等の事実だけで十分)。

## 出力先
