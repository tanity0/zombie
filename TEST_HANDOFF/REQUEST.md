# テスト依頼: ボス・ガントレット再走(2026-08-22・設計チャット)

## 目的(これだけを回す)
**全ボス21枠×botの自動戦闘で、バグ・凍結・未接敵を検出する**(research/BOSS_GAUNTLET.md)。
前回の本走(2026-08-19・版3620)は **10/21で中断**しており、そこから**約160版**進んでいる。
その間に入った大物: 幻影v9 / ステージ難度の階段 / EXボス「フィル」一式 / EX舞台の洋館通路化 /
トールの技台本(新技「突進」ほか)。**これらが乗った状態で通しで壊れないかを見るのが今回の主目的。**

**バランス・勝率は目的ではない。** タイムアウトは敗北ではなく「時間内に削れず」の記録なので
気にしなくてよい。※分析・裁定は設計チャット。テスト側は実行と記録だけでよい。

## 大前提
- **必ず `git pull`** し、左下の版が **v0.25.3828 以降**であることを確認して記録。
- **devサーバを使う場合は pull のあとに必ず再起動する**(前回、版ラベルが3620のまま焼かれて
  記録と実物がズレた。今回はラベルと `git log` の版が一致していることを最初に確認して書く)。
- **ヘッドレスは回さない**(headedのローカルChrome)。既存 botrun スクリプトは使わない。
- **コード・数値は一切変更しない。**
- **フレッシュなブラウザプロファイルでよい**(=Lv1初期装備。DPS不足で大半がタイムアウトするが、
  今回の目的はバグ検出なのでそれで良い)。フレッシュなら守護霊も未装備=走行拒否条件に当たらない。

## 回し方
1. `npm run build` → `npx vite preview`(ポートは表示されたもの。devサーバでも可・上の再起動に注意)
2. ローカルChrome(headed)で開く:
   `http://localhost:<port>/zombie/?gauntlet=1&bot=standard&botskill=master`
   ※`botskill=master` は必須。トールの新仕様(紫円の中では近接を振らない)が master/skilled 限定のため。
3. **放置**。21枠を自動で巡回する(1枠=撃破/bot死亡/実時間180秒で次へ)。全部で**最大75分前後**。
   チュートリアル等のポップアップはガントレット側が自動で閉じる(`?autotut=1` は不要)。
4. 完走すると要約表+「コピー」ボタンが出る。

## ★ゲーム開始までの突破(社長指示2026-08-19「いつも開始までのところでつまづく」)
`?gauntlet=1` は本来タイトル/メニューを通らず自動出撃する。**開いてから60秒経ってもボス戦画面に
ならない場合**は、以下を上から順に試して突破する(各操作の前にスクリーンショットを1枚残す):
1. **更新情報(changelog)ポップアップ** → 「OK」
2. **OP/イントロ映像** → 「スキップ」(表示があれば)
3. **タイトル画面** → 「はじめる」
4. **チュートリアル/レベルアップ/宝箱の選択画面** → OK/任意の選択肢を押して閉じる
5. **武器商人の購買画面(showShopMenu)** → READMEの掟どおり false に戻して続行(回数を記録)
- 突破した場合は「どの画面で・何回」を必ず記録する(=駆動の穴として設計チャットが直す)。
- 5分粘っても開始できない場合は、スクリーンショット+console全文+URLを results/ に書いて終了。
- 途中で60秒以上画面が進まなくなった時も同じ(状態を記録して中断してよい。原因調査は設計チャット)。

## ★今回そこだけ見てほしい観測点(6つ)
機械的に見えるものだけでよい。**「面白いか」「難しいか」は見なくてよい**(それは社長が実機で見る)。

1. **クラッシュ・凍結・console エラー。** 1件でも出たら**全文**を残す(枠名と時刻つき)。
   0件なら「0件」と書く。**これが最優先。**
2. **トールの枠(`thor@...`)で、新技が実際に出ているか。** 記録の `movesSeen` に
   **`thor-dash`(突進)** が入っているかを見る。あわせて、
   **紫の円(無の境地)が画面に出ているスクリーンショットを1枚**残す
   (出ていない可能性がある=まさにそれを確かめたい。出ていなければ「出ていない」と書く)。
3. **前回の宿題**: `giantbat@stage-7`(グレン)と `giantbat@stage-ex1` の2枠だけ
   **未接敵(movesSeen ゼロ)でタイムアウト**していた。**今回も同じか、直っているか。**
   ※stage-ex1 は今回フィルに差し替わっている可能性がある。**枠名と実際に出た相手を1行ずつ記録**してほしい。
4. **未出の技**(`未出` の数)。前回は giantbat 系で毎枠15〜20あった。今回の数だけ表に残す。
5. **★トールの突進の「赤い帯」**(v0.25.3828で新規)。走行中に**体の幅ぶんの赤い帯**が
   走る道すじに出るようになった。**その帯が出ているスクリーンショットを1枚**残す。
   見るのは「**出ているか / 出ていないか**」だけでよい(形が正しいかは社長が見る)。
   出ていなければ「出ていない」と1行書く。
6. **★賞金首4枠(バス停/馬乗り/舞妓/もう1種)で、相手が歩いて離れていかないか**(v0.25.3828で新規)。
   賞金首に「**湧いた場所から1200px以上離れたら追跡をやめて巣へ帰る**」が入った。
   計測路でこれが誤爆すると、**戦闘にならないまま180秒タイムアウト**になる。
   - 見るもの: その枠の `movesSeen` が**ゼロか極端に少ない**か / 画面上で
     **賞金首がプレイヤーを無視してゆっくり歩き去る**絵が出ていないか。
   - 起きていたら**枠名と、その時のスクリーンショット**を残す(起きていなければ「起きず」と1行)。
   - ※これは**今回入れたばかりの仕様が計測路で悪さをしないかの確認**。判断は設計チャットがする。

## 記録するもの
1. **完走画面の「コピー」の中身全文**(これが主成果物)+完走画面のスクリーンショット
2. `localStorage['zombie:gauntlet']` の中身全文(毎戦追記される生データ。ブラウザが落ちても残る)
3. console エラー全文(なければ「0件」)
4. 版(左下)+`git log -1` の短ハッシュ・実行環境(OS/ブラウザ/headed)・所要時間
5. 上の観測点2で撮った紫円のスクリーンショット(出ていなければその旨1行)
6. 起動の関門で押したもの(どの画面で・何回)。押していなければ「0回」
7. 観測点5で撮った**トールの突進の赤い帯**のスクリーンショット(出ていなければその旨1行)
8. 観測点6の**賞金首4枠の結果**(起きた枠名+スクリーンショット / 起きていなければ「起きず」)
