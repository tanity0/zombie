# テスト依頼: AIディレクターの指標計測(2026-08-15・設計チャット)

## 目的(これだけを回す)
AIディレクターの**未定パラメータを裁定できる数字**を、**信頼できるN数**で取る。
埋めたいのは `AI_DIRECTOR_HANDOFF.md`「3. まだやっていない」の数値詰め:
Intensity/Performanceの係数・**RELAXの効き**・**BUILDUPの効き**・**既定ON化してよいか**。
**このテストだけを回す**(他の項目の見た目確認は今回の依頼に含めない)。
※**分析・裁定は設計チャット**。テスト側は実行と記録だけでよい。

## 大前提
- **ヘッドレスは回さない。AIの実機テストで回す**(社長指示)。
- **必ず `git pull`** し、1ラン目で画面左下の版が **v0.25.3487 以降**であることを確認して記録。
- **ステージ・キャラ・初期装備・操作方針は全ラン同じ**にする(揃えた内容を最初に1回書く)。
- **1ランの尺は「死亡まで、最大10分」**。10分に達したら終了扱い。

## 回し方(2段階・N数はここが本題)
実機は乱数を固定できないためばらつきが大きい。**条件を3つに割ると1条件あたりのNが薄くなる**ので、
**まず差が一番大きいはずの2条件だけを厚く取る**。

### 第1段(まずこれだけ): **A と C を各15ラン(計30ラン)**
| 条件 | URL |
|---|---|
| **A(基準)** | `?director=1` |
| **C(全部適用)** | `?director=1&directorApply=all` |
- **`?director=1` は両方に付ける**(付けないと計測用の表示・記録が動かない)。
- 条件ごとにまとめて回してよい(A15本 → C15本)。
- **N=15の理由**: 生存時間やキル数のような「ばらつきの大きい指標」でも、
  平均の差が**標準偏差の1割前後**まで見えるようになる。10本だと「差なし」と「見えていないだけ」の
  区別がつかない場面が出る。**15本が実用的な下限**。

### 第2段(第1段でAとCに差が出た時だけ): **B を15ラン**
| 条件 | URL |
|---|---|
| **B(RELAXだけ)** | `?director=1&directorApply=relax` |
- 差の内訳(RELAXの寄与か、BUILDUPの寄与か)を分けるための追加計測。
- **第1段で差が出なければ回さない**(回しても意味が無いため)。

## 記録するもの(1ランごと)
1. **リザルト画面の緊張曲線+難易度スコア**のスクリーンショット(`?director=1` で死亡/クリア時に出る)

5. consoleエラー全文(なければ「0件」)

## 目安と出し方
- 1ラン最大10分 + 準備 → **30ランで3〜5時間**。**分割可**。
- **条件Aの15本が終わった時点で一度記録を出してよい**(基準が揃えば分析を始められる)。

## 注意

- **1つの条件は同じ版で通す**(途中で新しい版が出ても混ぜない)。版はランごとに記録。
