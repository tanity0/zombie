# テスト依頼 #8: 雑魚が居る実戦での守護霊の被弾内訳(10分・v0.25.2555以上)

## 目的
実機で「守護霊が10〜20秒で消える(ボスは生存)」との社長報告。単独ボス戦(依頼#7)では45秒以上
生きたので、**差分=雑魚の存在**が本命仮説(弱い体当たりは仕様上避けない+ヘイトで群がられ、
無敵明けごとに1発=飽和チップ死)。`[GHOSTDMG]`タグで**何に削られているか**を確定させたい。

## 手順
- `git pull`(package.json **0.25.2555以上**)・`npm run dev`・headed Chrome・390×844。
- URL: `http://localhost:5173/zombie/?smoke&ghost=1&stage=stage-1&arenanow=boss&autotut=1&ghostlog=1&bot=standard`
  (**arenanow=boss**=ボス囲いイベントを即発生させる→雑魚湧きのある実戦に近い環境でボス+雑魚の混在戦)
- ゲーム開始→囲いイベントが始まりボスが出たら、守護霊召喚〜死亡まで見届ける×**2ラン**。
  (守護霊が召喚されない場合: 囲いのボスに900px以内へ近づく。それでも出なければその旨を記録して終了)
- 依頼#7のHPサンプラー(1秒毎の[GHOST]ログ)も併用推奨。
## 記録してほしいもの
- **`[GHOSTDMG]`全行**+タグ別集計(contact:雑魚型 / contact:ボス型 / blast / proj / capsule / untagged)
- 守護霊の生存秒数(2ラン)
- 目視メモ: 守護霊の周りに雑魚が群がっていたか(スクショ1枚以上)
- consoleエラー全文(なければ0件)
- 結果: `results/<YYYYMMDD-HHMM>-ghostdmg-mobs.md`(+.json)。判断はしない(分析は設計チャット)。
