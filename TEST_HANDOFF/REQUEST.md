# テスト依頼: §7-11裁定用のベースライン指標(2026-08-14・設計チャット)

## 目的
バランス再設計(PACING_PUZZLE.md §7-11 裁定パッケージ)の裁定材料として、**現状ゲームの
ベースライン指標**を実機で取る。取りたい数字:
1. **1ランの総キル数**(裁定6: 敵スクラップ率の逆算アンカー/裁定2: XP経済の換算)
2. **到達レベルとレベルアップ回数**(裁定2)
3. **到達ランク(AIディレクターdanger rank)の推移**(裁定4)
4. **生存時間**
5. BOT_REPORTに含まれていれば: スクラップ収支・ドロップ内訳(裁定5・6)
※数字の分析・裁定材料化は設計チャットがやる。テストチャットは実行と記録だけでよい。

## 実行
- いつも通り `node scripts/botrun-local.mjs`(request.config.jsonは更新済み: baseline-1〜3の3ラン)。
- ステージはスクリプト仕様で **stage-1固定**(それでよい。ステージ差は設計チャット側で別途扱う)。
- 各ラン15分cap(runMs=900000)。**目安: ビルド+3ランで30〜50分**。
- ショップ画面が開いたら閉じて続行(README掟どおり・回数を1行記録)。

## 記録(results/ へ・いつもの形式)
- 各ランの `[BOT_REPORT]` 生JSON全文(これが本体)
- consoleエラー全文(なければ「0件」)
- 実行環境(headed/headless・OS)・ショップが開いた回数・気づき(任意)
