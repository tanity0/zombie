# テスト依頼: 接触ダメージ全面置換(噛みつき)+カウンター改定の実機確認(2026-08-25・設計チャット)

## 目的(これだけを見る)
**今日1日で戦闘の土台が大きく入れ替わった。それが「壊れていないか」だけを見る。**
- **接触ダメージが全面的に「噛みつき」へ置き換わった**(通常敵・エリート雑魚・ボス・賞金首)。
- **カウンターの成立時間が変わった**(振り抜きの後半だけ)。
- **噛みつきはカウンター不可(紫)**。

**知りたいのはただ2つ。**
1. **敵がちゃんと攻撃してくるか**(=無害化していないか)。
2. **止まる/固まる/エラーが出ないか**。

## ★これは「ではない」(労力をかけなくてよい)
- **バランス・勝率・DPS・タイムアウトは対象外。** 負けても時間切れでも構わない。
- **見た目の良し悪しの評価は不要。**「出ているか/出ていないか」だけ書けばよい。
- **原因の調査・コード修正はしない**(テストチャットの掟どおり。分析は設計チャット)。
- スクリーンショットの枚数を稼がなくてよい。**下の観察点に該当する場面だけ**でよい。

## 大前提
- **必ず `git pull`**。左下の版が **v0.25.3928 以降**であることを確認して記録する。
- **devサーバを使う場合は pull のあとに必ず再起動**(版ラベルが古いまま焼ける事故の前例あり)。
- **コード・数値は一切変更しない。**

## A. 通常ラン(まずこちら・約20分)
`node scripts/botrun-local.mjs` の既定運用でよい。**3ラン**回す。

- ステージ1(狂い咲きの森)× 2ラン
- ステージ2 × 1ラン(**索敵範囲を 200→180 に縮めた**ので、見つかり方が変わっていないかを見る)

### 記録してほしいこと(Aの必須項目)
1. 各ランの **`[BOT_REPORT]` 生JSON全文**。
2. ★**`damageTaken` の値**。**3ランとも 0 なら重大**(敵が無害化している)。0でなければOK。
3. ★**`deathCause`**。死んだ場合、死因に **「噛みつき」** が現れるか。
4. **consoleエラー全文**(無ければ「0件」と明記)。
5. **60秒以上ゲームが進まなくなった場面**があれば、その時刻とスクリーンショット。
