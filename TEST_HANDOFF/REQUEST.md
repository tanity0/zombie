# テスト依頼: ボス・ガントレット実機ラン(2026-08-19・設計チャット)

## 目的(これだけを回す)
**全ボス21枠×botの自動戦闘でバグを検出する**(research/BOSS_GAUNTLET.md のガントレット。
v0.25.3605で実装済み)。**バランス・勝率は目的ではない**。タイムアウトは敗北ではなく
「時間内に削れず」の記録なので気にしなくてよい。
※分析・裁定は設計チャット。テスト側は実行と記録だけでよい。

## 大前提
- **必ず `git pull`** し、左下の版が **v0.25.3612 以降**であることを確認して記録。
- **ヘッドレスは回さない**(headedのローカルChrome。既存 botrun スクリプトは使わない=下の手順で開くだけ)。
- **コード・数値は一切変更しない**。
- **フレッシュなブラウザプロファイルでよい**(=Lv1初期装備。DPS不足で大半がタイムアウトするが、
  このランの目的はバグ検出なのでそれで良い。装備データ前提の勝敗は社長の実データランで別途見る)。
  フレッシュなら守護霊も未装備=ガントレットの走行拒否条件に当たらない。

## 回し方
1. `npm run build` → `npx vite preview`(ポートは表示されたもの。※devサーバでも可)
2. ローカルChrome(headed)で開く:
   `http://localhost:<port>/zombie/?gauntlet=1&bot=standard&botskill=master`
3. **放置**。21枠を自動で巡回する(1枠=撃破/bot死亡/実時間180秒で次へ)。
   全部で**最大75分前後**。チュートリアル等のポップアップはガントレット側が自動で閉じる
   (`?autotut=1` は不要)。

## ★ゲーム開始までの突破(社長指示2026-08-19「いつも開始までのところでつまづく」)
`?gauntlet=1` は本来**タイトル/メニューを通らず自動出撃**する。ただし過去のテストランでは
OP・メニュー・更新情報ポップアップ・チュートリアルで固まる事故が繰り返し起きているので、
**開いてから60秒経ってもボス戦画面(方眼ではなく実ステージ・左下に版番号+敵)にならない場合**は、
以下を上から順に試して突破する(各操作の前にスクリーンショットを1枚残す):
1. **更新情報(changelog)ポップアップ** → 「OK」を押す
2. **OP/イントロ映像** → 「スキップ」ボタンを押す(表示があれば)
3. **タイトル画面** → 「はじめる」を押す(ガントレットが有効ならこの後自動で出撃するはず)
4. **チュートリアル/レベルアップ/宝箱の選択画面** → OK/任意の選択肢を押して閉じる
5. **武器商人の購買画面(showShopMenu)** → READMEの掟どおり
   `useGameStore.setState({showShopMenu:false})` 相当で閉じて続行(回数を記録)
- 上記で突破した場合は「どの画面で・何回」を結果に必ず記録する(=駆動の穴として設計チャットが直す)。
- 5分粘っても開始できない場合は、スクリーンショット+console全文+URLを results/ に書いて終了
  (原因調査は設計チャットの仕事)。
4. もし**60秒以上画面が進まない**ように見えたら: スクリーンショットを撮り、
   `showShopMenu`(商人画面)が開いていないかを確認(開いていたら READMEの掟どおり
   falseに戻して続行し、回数を記録)。それでも進まなければその時点の状態を記録して中断してよい
   (原因調査は設計チャット)。
5. 完走すると要約表+「コピー」ボタンが出る。

## 記録するもの
1. **完走画面の「コピー」の中身全文**(これが主成果物)+完走画面のスクリーンショット
2. `localStorage['zombie:gauntlet']` の中身全文(毎戦追記されている生データ。
   ブラウザが落ちた場合もこれが残っているので必ず取る)
3. consoleエラー全文(なければ「0件」)
4. 版(左下)・実行環境(OS/ブラウザ/headed)・所要時間
5. 途中で気づいた見た目の異常(あれば時刻とスクリーンショット。「どのボスの何の技か」を1行添える)
- 出力先: `results/<YYYYMMDD-HHMM>-gauntlet.md`(要約)+同名 `.json`(コピー/localStorageの生データ)

## 注意
- ブラウザが落ちた/タブを閉じてしまった場合: `zombie:gauntlet` の中身を取って記録すれば
  そこまでの分は使える。再走は同じURLを開き直すだけ(最初の枠からやり直しになるが問題ない)。
- 進行不能などの明らかな不具合が出たら、そのランを記録して報告し指示待ち(自分で直さない)。
