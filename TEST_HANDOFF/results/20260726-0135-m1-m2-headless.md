# M1/M2 ヘッドレス実走テスト(v0.25.2249 時点)【2026-07-26 01:35 JST】

社長指示「ここまででm1とm2で実機テスト回しといて」に対する結果。設計チャット(Fable)がリモート
コンテナ上で実施。**通常のテストチャット運用(ローカルChrome + `botrun-local.mjs`)ではない**ので、
下の「実行環境と制約」を必ず読んでから数字を解釈すること。

## 実行環境と制約(重要)
- 環境: リモートLinuxコンテナ / Chromium 1194(headless) / GPUなし=**swiftshader(ソフトウェアGL)**。
- **PixiJSはこの環境では実速×0.031しか出ない**(実測)。ゲーム内8分ぶんに約4時間かかるため、
  長時間の実走には使えない。計測値:

  | 構成 | 実時間比 | 8分ぶんに必要な実時間 |
  |---|---|---|
  | pixi 1280×800 | ×0.031 | 256分 |
  | pixi 360×640 | ×0.155 | 52分 |
  | **canvas 1280×800** | **×0.949** | **8分** |
  | canvas 360×640 | ×1.000 | 8分 |

- よって**長時間の実走は `?renderer=canvas` で実施**した。`useGameLoop`/store のシミュレーションは
  レンダラに依らず完全に同一(CLAUDE.md「PixiJS only draws」)なので、**湧き・イベント・ピックアップ等の
  ロジック検証としては有効**。ただし**PixiJSの描画品質・描画負荷は検証していない**(別枠で起動スモークのみ)。
- ボットは `?smoke=1&bot=standard`。dev サーバ(`npm run dev`)の `__gameStore` を page.evaluate で直読み。
- **実機(社長のスマホ)での確認の代わりにはならない**。特にFPS・見た目・タッチ操作は未検証。

### 湧き量の切り替え検証(v0.25.2248「ゴールと反対方向は3/3」)
ボットは意図的に逆走しないため、`__gameStore` でプレイヤーを固定位置に留め、同じゲーム内時間あたりの
新規湧き数を左右で比較した。

- **試行1(失敗・参考)**: 敵をそのままにして90秒ずつ計測 → ゴール側2体 / 逆側1体。
  **区画上限(`LAB_ENEMIES_PER_ZONE`=2)と画面上限に当たって棄却される領域**を測ってしまい、
  湧き"間隔"の差が出ない。この測り方は無効。
- **試行2(有効)**: 湧いた敵を即座に取り除いて上限に当たらない状態にし、120秒ずつ計測。

  | 条件 | 新規湧き | 換算 |
  |---|---|---|
  | ゴール側(間引きあり=2/3) | 26体 / 120秒 | 13.0/分 |
  | 逆側(間引きなし=3/3) | 39体 / 120秒 | 19.5/分 |
  | **比** | | **×1.50** |

  理論値 `LAB_SPAWN_INTERVAL_MULT(2.4) / LAB_SPAWN_INTERVAL_MULT_AWAY(1.6) = 1.5` と**完全一致**。
  → v0.25.2248は設計どおり動作している。

## 気づき(判断は社長/設計チャット)
1. **【テスト手法の限界】M2ではボットが機能しない。** 実走で**開始40秒(x=-1189)からラスト7分間、
   プレイヤーが完全停止**した(移動0・キル0・HP変化0)。当たり判定を静的に検証したところ、
   その地点でプレイヤー矩形(28×28)は壁にめり込んでおらず、左にも上にも移動可能だった。
   → **ゲーム側の詰まりではなく、ボットAIがM2で目標(ゴール)を持たず、敵6体が全員休眠で追う相手も
   いないため停止した**もの。**M2のヘッドレス自動テストは「湧き・システムの検証」には使えるが、
   「プレイ可能性・バランス」の検証には使えない**。M2のバランスを自動で測りたいなら、
   ボットに「ゴール方向へ進む」行動を足す必要がある(未実施・要判断)。
2. **【要観察】M2の湧きが薄い。** 8分で新規6体(固定ガード3体を除く)。湧きの条件が
   v0.25.2243(2/3)+v0.25.2244(通った道に湧かない)+v0.25.2245(他の敵の視界に湧かない)と
   3つ重なっているため。ただし**上のとおりボットが7分間停止していたラン**なので、
   「動かない=通った道が伸びない=湧く場所はあったのに湧かなかった」という測り方の歪みも含む。
   実機で社長が普通に前進した時の体感が本番の判断材料。薄すぎる場合は
   `LAB_SPAWN_INTERVAL_MULT`(2.4)を戻すのが一番影響を読みやすい。
3. **【未検証】** M2のクリア(書類取得)導線・PHILL弾を実際に拾えるか・叫喚型以外のイベント・
   実機FPS。いずれもボットが動かないため自動では取れていない。
