依頼の指示どおり「召喚されない場合はボスへ近づく」も実施(2ランとも実行)しましたが、変化なし。

### 原因(コードで確定)
`arenanow=boss` の囲いボスは **`pumpkin`**。一方、守護霊の召喚ゲートが見る
`ENGAGEABLE_BOSS_TYPES`(`src/utils/bossEngagement.ts:24`)は:
```
giantbat / mimir, jormungand, skadi, thor / miguel, jibril, rafi, uri, suriel, acrasiel / idol
```
**`pumpkin` は含まれていません。** よって囲いイベントのボス戦では、**仕様上そもそも守護霊が出ません**。
→ 「雑魚混在の実戦」を `arenanow=boss` で作る方法は成立しない、が結論です。
