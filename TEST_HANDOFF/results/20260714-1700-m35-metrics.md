### 今回の障害(設計チャットへの申し送り・最優先)
**`scripts/botrun-local.mjs` はWindowsで preview サーバを起動できず異常終了します(v0.25.1721)。**
- 前回報告した `fileURLToPath` 修正は**効いています**。`npm run build` も成功(33.13秒・dist生成OK)。
- 落ちるのは次の行(`scripts/botrun-local.mjs:26`):
  ```js
  server = spawn('npx', ['vite', 'preview', '--port', '4173', '--strictPort'], { cwd: root, stdio: 'ignore' });
  ```
  Windowsでは `npx` の実体が `npx.cmd` のため **`Error: spawn npx ENOENT` (errno -4058)** となり、
  `error` イベント未処理でプロセスごと落ちます(`[setup] previewサーバが起動しない` にも到達しない)。
- 想定される直し方(判断は設計チャット): `spawn('npx', args, { shell: true })` にする、または
  `process.platform === 'win32' ? 'npx.cmd' : 'npx'` を使う。あわせて `server.on('error', …)` を
  付けておくと、次に別の理由で起動失敗しても診断できます。
- **回避策として、今回は同ロジックの一時ランナーでローカルdevサーバ(5173)に対して実走しました。**
  ゲームコードは pull 済みHEAD(v0.25.1721)そのものです。
