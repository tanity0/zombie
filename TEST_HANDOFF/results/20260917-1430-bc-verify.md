## 2. ★C(seed)= **口は効いている。ただし同じseedでも湧きは一致しない**

### 効いていること
- `?seed=12345` が Bridge の `read().seed` に**そのまま返ってくる**(2本とも `effective=12345`)。
- Manifest に `requested` / `effective` が記録される。

### 一致しないこと(事実)
**同じ `seed=12345` で2本回したが、敵の湧きは1体目から違う。**

| | 1本目 | 2本目 |
|---|---|---|
| `enemySpawn` 件数 | **56** | **66** |
| 先頭12体の型 | `skeleton,skeleton,zombie,bat,bat,bat,bat,skeleton,bat,skeleton,skeleton,bat` | `bat,skeleton,bat,bat,bat,bat,skeleton,zombie,skeleton,bat,bat,bat` |
| 最初の食い違い | **0件目**(`skeleton` vs `bat`) | |

湧きの**時刻**にも差が出ている。
```
1本目: 549.9 / 2032.9 / 4034.4 / 5834.2 / 6367.8 / 8068.6 / 10118.3 / 11101.6
2本目: 566.1 / 2016.8 / 4034.3 / 4667.2 / 6051.2 / 8068.0 / 8914.8 / 10100.2
```
**前半の時刻はほぼ揃っている**(549.9/566.1、2032.9/2016.8、4034.4/4034.3、8068.6/8068.0)のに、
**7件目あたりから値が小数まで不揃いになる**(`8914.804100133864` / `10100.292499248462`)。
=「時計は同じ刻みで進んでいるが、どこかで別系統の乱数が混ざる」形に見える。
**ただしこれは観測された数字であって、原因の切り分けはしていない。**

参考(発注文Cへの回答としてコード側に書かれていた事実):
> 他の乱数系(敵のAI・ドロップ等)はまだ `Math.random()` 直呼びのまま(`testBridge.ts` の `seed` コメント)

コミット `e4788d92` の題も「**湧きだけ先に**」なので、**Cは部分着地**。
再現性が要る用途(広告A/B・版比較)に使えるかは設計チャットの判断。
