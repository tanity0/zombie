## 1. B1 区画の境界と名前(跨いだ瞬間だけ)

★v0.25.5070 で実装着地、v0.25.5071 で検収監査(品質・クリエイティブ)の指摘を反映。以下は**出荷した実態**(設計時の叩き台から変わった点は「変更」と明記)。

### 1-1. 前
区域(距離の輪: 軍備配置区域 / 研究対象区域 / デンジャーゾーン / 未確認汚染エリア / 深層域・`AREA_THRESHOLDS`)を跨いだ時、
HUDの小さなイベント帯(`eventBannerText`)に名前が出るだけだった。境界がどこにあるかは画面に無かった。

### 1-2. 仕様(実装どおり)
1. **引き金**: 既存の区域跨ぎの判定(useGameLoop・`detectWallBreach`・ゲートで塞がれていれば保留)はそのまま。
   区域跨ぎでは `eventBannerText` を**使わず**(事実: 区域の分岐だけ置き換えた。ウェルカム等の他の帯は不変)、
   `areaCrossFx = { at, zoneIdx, deeper, radius, angle, arc, banner, lead }` を store に書く(`areaCrossFxAt()`・useGameLoop)。
   - **ゲートで塞がれた跨ぎ**は従来どおり保留し、**ゲート1/2クリア時に帯を出す**(品質監査(A): 保留のまま告知が消えていた穴を塞いだ)。
     その時プレイヤーは輪の上に居ないので弧は描かない。
   - **弧(arc)はプレイヤーが跨いだ輪から 420px 以内に居る時だけ**(ファストトラベル・ゲートクリアの遅延告知では帯だけ)。
   - **再生中に次の跨ぎが来たら上書き**(新しい方で描き直す。重ねない)。
2. **境界線(世界座標・`groundLayer`=足の下)**: 跨いだ輪(半径 `radius`・原点中心)の弧を、跨いだ点から**左右へ伸ばして**画面の外まで描く(`syncAreaCrossLine`)。
   - **地面の線なので足の下**(血溜まり・影と同じ層の最上段。出る瞬間に上げ直す)。v0.25.5070 は effectLayer=人物の上を線が通っていた(検収クリエイティブ監査)。
   - 入り 350ms(ease-out・出足が最速)→ 反対側の遅れ 120ms → 保持 450ms → 消え 500ms(端から中央へ吸い込まれ、同時に薄れる)。全長 **約1.4秒**。
   - **進行方向側(lead)が先に走り切り、反対側は 120ms 遅れて追う**(入りの間、画面の中で先と後が見える。v0.25.5070 の「0.85倍・60ms」は画面の外でしか差が無かった)。
   - **跨いだ点が主役**: 中央 160px は 3px、外へ行くほど薄い(端は 0.4 倍)。線は画面 2px(ズームで割る)。走っている間だけ先端 70px を明るく太く(先に走る側が明るい)。
   - 色: **琥珀1色** `#ffb340`(`--menu-accent`・メニューの差し色と同じ=家の色を増やさない。**変更**: 叩き台の真鍮 0xc9a46a から)。
     浅い側へ戻る時は**強さだけ落とす**(0.5)。**変更**: v0.25.5070 は白。方向を色相で符号化してもプレイヤーが学ぶ機会が無い(検収クリエイティブ監査)。赤・紫は使わない。
   - **地平線フェード(`horizonActorAlpha`)を弧にも掛ける**(24分割で区間ごとに alpha)。1本で描くと奥の tilt-shift の強ボケ帯で線が
     太いボケの帯になり森の上まで突き抜けた(ヘッドレス実測)。世界の他の物と同じ法則で奥へ消える。
   - 弧の角度幅は可視域の対角線(÷ズーム)から求める=`?zoomlock=0.4` でも画面を横切る。`?hidelayer=areacross` で消せる。
3. **区画名(HUD・DOM・`AreaCrossBanner`)**: **銘打ち(WallInscription)と同じ題字の運動・同じ数字**で名前**だけ**を出す(題字の出方を家で1つにする。
   **変更**: 叩き台の「36%・画面幅いっぱいの帯・上下線」から。クリエイティブ監査「家に既にある題字の作法を使え」)。
   - 名前(Georgia/明朝 26px・字間 0.34em→0.14em・開始 350ms・600ms)。全長 **2.0秒**(消え 800ms ease-in)=銘打ちと違うのは全長だけ。
     世界の弧が走り切る 350ms に名前が出て、弧が消えた後に名前だけ一拍残る(順序に意味を持たせる)。
   - **横罫と小さな英字は出さない**(**変更**: v0.25.5070 は罫 220px+ENTERING。罫は世界の弧と十字の照準になり、ENTERING は家の口調(TRESPASS 等の名詞)から外れ、
     ゲートクリアの遅延告知では事実と違った=検収クリエイティブ監査)。
   - 場所は **高さ 42%**(自機=約56% の上)。**変更**: v0.25.5070 は銘打ちと同じ 58% で、跨ぐたびに自機が文字で隠れた(検収品質監査 A-3)。銘打ちは初回だけの儀式なので 58% のまま。
   - **深い側・浅い側とも名前を出す**(**変更**: v0.25.5070 は深い側だけ。社長の言葉に方向の区別は無く、旧い帯も両方向だった=検収品質監査 A-2)。
   - **初回踏破(銘打ちが4秒出る回)は名前を譲る**(`banner=false`・弧だけ)。
   - **同じ輪を 8秒以内に再び跨いだ時も名前は出さない**(弧だけ・`AREA_CROSS_REBANNER_MS`)。境界沿いの戦い(拠点は輪のすぐ外)で題字が何度も出直すのを止める。
     SE の「1ランに1区域1回」と揃えた(検収クリエイティブ監査)。判定・年表・SE は従来どおり。
   - 購読は `areaCrossFx` だけ(毎フレームの再レンダ無し)。アニメは開いた時刻から数えた負の delay(レンダが遅れても消える時刻が揃う)。
4. **SE**: 既存の区域遷移音(深い側へ移動した時だけ鳴る)はそのまま。新しい音は足していない。
5. **出さない所**: 研究所(S2)・洋館の通路(S6)・訓練(M0)・EX は輪が無い/固定なので従来どおり何も出ない。
6. **負荷**: 1/10(約1.4秒だけ Graphics 最大26本/フレーム+DOM 1枚)。
7. **★社長判断(検収クリエイティブ監査 #9)**: 境界の手前 150px で出る既存の白い帯「この先 — ◯◯」(2.8秒・画面上部)と、跨いだ時の琥珀の名前(42%)で
   **同じ名前が上と中央に2回出る**。推薦=予告の帯は名前無しの罫だけにし、名前は到着(本件)に持たせる(「この先」は既存のエフェクトなので指示なく変えない)。

### 1-3. 受け入れ条件(実装で確認した物)
- 区域を跨いだ瞬間に弧と名前が出て、弧は約1.4秒・名前は2.0秒で消える。跨がなければ何も出ない。(ヘッドレス撮影 b1v2-230/700.png)
- 浅い側へ戻った時は薄い琥珀の線+名前。深い側は濃い琥珀+名前。名前は自機に被らない(42%)。
- 同じ輪を8秒以内に行き来しても名前は出直さない(線だけ)。
- `?zoomlock=0.4` でも弧が画面を横切る(角度幅を可視域から計算)。
- 既存のイベント帯(ウェルカム等)は従来どおり出る。
- ゲートで塞がれた跨ぎはクリア時に名前が出る。

## 2. B2 一時停止メニューの地図

★v0.25.5070 で実装着地(`PauseMap.tsx`・`PauseMenu.tsx` の `readPauseMap`)、v0.25.5071 で検収監査の指摘を反映。

### 2-1. 仕様(実装どおり)
1. **置き場**: 一時停止の右列(戦況)の**一番上**、「経過時間」の上。**見出しは付けない**(地図の中のタグが見出しを兼ねる。作戦室と同じ。
   **変更**: v0.25.5070 は「地図」の見出し付き=二重見出し・検収クリエイティブ監査)。開いた時の1回読み(スナップショット)で canvas に1度だけ描く。
2. **大きさ**: 高さ `clamp(110px, 18vh, 240px)` の正方形(左寄せ・バッキング 300px)。**変更**: v0.25.5070 は右列いっぱい(430×932 で 209px)。
   小さい端末(375×667)で右列が溢れて説明がスクロールしないと読めなくなっていた(検収品質監査 A-1)。`.ds-map` の箱(作戦室と同じ枠。
   DS トークン `--ds-*` は `.ds-home` にしか無いので、`PauseMap` がメニューの色へ読み替えて与える=v0.25.5070 は枠も地も無効だった・検収クリエイティブ監査)。
   **一時停止の中身は上下中央寄せなので、右列が高くなる分だけ左列(続ける/メニューに戻る)が上へ動く**(430×932 で約 −90px)。
   これは地図を足す以上避けられない(避けるなら右列を固定高にして地図ぶんスクロール=戦況が読めなくなる方が悪い)。意図した変化として記録。
3. **凡例は作戦室の等高線地図(`DsContourMap`)の家族**(**変更**: 叩き台の「真鍮の点+白の点」から。クリエイティブ監査「地図の記号を家で2系統にしない」。
   v0.25.5071 で**形で分ける**ように直した=v0.25.5070 は菱形3種が色相だけの差で 6px では区別できなかった・検収クリエイティブ監査 #14):
   - 区域の輪 4本(`activeAreaThresholds()`・琥珀の点描 0.32・**今居る帯の両側の輪は 0.6 で明るく、帯の中をごく薄く塗る**)。
     縮尺は「描く物(自分・拠点・寄り道・宿敵)の一番遠い物を含む次の輪」が収まるまで(最低2本目の輪)。外の輪は縁に欠けた弧として残る
     (**変更**: v0.25.5070 は一番外の輪固定=箱の6割が空だった)。
   - 区画の線 4本(`POI_SECTORS` の境=45°の斜め・薄い点描 0.22)。
   - 拠点=**四角**(場所): 未解放=琥珀の枠 / 解放済み=白の塗り。
   - 自分=白い角(5px)+白枠 13px(一番大きい)。向きは**枠の一辺に付く小さな三角**(線ではなく形)。
   - 発見済み(`isPoiRevealed`)の寄り道(武器庫・警察・病院・裏ボスの巣)=**琥珀明の点**。未発見は出さない(探す楽しみを殺さない)。
   - 宿敵(`isNamed`・死体は除く)=**琥珀の菱形**(作戦室の「脅威」と同じ形)。
   - 文字は**今居る区域の名だけ**(`ds-map-tag`「**DEPTH** — ◯◯」。**変更**: v0.25.5070 は「SECTOR — ◯◯」だったが、SECTOR は作戦室で
     出撃先の場所名に使っている語=一語一義にする)。輪ごとの名は書かない(地図を汚す)。
   - ★記号の割付(どれを脅威・目標とするか)は意匠=社長が実機で見て変えてよい。
   - **軍人は出さない**(**変更**: 叩き台では白の小さな点。監査「10人超の点が地図の読みを壊す。軍人は画面に見えているので地図に要らない」)。
   - 画面の矩形(今見えている範囲)は出さない。
4. **出さない所**: 地図を描くのは `stage-1 / stage-3 / stage-4 / stage-5` だけ(`PAUSE_MAP_STAGES`)。研究所(S2)・洋館の通路(S6・corridorMode)・
   訓練(M0)・EX・ステージ7は描かない。**練習枠(`isPracticeRun`)・計測路(`isGauntletRun`)・ボスメーカー(`bossMaker.active`)も描かない**
   (練習枠は `getSelectedStageId()` が枠の stageId を返すので別に見る=検収品質監査 C-3)。
5. **キーボード/パッドの操作**: 地図は見るだけ(menuNav の候補に入れない)。
6. **負荷**: 0/10(開いた時に canvas 1回)。

### 2-2. 受け入れ条件(実装で確認した物)
- 一時停止を開くと地図が出て、自分・拠点・区域の輪・今居る区域名が読める(ヘッドレス撮影 b2v2-pause-430/375.png)。閉じて開くと更新されている。

## 3. B10 血の覚醒(A+B+液体の色)

★設計の監査(品質+クリエイティブ・fable・2026-10-16)を反映した**第2版**。(A)/(C)は直し、意匠・仕様に触れる物は §6 の社長判断へ。**実装は §6 の裁定後**。

### 3-1. 状態(store・`utils/bloodAwaken.ts` の純関数で計算)
- `player.bloodMeter: 0..1`(血の量)/ `player.bloodAwakenUntil`(覚醒の終わり・**gameTime**)/ `player.bloodAwakenStartedAt` / `player.bloodLastGainAt` / `player.bloodFullSince`。
  - **守護霊の擬似プレイヤーには持ち越さない**: `ghostBuild.ts` の記録時に `bloodMeter/bloodAwaken*` を落とす(`...build.player` で丸写しされるため。落とさないと覚醒中に計測したビルドの守護霊が永久に×1.5になる)。
  - **初期化**: `resetGame`(ステージ跨ぎ・リトライ)で全部 0/未定義。覚醒中に死亡→リトライで残らない(受け入れ条件)。
- **溜まり方**(浴びる=自分の手で近くで倒す。**加算は呼び手が旗を立てて渡す**=関数の中では分身/守護霊を見分けられないため):
  | 経路(関数) | 旗 `bloodSplash` | 量 |
  |---|---|---|
  | カウンター(ナイフ・`triggerCounter`→`grantMeleeKillRewards`) | 浴びる | キル: 距離≤120px +0.12 / それ以上 +0.06。ヒットのみ +0.02 |
  | 刀の一閃(本人・`ghostId` 無し) | 浴びる | 同上 |
  | 鞭 | 浴びる | 同上 |
  | 縮地(ワープ斬撃) | 浴びる | 同上 |
  | 処刑(近接フィニッシュ `applyMeleeFinisher` 系) | 浴びる | +0.12(密着が前提) |
  | 被弾反撃(`tryHitRetaliation` の踏み込み斬り) | 浴びる | 同上(キル/ヒット) |
  | 分身(`shadow clone`・同じ player を渡す経路) | **浴びない** | 0 |
  | 投擲スケボー・シールドバッシュ・アンカー | **浴びない**(道具が当たる) | 0 |
  | 守護霊の刀(`ghostId` 有り) | **浴びない** | 0 |
  | 銃(`damageEnemy` の `damageChannel==='gun'`・サブウェポンの弾は 'other' なので入らない) | キルだけ | 距離≤90px +0.06(血飛沫が届く距離だけ)。遠距離 0 |
  | 爆発・DoT・地雷・犬・召喚・守護霊(`damageChannel` 'other'/'dot'・`hateSource` 'ghost'/'dog') | 浴びない | 0 |
  - 距離=プレイヤー中心と敵中心(`enemyMeleeDist` ではなく中心同士。血飛沫の出どころと同じ)。
  - **乾き**: 最後に浴びてから 4秒後から −0.01/秒。覚醒中は乾かない。満ちている間は 30秒まで乾かない(以後は乾く)。
    ※「見えない内部ルールが多い」(クリエイティブ B10-10)は §6 の社長判断(減らすか・絵で見せるか)。
- **満ちた時(1.0)**: 自動では発動しない(B)。溢れた分は捨てる。
- **「血を拭う」(発動の操作)**: **体力のオーブを長押し 0.5秒**(スマホ=指・PC=マウス。PC のキーは §6)。
  - **配線の事実**: GameHUD の根は `pointer-events-none`。**オーブ(`VitalsOrb`)の箱だけ `pointer-events-auto`** にし、要素の `onPointerDown/Up/Cancel` で取る
    (VirtualJoystick/MouseControls も要素レベルなので下へ抜けない=撃つ/照準と衝突しない)。
  - **長押し中の絵は「拭う」=液面の深紅が上から引いていく**(クリエイティブ B10-6: 満ちる輪は EXP リングと同じ場所に2つ目のリングになり、動詞と逆)。
    0.5秒で拭い切ると発動。途中で離せば**粘って戻る**(VitalsOrb の指数追従と同じ曲線)。満ちていない時に押しても何も起きない。
  - **長押し中に被弾しても長押しは続く**(指が離れない限り。被弾で途切れると戦闘中に発動できない)。
  - 位置(左上のオーブを戦闘中に 0.5秒押せるか)は §6 の社長判断(代案: 右手側の武器列の長押し)。
- **覚醒(10秒・gameTime)**: 弾速 ×1.5(**発射時に確定・飛行中の弾は変わらない**。弾の寿命が時間基準なので射程も 1.5倍=副作用として許容) /
  移動速度 ×1.5(`computeEffectiveMoveSpeed` の `bonusMult` の**外**=ランプを待たず即。ワイヤー/一閃の dashOverride・スケーターには掛けない) /
  与ダメージ ×1.5(**近接と銃だけ**=`skillOutgoingDamageMult` を通る物。爆発・サブ・DoT・召喚は対象外。社長の「攻撃+50%」の範囲は §6 で確認) /
  被ダメージ ×2(ナイト等と乗算・`skilled` の段で) / **時間 0.9倍は既存の `triggerTimeSlow` には乗せない**(重なった KILL スローと併合されて壊れる)。
  `useGameLoop` の deltaTime 計算で `timeScale × awakenTimeScale` の**別の乗算層**として持つ(既存スローと乗算で重なる)。
  ※0.9 が見えるか(クリエイティブ B10-9)は §6。/ **スーパーアーマー**(§4)。
- **終わり**: 10秒で `bloodMeter=0`。効果は 1秒かけて戻る(速度・与ダメは線形に、時間倍率は 0.9→1.0。**弾速は新弾にだけ効く**)。発動後 3秒は溜まらない。
- **ボット**: 長押しできないので覚醒は起きない(計測の分母が変わる=別案件 B。満ちたら自動発動のフックは**付けない**)。

### 3-2. 見せ方(A)
- **体力のオーブの液体の色**: 血の量で紫→深紅へ。**補間ではなく粘り**(VitalsOrb の指数追従+減衰=家のイディオム。血は粘る)。色は hpHi/hpLo を
  `bloodMeter` で深紅 #c2413a/#5a0b12 へ寄せる。満ちたら**液面が一筋溢れて垂れる**(鼓動「ドクン」は瀕死の記号なので使わない=クリエイティブ B10-4)。
  覚醒中は 10秒で深紅→紫へ戻る(**残り時間は液体で読む**。縁は下の役割)。
- **画面の縁の血**: **上から垂れる**(浴びた血は顔に付く=物理。既存の瀕死の縁=全周・方向の縁=食らった側、と向きで差がつく)。
  量 = `bloodMeter`(上端から 0→画面の 22%)。**覚醒中は縁も 10秒で引く**(液体と同じ物として読める=役割を1つに。クリエイティブ B10-5)。
  瀕死の縁(赤・脈動)と同時に出る時は**血の縁は脈動しない**(2つのテンポを重ねない)。色は深紅(瀕死の赤より暗く青寄り)。
- **覚醒中の体**: **赤い輪郭光は使わない**(赤=カウンターの合図)。既存のオーラ家族(金=バーサーカー/青=オーバークロックの加算ソフトグロー)を
  **深紅 #5a0b12 系**で。血の粒は**移動速度に比例**して後ろへ(立つと足元へ滴る=既存の床の血飛沫を流用。2〜3粒/秒固定は「小さくて見えない」)。
  ※「血の視界」(上から垂れる筋・一瞬濁る)まで踏み込むかは §6。
- **音**: 発動=`heavy-impact`(既存)…ではなく**静かな音**に(拭う動作と合わない=クリエイティブ B10-7)。既存の中で布/息系が無ければ**発動は無音・終わりに `heavy-impact`**(重さは終わりに置く)。新しい音は足さない。

### 3-3. 受け入れ条件
- 近接で密着キルを 8回前後で満ちる。銃だけでは満ちにくい(0.06×17回)。分身・守護霊・スケボーのキルでは溜まらない(テストで固定)。
- 満ちてもオーブを長押ししなければ発動しない。長押し 0.5秒で発動。被弾しても長押しは途切れない。
- 覚醒中: 速度・弾速・与ダメ(近接/銃)が 1.5倍、被ダメ 2倍、時間 0.9倍(KILL スローと重なっても覚醒の 0.9 は壊れない)、吹き飛ばない。10秒(gameTime)で全部戻る。
- オーブの色と上縁の血が量に追従し、覚醒中に両方減っていくのが読める。
- リトライ・ステージ跨ぎで血も覚醒も残らない。守護霊のビルドに覚醒が写らない。
- スマホの HUD 配置は不変(縁の血・オーブの色は既存の箱の中)。

## 4. B12 スーパーアーマー

★設計の監査を反映した第2版。**実装は §6 の裁定後**。

### 4-1. 定義(プレイヤー側)
「スーパーアーマー中の被弾は、ダメージは受けるが**ノックバック・しゃがみ(被弾硬直)・移動/銃のロック**を受けない」。
被弾無敵(敵ごと1秒)・ヒットストップ・被弾反撃の窓・画面シェイク・既存の被弾演出(白フラッシュ・血・方向の知らせ)は**従来どおり**。

### 4-2. 入口は3つ(どれか1つでも立てばアーマー)
1. **血の覚醒中**(B10)。
2. **スキル(通常枠・Lv1〜3)**: 内部キー `super-armor`。**プレイヤーに見せる名は §6**(社長の内部語「スーパーアーマー」のままか、作品の口調=人物像・技名(例: 不動)にするか)。
   - Lv1: 1発の実ダメージが **8 以下**なら吹き飛ばない。Lv2: **16 以下**。Lv3(覚醒): **24 以下**+**近接の振り中**は量を問わず吹き飛ばない。
     ※8/16/24 の等差は当たり(クリエイティブ)。数値は社長が実機で。
   - **実ダメージ**=`skilled`(ナイト/バーサーカー/ランナー覚醒/B10 ×2 を掛けた後)。M0 の `noDeath` 切り詰めの**前**の値で見る。
   - **「近接の振り中」の定義**: `pendingSwingAt>0`(前隙)**または** `meleeSwingAt + PLAYER_MELEE_SWING_MS` の内(振り)。刀の一閃・鞭・縮地のワープ斬撃も
     「振り」(それぞれの `*SwingAt` が立っている間)に含める。
   - 台帳(`SKILLS`/`SKILL_LEVEL_INFO`)の形: `base: '小さなダメージでは吹き飛ばず、動きが止まらない', lv: ['8以下', '16以下', '24以下。近接を振っている間は吹き飛ばない']`。
   - **入手**: ガチャの normal プールへ自動で入る(均等抽選=他の通常スキルの出現率が少し下がる)。初期所持にはしない。`NEW_SLEEPING_SKILLS` には入れない(眠らせない)。
   - **アイコン**: §6(39枚目の支給まで出さない/別の既存アイコンを借りる。色違いは使わない)。足す時 `skillIcons.test.ts` の COUNT=38 と `SKILL_SINGLE_ICON` 一覧テストを同コミットで更新。
3. (将来)装備・他スキル。

### 4-3. 配線(品質監査(A): 読み手は1つではない)
- 判定は純関数 `playerSuperArmorActive(player, skilledDmg, now): boolean`(`utils/superArmor.ts`)1本。
- **吹き飛びを書く場所は2つ**: ①`damagePlayer` の kbApply ②`combatTick.ts` の爆風(`applyPumpkinBlastDamage` の `knockbackVx/Vy/Until` 直書き=跳び・叩きつけ・薙ぎの大半)。
  **両方**で純関数を読む。②は「`lastHurtAt` が変わった=当たった」で押し出しを決めているので、アーマー時は `damagePlayer` が**別の旗 `hurtArmoredAt`** を書き、
  ②は「`lastHurtAt` か `hurtArmoredAt` が変わった」で命中を見て、アーマーなら押し出しを**書かない**。
- **しゃがみ・移動ロック・銃ロック**の読み手は3つ(`isHurtMoveLocked` / `isHurtGunLocked`(useGameLoop 3箇所)/ pixi のしゃがみの絵)。全部 `lastHurtAt/lastHurtTier` を読む。
  アーマー時は **`lastHurtAt` を書かない**(=3つとも自然に通る)。被弾反撃の窓・無敵・ヒットストップは `lastHurtAt` を読んでいない(別欄)ので従来どおり。
- **蝙蝠の掴み(`grabbedUntil`)・対人体勢(pvpPosture)はアーマーで防がない**(別の状態。移動ロックの一種だが「吹き飛び」ではない)。

### 4-4. 見せ方
- **白い縁は使わない**(被弾の瞬間は既にオーブの白・方向の縁の白・全画面フラッシュ=白は「食らった」の色。クリエイティブ B12-1)。
- アーマーで吹き飛びを打ち消した瞬間は**動きで見せる**: 体が一瞬沈み込んで踏ん張る(縦 0.94 倍→戻り 180ms・ease-out)+足元に小さな砂埃(既存 `spawnDust` 系)。
  **被弾フラッシュが引いた後**(+200ms)に出す(埋もれない)。
- 常時の表示は無し(アーマーは「止まらない」ことで分かる)。既存の被弾演出は消さない。

### 4-5. 受け入れ条件(テストで固定)
- Lv1 で 8 ダメージの噛みを受けても位置が動かず、しゃがまず、撃ち続けられる。9 以上では従来どおり吹き飛ぶ(境界テスト)。
- Lv3 で近接を振っている最中は 74 ダメージ(S6の赤ゾンビ・爆風経路)でも吹き飛ばない(ダメージは受ける)。
- 血の覚醒中はスキルが無くても吹き飛ばない。
- アーマー時も `hitstopUntil`・`hitRetaliation`・`iframeBySource`・`invulnerableTime` は従来と同値。`knockbackUntil/lastHurtAt` は両経路で変化しない。

## 6. ★社長判断(B10/B12 の実装前に要る物。番号は名札つき)
- **#1「時間0.9倍」**: 0.9 はほぼ見えない(監査)。選択肢: (a)0.9 のまま(社長案)/(b)見えるまで下げる(0.8)/(c)時間は触らず画面(彩度・周辺の暗さ)で「覚醒の視界」を作る。**推薦 (c)**=理由: 10秒の常時スローは KILL/カウンターの一瞬のスローの価値を薄め、画面で作る方が「血を浴びた」固有の絵になって面白い。
- **#2「拭う場所」**: 左上のオーブ長押し(設計)か、右手側(武器列)の長押しか。**推薦=オーブ**(絵と動詞が一致)。ただしスマホで左親指は移動に使うので実機で確かめる。
- **#3「PC のキー」**: 血を拭うキー(空きキーから1つ)。
- **#4「見えない規則」**: 乾き4秒後・30秒・発動後3秒の抑え。選択肢: 残す(数字は実機で)/ 減らす(乾きだけ残す)/ 絵で見せる(液体が濁る)。**推薦=乾きだけ残し、他は外す**(規則が少ない方が液体の色だけで全部読める)。
- **#5「血の視界」**: 覚醒中に画面上部から血の筋が垂れる・瞬きのように一瞬濁る、まで踏み込むか。**推薦=筋だけ踏み込む**(縁の血の延長で済み、固有性が出る)。
- **#6「与ダメ+50%の範囲」**: 近接+銃だけ(設計)か、爆発・サブ・召喚も含むか。**推薦=近接+銃だけ**(浴びた本人の手が強くなる、で筋が通る)。
- **#7「スキルの見せる名」**: 「スーパーアーマー」のまま(社長の言葉)か、作品の口調の名(例: 不動)か。**推薦=不動**(既存のスキル名は 死神/バーサーカー/縮地/英雄/守護霊=人物像・技名)。
- **#8「アイコン」**: 39枚目の支給まで出さない / 意味の近い既存アイコンを借りる。**推薦=支給まで借りる**(色違いは使わない)。
- **#9「B11(巡航の装備)」**: B3(巡航の方式)の決着待ち(まとめHTMLの監査の判断)。
