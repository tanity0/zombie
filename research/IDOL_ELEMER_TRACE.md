## 4. 秒数の出どころ(ERから写していない)

ERの技単位のフレームデータは公開されていないため、**秒数は本作の式から導出**している:

```
歩いて避けられる下限:  予告 ≧ (判定半径 + 自機半径16) ÷ 104.4 × 1000
カウンターが間に合う下限: 予告 ≧ 550ms
   (導出: カウンター窓400ms・人の反応250ms ⇒ 押してよい時刻の幅を300ms以上確保する条件)
```

写したERの数値は**構造の物差しだけ**:

| ER | 本作 | 一致度 |
|---|---|---|
| ロール無敵 0.42〜0.45秒 | カウンター窓 **400ms** | ほぼ一致(偶然ではなく、これを物差しに採用した) |
| パニッシュ窓 1〜2秒 | 休符 **0.9秒(1発)/1.7秒(2発)** | ほぼ一致 |
| コンボ最大3段(ミドラ) | ストリング **P1=3段 / P2=4段** | MAX枠なので1段上乗せ |
| アリーナ直径30〜40m | **1m ≒ 17px** で換算 | 既存の距離帯とほぼ一致 |

## 5. ★写しきれていない点(社長判断・素材待ちを含む)

1. **①の「大剣が浮遊する」絵が無い。** ERは**武器が宙に浮く**ことが予告そのもの。本作は赤い予告図形で
   代替しているが、**アイドルは1枚絵+左右反転しか無い**ので「構えの違い」で読ませることが物理的に不可能。
   → **モーション差分の素材が要る**(必要素材リスト)。
2. **③の「2回斬って戻る」が未実装。** 現状 orb は片道の誘導弾。**戻り**を足すと
   「避けた後にもう一度来る」=①の回避狩りと同じ効き方をする。**実装可能・未着手。**
3. **④盾タックルを落としたことの是非。** アイドルの主題と真逆なので不採用としたが、
   「**密着に居座られた時に剥がす技**」が無いという穴でもある(現状は roll で離脱するだけ)。
   ER忠実を優先するなら足す案もある。**社長裁定待ち。**
4. **【実装上の問題】硬直の差が消えている。** 設計では roll=500 / punch=900 のように
   **技ごとに硬直を変えて「硬直の長さの違いで技を選ぶ」**読みを作る意図だったが、
   v0.25.2613で入れた**硬直の下限900ms(`withRecoverFloor`)により全6技が一律900msになった**。
   ⇒ **「どの技を食らったかで反撃の余裕が変わる」という読みが成立していない。**
   下限は「休符が短すぎてプレイヤーのターンが無い」問題への対策なので**下限自体は正しい**が、
   **技ごとの差を付け直す**necessity がある(例: 下限900を保ったまま重い技は1200〜1700にする)。
   **社長裁定待ち。**
