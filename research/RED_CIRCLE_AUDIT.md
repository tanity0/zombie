# 赤円テレグラフ全数監査(2026-08-30・社長報告「サークル内が当たり判定になってない嘘がある。グレンの飛び掛かりとかも」)

走査エージェント(Explore)で**全ての赤い円の「絵」と「判定」**(中心・半径・発火タイミング・接触の絡み)を
突き合わせた結果の台帳。行番号は v0.25.4084 時点。

## A. グレンの飛び掛かりの正体(最有力)= #R1「ボスの体の接触ダメージが赤の外で生きている」

- **円の幾何そのものは正直**(gJumpRadius を絵と判定が同じフィールドで読む・ステージ倍率も1箇所)。
- **嘘の正体**: 着地の瞬間に円は消える(描画は windup/air のみ)が、**ボスの体の接触ダメージは
  溜め・硬直(recover)中も生きている**(combatTick.ts の isBiteSubject 早期return はボスに効かない
  =ボスは噛みつき化の対象外なので素の接触ダメージが残る)。着地硬直 g-jump-recover ≈実効1100ms >
  被弾i-frame 1000ms なので、**円の中で1発→i-frame切れで見えない体からもう1発**が起きる。
  硬直を殴りに寄っても**赤が無いのに当たる**。
- さらにカウンター憲法(v3947)は「recover は接触ダメージが無い」という**誤った前提**で recover を
  パリィ対象から外した(コメント combatTick.ts:1464 付近)——実際は当たるのに弾けない。
- 同型: pumpkin / lab-zombie-3 / hunter(isBossType)の crouch / recover。
- **裁定待ち #R1**(仕様変更なので勝手に直さない)。選択肢は本文(チャット2026-08-30)参照。

## B. 系統的な嘘 = #R2「判定は『円の半径+プレイヤー半身14px』」

- applyPumpkinBlastDamage(combatTick.ts:279-281)は `距離 <= 半径 + pr`(pr=14)。
  **絵の円の外側14pxの輪も被弾する**(小円 r=70 では実効+20%)。
- 同じ+pr: applyGlenFloorDamage / mk-spin(bountyTick) / suriel ringspin / acrasiel burst / warp。
- コード内コメントの「赤の外=安全」(pixiScene 2箇所)と食い違う。**裁定待ち #R2**
  (判定を「プレイヤー中心が円内」へ縮めるか、絵を+14pxで描くか)。

## C. 空中の体当たり抑止の取りこぼし = #R3(区分整合の候補)

- 抑止済み(裁定済みの型): 汎用jump / g-jump-air(v2601) / g-trijump-air(v3050) / g-glide-active(v3052) / トール全攻撃州。
- **未抑止のまま同じ動作**: ラフィ jump-attack / 賞金首バランス型 leap-air(combatTick.ts:1513に
  「接触が生きている」旨の注記あり=要確認) / 舞妓 mk-suiu-hop1..3 / フィル phill-dive-fall。
  **飛行経路の体に触れると赤円の外で被弾**。裁定済みの区分仕様への整合として直す候補。

## D. その他((B)積み・小)

1. **翼撃(g-wing)**: 判定は windup 明けの1回だが、active 220ms も全濃度の円が残る。
   →sweep等と同じ「activeは見た目のみ」の既存慣習の範囲。据え置き(気になるなら消え際フェード)。
2. **フィルの裁き/急降下**: 絵の半径だけズームでクランプ(phillZoomSafeRadius)・判定は生値。
   現行値(90/70)ではクランプに達しない=潜伏。半径を上げる調整をしたら顕在化する。
3. **スリィエルring-spin/アクラシエルburst の完了latch**: 命中後も短時間、全濃度の円を描き続ける
   (「赤いのに当たらない」の尻尾)。
4. **押し(ノックバック)中は遅延ヒットの消化ループが280ms止まる**: 満了済みの円が遅れて爆ぜる。
   §8(ノックバック)の設計と絡むのでそちらで扱う。
5. **見え方の注意**: 着地円の中心=AABB中心・ボスの絵は足元アンカー。グレン(120×120)は見た目の
   着地点が円中心の60px南に見える。「円と違う場所に着地して見える」の一部はこれかもしれない。
