## 3. 動き
- **ずっと浮いている**(着地しない)。絵は16コマのループ(1コマ 90ms・叩き台)。上下にゆっくり漂う(±3px・周期約2.4秒・2つの周期を重ねて揃えない)。描画で持ち上げる(判定・影・帯の y は地面のまま=CLAUDE.md「Y方向」の掟)。
- **慣性**(CLAUDE.md MUST): 最高速までおよそ0.8秒・止まるまでおよそ1.0秒。
- **巡回(見つける前)**: 宇宙飛行群と同じく POI を無作為に巡る(速さ 80px/s・叩き台)。着いたら2〜4秒その場を漂う(着地はしない)。詰まりの見張り・障害物の回り込み・行ける帯(`clampRectToPlayableArea`)は宇宙飛行群と同じ。
- **索敵**: 宇宙飛行群と同じ(`frontConeSees`・前方900px・殴られたら気づく・1350px より外に3秒で見失う)。対象はプレイヤーと守護霊。
- **周回(見つけた後)**: 相手(プレイヤー)の周りを**半径 320px**(叩き台)の輪で回る。回る向きは見つけた時に無作為、**8〜14秒ごとに減速して逆向きに回り直す**(慣性つき)。周回の速さは角速度で 1周約7秒(輪の上で約290px/s・叩き台)。プレイヤーが動けば輪の中心も動く(中心は慣性なしで追うが、亡霊の移動そのものは慣性つき=急な追従はしない)。
  - 輪が障害物・行ける帯の外にかかる所は、通れる所まで半径を縮める(縮められなければ、その区間は輪の内側を通る)。
  - 画面の外へ出続けない(交戦中は画面の内側を優先・宇宙飛行群 §8 A8 と同じ)。
- **反対側へのワープ**: プレイヤー(または守護霊)の攻撃が当たった時、**3割の確率**(叩き台・連続しない=ワープしてから4秒は起きない)で、**薄れて消え→輪の反対側(角度+180°)に薄れて現れる**(各250ms・パッと消えない)。消えている間と現れる途中は当たらない(当たり判定を外す=撃っても素通り)。現れた所が通れない時は、通れるところまで輪を回した位置。ワープの瞬間に低い風の音と、消えた所・現れた所に淡い灰色の霧(派手さの絵・判定なし)。
- **崩し(紫)・気絶**: その間は周回もワープもしない(その場で漂う)。

## 4. 攻撃=叫び(社長支給2026-10-29「攻撃モーション。口を開く」「これは叫び。周囲に範囲攻撃。カウンター不可」)
- **素材**: `public/sprites/mutant-wraith-scream.png` 1216×135・**16コマ×76px**・口が開いていく。社長「少しズームしちゃってるから、大きさうまく合わせて。多分スタート側が小さくなってる」=実測で本体の高さが **0コマ目111px → 15コマ目130px**(足元を支点に約17%ズーム): コマごとの本体の高さ `[111, 112, 113, 114, 116, 116, 118, 120, 121, 123, 125, 126, 131, 129, 129, 130]` を既存の「シートのコマは立ち絵と同じ背丈へ合わせる」(`sheetHeightFix` の bodyH)へ渡し、**どのコマも浮遊の立ち絵(本体150px/枠152px)と同じ背丈**で描く。横は胸の位置が3px以内で動く程度(寄せは同じ方式で付ける)。
- **形**: 本体を中心にした**円の範囲攻撃**(半径 380px・叩き台=周回の輪 320px より外まで届く=周回の輪に立っていると当たる。外へ走って逃げる)。**カウンター不可=紫の円**(色と形の文法②)。弾けない(`noParry`・宇宙飛行群の隕石と同じ)。盾は防ぐ(既存どおり)。ダメージ 20(叩き台)。
- **時刻**: 周回中に、前の叫びから5〜8秒(叩き台)。まず慣性で止まり(移動しながら叫ばない=円の中心が動かない)、止まり切ったら溜め=16コマを1コマ70ms(計1120ms)で再生し、**15コマ目が終わる瞬間(1120ms)に当たる**。その後 400ms 最後のコマのまま叫び続け(判定なし)、浮遊のコマへ戻って周回を再開。
- **赤い予告の4つの掟**(紫も同じ): ①紫の円が外から内へ流れて、②**溜めの始まり(0ms)に出て**、③**1120ms で消え切った瞬間に当たる**(`meteorPhase`)。④通る技ではない。
- **崩し(紫)・気絶で溜めが止まった時**: 叫びは消え、予告も消える(紫が残って当たらない、を作らない)。溜め・叫びの間はワープしない。
- **当たった瞬間**: 叫び声(既存の叫喚型の声を低く)・紫がかった灰色の衝撃の輪を2〜3重に外へ・軽い画面の揺れ(派手さの絵・判定なし)。
- 接触ダメージは無し(宇宙飛行群・解放軍群の旗手と同じ)。

## 6. 受け入れ条件
- ステージ1・3・4・5で出撃3秒に遠くの POI に1体。POI を巡って漂う(着地しない)。
- 見つけるとプレイヤーの周りを回り、ときどき逆向きに回り直す。動き出し・止まり・向き変えに慣性がある。
- 撃つと、たまに反対側へワープする(薄れて消え、反対側に薄れて現れる)。連続ではワープしない。ワープ中は当たらない。
- 初見でカットイン・HPバー・体勢値・画面外の印が付く。倒すと消える(死体は崩れて薄れる)。
- 周回中にときどき止まって叫ぶ。叫びの溜めの始まりに紫の円が出て、外から内へ流れ、消え切った瞬間に当たる。カウンターでは弾けない。叫びのコマはどれも浮遊と同じ背丈。接触ダメージは無い。
- `?wraithnow=1`・対策室・ボス戦テストで出せる。

## 8. 着手前の品質監査(opus・2026-10-29)を受けた確定(§2〜§5 より優先)
- **区分の付け方(A1)**: `isBountyType`(賞金首4型の表)には**載せない**(載せると賞金首の制御・120秒退場・金箱・常時の印・囲いの停止が付く)。宇宙飛行群と同じく**個別の名簿**に足す: `ENEMY_STATS`(判定 60×50・速さ80・体力2000の仮=出現時に式で決め直す・接触ダメージ0・経験値0)/ `countsTowardEnemyCap` の除外 / `CONSTANT_STRENGTH` / `isBossType` / `isBodyWallBoss`(接触の被弾演出の除外・体の壁・画面外は当たらない・英雄に引き寄せられない・犬と護衛の対象外・盾)/ updateEnemies の素通り / ドロップの除外 / 体勢値(90)と交戦中だけの印 / カットインの名・表示名・ボスアイコン・対策室のヒント・表示倍率 / 対策室の枠(`wraithnow`)・ボスラッシュの棚(宇宙飛行群と同じ「story」)・ボス戦テスト / 歩行の二次モーションの表(揺れ・傾ぎを掛けない `hover`)/ 遅延組 `wraith` と原盤台帳。「ボス戦」(ENGAGEABLE)には入れない(宇宙飛行群と同じ)。
- **輪の形(A2)**: 輪はプレイヤーの足元を中心にした**横長の楕円 横170×縦95px**(固定値=スマホの論理幅405の画面に左右とも収まり、上は地平線のフェード(約230px上)にかからない・PC でも同じ値=判定はスマホと同じ)。それに合わせて**叫びの半径を200px・1コマ90ms(溜め1440ms)**に直す(輪の一番近い所=縦95pxに居ても、外へ105px走れば抜けられる=反応0.3秒込みで1.3秒 < 1.44秒)。
- **ワープの判定(A3・A4)**: 見つけて周回している時だけ(巡回中に殴られた時は気づくだけ)。プレイヤー側の攻撃かを区別できない入口なので、**被弾(`lastHit` の更新)ごとに600msに1回だけ**3割を引く(散弾・継続ダメージで何度も引かない)。崩し・気絶・叫びの溜めと叫びの間・ワープの後4秒は引かない。きっかけの一撃のダメージと体勢値はそのまま通る。
  - 消える250ms+現れる250msの**計500msは当たらない**: `isUntouchable` に「ワープ中」(`wraithPhased`)を足す(照準・近接・爆風)+弾の衝突(`collisionUtils`)と `damageEnemy` の入口でも素通り。体は**消え切った瞬間**に、その時のプレイヤーから見て反対側(今の角度+180°)の楕円の上へ移す(通れなければ通れるまで楕円を回す)。本体・影・光が一緒に薄れる。HPバー(HUD)は出したまま。
- **振り切れるか(A5)**: ★未決 #4(社長へ)。決まるまでは設計どおり(輪の中心はプレイヤーへ付いていく)。ただし**ステージボス戦・カットイン・大きなイベント・屋内・帰還サークルの間は見失って巡回へ戻る**(照準の取り合い・囲いの壁の内外の食い違いを作らない)。
- **持ち上げ(A6)**: 絵を34px持ち上げる(判定・影の y は地面)。影は小さく薄く(幅0.6倍・濃さ0.5倍=浮いている)。その上に ±3px の漂い。
- **輪の中心(A7)**: 見つけた相手(プレイヤーか守護霊・宇宙飛行群と同じ `nearestTarget`)の足元。
- **向き・寸法・死体(A8)**: 向きは見つけている間は相手の方、巡回中は進む向き(宇宙飛行群と同じ)。左右を返すとコマごとの寄せも一緒に返る(支点は絵の座標で付けるので自動で鏡になる)。表示倍率は実寸で撮って決める(背丈=画面で約170px・ボス帯)。死体は宇宙飛行群と同じく、倒れた瞬間のコマ・寄せ・持ち上げ・向きを引き継いで落ちてから崩れる。
