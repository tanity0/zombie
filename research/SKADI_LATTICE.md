# スカジの新技「氷の格子」(縦10本→横10本の氷の刃)

社長の言葉(2026-10-02):
「スカジの新技。プレイヤーを中心に10本、縦に氷の刃、直後に横に10本。覚醒後は3連続。カウンター不可。高速。縦、横、都度ターゲティングしなおし。」

判断の物差し(CLAUDE.md): より面白くなる方。

## 1. 何をするか
- スカジは立ち止まり、**相手(ヘイトの相手)の今の位置を中心に**、縦向きの氷の刃(帯)を**10本**、等間隔に並べて落とす。
- 当たった直後に、**その時の相手の位置を中心に取り直して**、横向きの刃を10本。
- **覚醒後(HP70%以下=フェーズ2以降)は「縦→横」を3回続ける**(縦→横→縦→横→縦→横の6段)。フェーズ1は1回(2段)。
- **カウンター不可**=予告も刃も紫(色と形の文法)。
- 高速: 1段の溜め 650ms(設計監査 A-1 で 550 から。反応250ms+静止から1歩=慣性込み約350ms が入る最短)。

## 2. なぜ面白いか(設計の芯)
- **刃の1本は必ず相手の真上を通る**(並びの中心の1本が相手の位置)。止まっていると毎段必ず当たる=**毎段、横へ(縦の段)/縦へ(横の段)一歩ずれる**ダンスになる。
  隙間は64px(帯の幅32px・間隔96px)=1歩ずれれば入れる。必要なのは30px(帯の半幅16+自機の半身14)=静止から慣性込みで約0.35秒+反応0.25秒 ≤ 溜め0.65秒。
- 段ごとに取り直すので、**どこへ逃げても次の格子が付いてくる**。覚醒後は6段を軸を替えながら踏み続ける=リズムゲーム的な手応え。
- ※**斜めに歩き続けるだけで全段を抜けられる**(設計監査 A-2: 各軸 73.8px/s で 30px を 0.41秒で抜け、隣の刃までは届かない)。
  社長へ事実として上げる(推薦=段の中心を「相手の今の位置+速度×溜め」=予測位置に置く。止まる/切り返すの判断を毎段迫れる)。答えが出るまでは社長の言葉どおり「相手の今の位置」。
- ※被弾の無敵(1秒)が段の間隔(0.65秒)より長いので、**1段食らうと次の段は当たらない**(設計監査 C-2)。覚醒後の最大被弾は3回。事実として社長へ。

## 3. 流れ(状態)
`lattice-windup`(段の溜め 550ms・静止)→ 溜めの終わりの1フレームで当たる → 次の段があれば**同じフレームで**次の段の溜めへ(軸を替え、相手の位置を取り直す)→ 最後の段のあと `lattice-recover`(硬直)→ 追跡へ。
- 段の中心=**段の溜めの頭のヘイトの相手の位置**(以後その段は動かない)。
- 並び: 軸に垂直な方向に、中心から (i−4)·spacing(i=0..9)=**中心の1本(i=4)が相手の真上**、左右(上下)非対称に 4本と5本。
  どちらが4本側かは段ごとにランダム(同じ方向へ逃げ続けるだけ、を潰す)。
- 刃の長さ: 並びの幅と同じ(10·spacing=960px)=正方形の格子。中心=段の中心。
- 判定: 溜めの終わりの1回だけ。各刃=帯(始点→終点・半幅 halfWidth)を `distToBandRect`(描いている四角と同じ)で判定。どれか1本に入っていれば damage(1段1回)。
  弾く向き: **刃に直交**。刃の真上に居たら本数の少ない側(開けている側)へ(`latticeHitSource`・設計監査 A-4)。死因の表示は「スカジの氷の格子」。
  4本側: side=+1 は中心より+側(右/下)に5本・−側に4本(−1 はその逆)。
  守護霊にも同じ帯で当たる(applyGhostAllyCapsuleHit)。
- 段の数: フェーズ1=2段 / フェーズ2以降=6段(**溜めの頭のフェーズで決めて持つ**)。

## 4. 予告(赤い予告の掟。カウンター不可=紫で描く)
- 各段の10本の帯は**その段の溜めの頭の1フレーム目から**、判定と同じ四角を薄い紫で敷く(掟②。窓だけだと頭の約85msが空白=設計監査 A-3)。
  その上を既存の帯と同じ窓(`bandSweepCenter`/`bandSweepAlphaAt`=帯の始点→終点へ流れる既存の帯の文法)が紫で流れ、**抜け切った瞬間=当たる**(掟③)。段ごとに別々の時刻。
  10本ぶんなので縁の焼き素材は使わず、1本10スライスの塗りだけ(図形数を抑える・設計監査 C-4)。
- 刃そのもの(当たった瞬間に帯をなぞって走る氷の筋と破片)は派手さの絵=判定なし。大きく。
- 次の段の予告は、前の段が当たった同じフレームに出る(=「直後に」)。

## 5. 抽選・カウンター・台帳
- `SkadiMove` に `lattice`。重み melee15 / near20 / mid25 / far25。CD 16秒(溜めの頭で打つ・潰されても残る)。
- 台本: `lattice: ['lattice', 'dash', 'ice']`。
- カウンター: 溜めは紫=カウンター不可(HIDDEN_COUNTER_WINDUP_STATES に載せない)。硬直 `lattice-recover` は体当て('body')で取れる。
- 守護霊のAI台帳(ghostTelegraph): 'none'(10本の格子=帯1本でも円でもない。守護霊は既存の被弾規則で受ける)。
- 記録用の技キー: 'skadi-lattice'(死因「氷の格子」)。ボスメーカー ▸ 'sk-lattice'。

## 6. 数字(叩き台・`HIDDEN_SKADI_TUNING.lattice`)
windupMs 650 / bands 10 / spacing 96 / halfWidth 16 / damage 28 / roundsP1 1 / roundsAwake 3 / recover 900(下限つき)/ cdMs 16000。

## 7. 受け入れ条件(テストで固定)
1. 並び: 中心の1本が段の中心を通る/隣との間隔 spacing/本数 bands。4本側の向きは指定どおり。
2. 隙間を自機が通れる: spacing − 2·halfWidth > 自機の幅(28)。
3. 1歩で抜けられる: 反応250ms + 抜けるのに要る距離(halfWidth + 自機の半身14)を**静止から慣性つきで**歩く時間(`walkTimeMs`)≤ 溜め。
4. 判定=描いている四角(帯の端点を半幅ぶん伸ばした矩形)と一致(distToBandRect を同じ端点で呼ぶ)。
5. 段の数: フェーズ1=2 / フェーズ2以降=6。

## 8. 後始末
- ノックバックだけで止まっている間は既存どおり bossStateUntil が繰り下がる(段の中心は動かない)。
- 気絶・紫・罠などで潰れたら既存どおり追跡へ戻る(残りの段は出ない)。

## 9. 負荷 1/10
判定=1段の終わりに帯10本の距離計算1回。絵=溜め中は帯10本×(四角2+スライス最大10)=最大120図形/フレーム、当たった段は筋10本×(線2+円1+破片4)=70図形を420ms。
スプライトは使わない。投影影なし。(既存の帯1本=スライス30+縁スプライト30 の約4本ぶん)
