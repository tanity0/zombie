# 進軍NPCを敵が狙う(体力・自然なヘイト・倒れて起こす)

## 0. 社長の言葉(2026-10-06〜07・この順で決まった)
- 「守護霊はそのままに、もう一体、ゲーム通してついてきてくれるNPCの助っ人をつけるとどうなりそう？」
- 「NPCを敵から狙われるようにできる？」
- 「ボス戦でもヘイトを取れるようにできる？」→「**いいえ、自然にヘイトを取る仕組みがいい**」
- (ボスの狙い=ダメージ+近さ・近さを全員に効かせる案)→「いいね」→「推薦で」
- 「ジュンはストーリー用の死ぬキャラなので使えない」「**進軍NPCのことです。今回のは**」
- (新しい助っ人を作るか/今の進軍NPCそのものを狙わせるか)→「**いいえ**」=**新しい助っ人は作らない。今の進軍NPCを狙わせる。**

**ゴール(1行)**: 拠点へ進軍する軍人NPCが、敵に自然な理由(近さ・撃ったダメージ)で狙われ、倒れることもある。プレイヤーは立ち位置で彼らを守り、倒れたら起こしに行く。

旧案(衛生兵ジュンを新しい助っ人として随行させる)は社長判断で取り下げ。旧ファイル名 research/COMPANION_NPC.md。

## 1. 今の進軍NPC(事実)
- **誰**: 名簿8人(エドガー/ジョセフ/エリザベス/武蔵/ムハンマド/チェン/ローレン/フェイザー)から**1出撃4人**。東西南北の拠点を1人ずつ担当(`makeEscorts`・`state.escorts: EscortSoldier[]`)。
- **出るステージ**: 屋外の本編。**出ない**: ラボ(ステージ2)・屋内・ストーリーボス直行(M7)・EX・ボス戦テスト・練習・エンディング。洋館の通路(corridorMode)では**横一列でプレイヤーについて歩く**。訓練(M0)は別の随行2人(軍人+衛生兵ジュン)=**今回の対象外**。
- **動き**: 担当拠点へ前進。前方に敵=停止、左右=50%、後方=70%の速さ。**画面の外では索敵・射撃なしで、通常の5分の1の速さで拠点へまっすぐ進む**(社長指示2026-10-07・`utils/escortOffscreen.ts`)。苦戦の通信(後退/放置のセリフ)が流れると、その軍人は20秒止まる。拠点の円に10秒居ると解放(画面外でも)、その後は円の縁を巡回。解放はカメラのアテンションではなく、通信「◯部拠点の解放を確認。」→その軍人の解放セリフで知らせる。
- **撃つ**: 全方位の最寄りの敵へ、0.6秒ごとに8ダメージの実弾(フェイザーは2発)。
- **体力は無い**。「被弾しても何も起きない」が今の作り(gameStore.ts の護衛ブロックのコメント)。囲まれた/助けられた/放置などの台詞はある。

## 2. 変えること(全体像)
1. 進軍NPCに**体力**を持たせる。敵の攻撃が当たる。
2. 雑魚・強個体・ハンターは、進軍NPCの方がプレイヤーより近ければ**進軍NPCを狙う**。
3. ボスは「**直近に与えたダメージの割合+近さ**」で狙いを決める(プレイヤー/守護霊/進軍NPCの全員共通)。
4. 体力が尽きると**倒れる(死なない)**。プレイヤーがそばに居ると起き上がる。

## 3. 体力と当たり方
- **体力**: 出撃時のプレイヤーの最大体力の**60%**(叩き台)。出撃中は固定。
- **「画面内」の定義は1本にする(品質監査QA-2 A-2)**: **ズーム込みの可視域**(`isPointInZoomedViewport`・英雄と同じ)+100px。今の進軍NPCの `onScreen`(updateSuppression・camera+gameBounds±100・ズームを見ない)もこれに揃える=ボス戦のズーム引き(0.4)で見えている軍人が「画面外」扱いになっていたのを直す(CLAUDE.md「ズーム引き考慮」の不具合修正・**現行挙動が変わる**ので社長へ一言)。
- **当たるのは画面の中(画面外100pxまで)に居る間だけ**。画面外の進軍NPCは敵の居ない所を自動で進むだけで、攻撃は当たらない。**見えない所で勝手に倒れない**(プレイヤーの目の前でだけ起きる)。
- 被弾の扱いはプレイヤーと同じ量。被弾後**1秒の無敵**(プレイヤーの `INVULN_MS` と同じ考え・連続ヒットで溶けない)。
- **プレイヤー・守護霊の攻撃は当たらない**(味方)。
- **被弾の経路(全部に入れる・入口名で)**: 次の5系統すべてで進軍NPCに当たること。1つでも抜けると「その技だけ素通り」になる。
  1. **接触**(体当たり・噛みつき・§16の爪/叩き): `combatTick.applyContactDamage` と同じ判定で、進軍NPC用の分岐を足す(召喚の `checkEnemySummonCollisions`・英雄の `applyContactToHero` と同じ並び)。
  2. **敵弾**: `combatTick.ts` の英雄用・守護霊用の弾ループと並べて進軍NPC用を足す。
  3. **ボス技の形(円/カプセル/扇/矩形)**: **`hitThirdParties`(heroBlast.ts)に進軍NPCを合流**させる(守護霊・英雄と同じ入口=約27箇所が自動で拾う)。守護霊を直接引いている箇所(`applyGhostAllyCapsuleHit` 等)は進軍NPCの分岐を足す。
  4. **gameStore 内の継続技**: `setThirdPartyHook` 経由で同じく合流。
  5. **床**(ジブリールの火・グレンの血溜まり・地面の火): 第三者に当たる床は進軍NPCにも当てる。
  - 実装者は `grep -n "hitThirdParties\|ghost-ally" src` で全箇所を列挙し、**1箇所ずつ「進軍NPCも当たる/当たらない(理由)」を DEVELOPMENT_LOG に表で残す**。

- **品質監査QA-2 の(B)で、実装時に必ず拾うもの**:
  - 被弾の経路は5系統に加えて**爆風**(パンプキンの着地・城ボスの跳びの着地=combatTick の PumpkinBlast 経路)も。入口の実数は32(hitThirdParties 15+hook 4+守護霊を直接引く13)。
  - 敵側の新フィールド名は既存の `Enemy.escortTarget`(救助イベント)と衝突させない(例: `targetEscortId`)。
  - アイドルの偏差撃ちは相手の速度を使う=軍人の速度も渡す。
  - **対象の軍人**: 本編の4人と洋館通路の4人。**M0の随行2人は除外**(`farBackdrop === 'tutorial'`)。
  - 倒れている間は台詞(囲まれた/苦戦/並走)を出さず、`stallUntil` も付けない。
  - 倒れる時の滑りは `clampRectToPlayableArea` を通す。画面外の倒れ印は既存の緑の矢印(syncArrows)と重ねない。
  - 守護霊ボス「幻影」も `HATE_TRACKED_BOSS_TYPES` 側(ボスの規則)。

## 4. 雑魚・強個体・ハンターに狙われる
- `resolveEnemyTarget`(`enemyUtils.ts`)の候補に、**画面内・倒れていない進軍NPC**を足す。
- **規則**: その敵から見て、進軍NPCが**気づく距離(380px=錬金術の仲間と同じ `ALCHEMY_AGGRO_RANGE`)の内側**で、かつ**プレイヤーより近い**なら進軍NPCを追う/撃つ。
- **対象の敵**: ボスのヘイト表(`HATE_TRACKED_BOSS_TYPES`)に**入っていない敵全部**=雑魚・強個体(パンプキン/削岩型/伐採人)・ハンター(★S-3 の推薦どおり。区分「強個体」の仕様として入れる)。述語は `isBossType` ではなく `!isHateTrackedBossType` で分ける。
  - 除外: 英雄(変異)・解放軍群(変異)の旗手=中立/狙いは今のまま。死神系=今のまま(プレイヤーを追う)。
- **技の目標点も同じ相手にする(品質監査QA-2 A-3)**: 強個体・ハンターの技(突進・跳び・振り下ろし)は今、目標点をプレイヤーの中心から直接読んでいる(gameStore の各 aiPhase の開始)。`resolveEnemyTarget` だけを直すと「歩くのは軍人へ、跳ぶのはプレイヤーへ」になる(v0.25.3862 の掟違反)。**技の開始時の目標点も `resolveEnemyTarget` の結果から取る**。対象箇所は実装時に `grep` で列挙し DEVLOG に表で残す。
- **パタつき防止**: 進軍NPCとプレイヤーがほぼ等距離の時に狙いが毎フレーム入れ替わらないよう、**今の相手に20%の粘着**(相手を替えるのは、新しい方が今の相手より2割近い時)。
- **優先順**(関数は上から順に決まる): ①英雄の誘い(今のまま) ②守護霊に殴られた雑魚のラッチ(今のまま) ③ボスのヘイト(§5) ④距離規則(プレイヤー/召喚/進軍NPCのうち近い方・上の粘着つき)。
- **赤い予告の掟**: 進軍NPCを狙う技も、プレイヤーを狙う時と**同じ予告を同じ時刻に**出す(出る=溜め開始/消え切る=当たる)。新しい予告は作らない(既存の技の狙い先が変わるだけ)。

## 5. ボスのヘイト=「ダメージの割合+近さ」(全員共通・社長了承)
- 今: ボスは技の溜めに入る瞬間に、**直近6秒に与えたダメージ**が多い方(プレイヤー/守護霊)を狙う。今の相手に×1.3の粘着。両方0なら粘着なしで近い方(`bossHate.ts` `pickHateSide`)。
- 新: 候補を**プレイヤー/守護霊/画面内で倒れていない進軍NPC(最大4人)**にする。
  1. **全員のダメージが0の時**: **今と同じ**=粘着なしで一番近い相手(★S-4 推薦どおり、開幕の狙いを変えない)。
  2. **それ以外**: 点数 = **ダメージの割合** `dmg_i / Σdmg`(0〜1) + **近さの点** `NEAR_W × ramp(d)`。
     - `d`=ボスの中心から相手の中心。`ramp` は 600px で0 → 160px 以内で1 の直線。`NEAR_W`=0.6(叩き台)。
     - 今の相手には ×1.3(粘着は今のまま)。いちばん高い相手を狙う。同点はプレイヤー。
- **進軍NPCも撃つので、ダメージの割合を自然に持つ**(1射8ダメージ)。ボスの近くで撃ち続ける軍人は、プレイヤーが手を止めた時に狙われやすい。
- **起きること**: 攻撃し続けている人がほぼ狙われる。手を止めると、ボスの近くで撃っている相手へ向く。**プレイヤーがボスと軍人の間に立てば、近さで狙いを取り返せる**。
- ★**守護霊の狙われ方も変わる(社長了承済み)**: ボスの間合いで斬り合う守護霊は今より狙われやすく、遠くから撃つプレイヤーは今より狙われにくくなる。開幕(全員0ダメージ)は今と同じ。
- **型**: 狙いの相手を `HateSide = 'player' | 'ghost'` から `{ kind: 'player' } | { kind: 'ghost' } | { kind: 'escort'; id: string }` へ広げる。**ダメージを積む側も広げる**(品質監査QA-2 A-1): 今は軍人の弾が `hateShotSource = isGhostShot ? 'ghost' : 'player'`(useGameLoop)で**プレイヤーのバケツに積まれている**=このままだと軍人の割合は常に0で、4人の射撃がプレイヤーの割合を水増しする。
  - 軍人の弾(gameStore の escortShots → 実弾)に **`escortId`** を持たせる。
  - `damageEnemy` の hateSource に `{ kind: 'escort'; id }` を足し、ボスは**軍人ごとのバケツ**(`hateEscortBuckets: Record<id, HateBucket[]>`)に積む(プレイヤー/守護霊のバケツと同じ形・同じ6秒窓)。
- **二択の箇所を全部3択以上にする**: 狙いの座標を `aim.side === 'ghost' ? ghost : player` の形で引いている箇所(例: idolTick.ts 偏差撃ち・angelBossTick.ts 火の足元)は、型を広げても TS が拾わない。`grep -n "side === 'ghost'\|hateTarget === 'ghost'" src` の全箇所を列挙して直し、DEVLOG に表で残す。
- **移動の狙い**(`resolveEnemyTarget` の `hateTarget`)も進軍NPCへ向くようにする(技と移動の主語を揃える=v0.25.3862 の掟)。
- **裏ボスの召喚への吸い付き**(useGameLoop の `BOSS_SUMMON_AGGRO`=距離だけで召喚へ寄る)は、進軍NPCを候補に**入れない**(ヘイトの点数を素通りさせない)。
- 対象のボス: `HATE_TRACKED_BOSS_TYPES` の全部(城ボス・アイドル・ゲート2の6体・裏ボス4体・フィル・賞金首4体)。英雄・旗手は今のまま。
- `?bosshate=0` は今どおり「常にプレイヤー」。

## 6. 倒れる・起こす
- 体力が0になると**倒れる(死なない・出撃は続く)**。
- **倒れている間**: 前進しない・撃たない・拠点の10秒は**止まる(進んだぶんは保つ)**・**敵に狙われない・技も当たらない**(★S-2 推薦どおり)。
- **ボスが倒れた軍人に狙いを決めた直後に倒れた時**: 決めた狙いはプレイヤーへ戻す(守護霊が消えた時と同じ扱い=`resolveBossLockedHateAim`)。
- **起こす**: プレイヤーが**90px以内に2秒**居ると起き上がる。離れると進み具合は少しずつ戻る(1秒で0.5秒ぶん)。起き上がると体力50%。
  - 半径に入った瞬間、倒れた軍人が**プレイヤーの方を向く**(向きの切り替え)+進みの縁取りが灯る(CA-2 項6)。
  - 進み具合は頭上の体力の線に**重ねた細い白い縁取りが伸びる**ことで見せる。**満ちる先は起きた時の体力(50%)の位置**(満ちた=立つ、で嘘が無い)。離れて戻る時は**縁取りだけが引く**(体力の線は縮まない=殴られたように見せない)。床の円は使わない(この作品の床の円は危険/範囲の記号)(CA-2 項5)。
- **時間で自然に起きる**(社長裁定2026-10-07「自然に起きる」): 倒れてから**30秒**(叩き台)で、プレイヤーが居なくても起き上がる(体力50%)。画面外でも時計は進む。
  - 社長の言葉「現状すでに画面外だと動かないはずなので、起きても拠点は解放されない」は、**その直後の社長指示(画面外でも1/5の速さで自動進行・たどり着けば解放=v0.25.4894)で前提が変わった**。今は、自然に起きた軍人は画面外でも1/5の速さで進み直し、たどり着けば解放する。**見捨てた代償は「起きるまでの30秒、守りと射撃と進軍が止まる」こと**(品質監査QA-2 S-1・社長へ事実として報告)。
  - **倒れている間は画面外の自動進行も止める**(品質監査QA-2 A-4): `escortOffscreenStep` に「倒れている」を渡して進まない・滞在も進まない。`escortCaptures`(解放の成立)にも「倒れていない」を条件に足す。
  - **起き上がった直後は2秒の無敵**(叩き台・品質監査QA-2 S-2): 囲まれたまま起きて即また倒れる→30秒→…の繰り返しを防ぐ。
  - プレイヤーが起こせば2秒で済む(起こしに行く意味は残る)。
- 倒れた軍人が画面外にいる時は、**画面の端に印**を出して場所を教える(CA-2 項7): 既存の味方の印(輪+頭と肩の人型)を流用し、**人型を下げる**(頭が輪の下半分=伏せている)。色は**薄紅 0xfca5a5**(救助NPCの「助けて」と同じ=危険の赤 0xef4444 とは別)。明滅はハンターの印より遅く。倒れている間は**その軍人の緑の印を出さず置き換える**(重ねない)。**担当セクター外でも出す**(今の緑の印は担当の1人だけ)。
- 倒れ絵: ★**S-5「倒れ絵」**。名簿8人は大きな立ち絵(例: edgar 264×293)で、倒れ姿の絵が無い。90°回転は以前社長が却下した形(エンディングの兵士)。
  - 推薦: 8人ぶんの「しゃがみ/倒れ」の絵を変換スタジオで作る。
  - 絵が来るまで(CA-2 項1・2): **暗くしない**(暗さはこの作品では「帯の外の減光/裏回りの透け」の見え方=固まったNPCに見える)。代わりに**立ち絵の止めコマのまま足元を6〜8px沈める**+**影を短い楕円に**+**alpha をゆっくり呼吸**(0.85↔1.0・約2秒周期)。頭上の印は**救助NPCと同じ薄紅の点**をゆっくり明滅(新しい形を作らない・体力の線と2つ重ねない)。いずれも位置/影/透明度=歪みではない。

## 7. 見せ方(クリエイティブ監査CA-2 を反映)
- **頭上の体力の線**: 救助NPCと同じ **STATUS_GREEN・3px**(意味が同じ=あなたが守る人。守護霊の白と自然に別れる)。長さは立ち絵の実幅に合わせる。**被弾で出て、最後の被弾から数秒でフェードして消える**。**半分を切ったら消えない**(見張る必要がある時だけ常設)(項3・4)。
- **被弾の反応**(項8・9): ノックバック方向へ**短く大きめに滑って止まる**(位置の動き・ease-out・`clampRectToPlayableArea`)/**射撃を300ms止める**(撃つ手が止まる)/**血飛沫**(派手さの絵=判定より大きく。`spawnMeleeBlood` と同じ出し方)。白フラッシュは残すが従(血と滑りが主)。
- **音**(項10): 被弾=既存の肉のヒット音(距離減衰 `npcSfxDistGain`)/倒れる=装備ごと落ちる鈍い音/起きる=短い息か装具の金属音。**自力で起きる時は音を小さく**。新しい音は既存素材から選ぶ(無ければ社長の素材待ちとして既存の近い音)。
- **倒れる瞬間**(項16): 歩行アニメを止めコマで止める(`moving=false` と同じ経路)・影を短くする・ノックバック方向へ ease-out で滑る。
- **起き上がり**(項15・18の見た目): 沈み(+6〜8px)から ease-out で戻り、**少し行き過ぎて(−1〜2px)落ち着く**(エンディングの起き上がりと同型)。影も同じカーブで戻す。**起こされた時は通常の尺、自力で起きる時は尺2倍でゆっくり・無言・音小さく**。起き上がり後2秒の無敵の間は短い点滅。
- **台詞**(項11〜14):
  - 場面は **倒れた / 起こしてもらった / ボスの赤い予告が自分に掛かった瞬間** の3つ。(内部判定の「狙われている」は作らない=本人には見えない原因から喋らない。雑魚に追われる分は既存の「囲まれた」「後退」で足りる)
  - **倒れた瞬間は息・断片か無言**(倒れた男が自分の転倒を実況しない)。人格は「起こしてもらった」側に寄せる。**喋らない人を作る**(例: 武蔵=倒れて無言・起きて一語/フェイザー=起こされて「触るな」/ジョセフ=倒れても軽口/チェン=無線の定型が途切れる)。8人×全場面を同じ長さで埋めない。
