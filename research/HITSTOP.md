# ヒットストップの作り直し(桜井政博「8つのヒットストップ仕様」「大事なところはストップ」を参考に)

## 0. 社長の言葉(そのまま)
- 2026-11-27: 参考資料(桜井政博のゲーム作るには『8つのヒットストップ仕様』『大事なところはストップ!』)を共有。
- 比較ページ(https://claude.ai/artifact/4aqucR1JenegCyyARwRWRa)の推薦1〜8に「ヒットストップの件、推薦の通りで、さらにプレイヤーやボス倒した時にも参考のヒットストップスローはいい感じに入れて。」
- 前提(同じ日): 「攻撃時、絵が揺れてるのやめたい。きっちり動きと止まりをハッキリさせて」(=v0.25.5858 で自分の体の揺れは止めた)。

## 1. 対象と前提(事実)
- 対象: プレイヤー本人の近接4武器(ナイフ・鞭・刀・格闘)の当たり。銃・サブウェポン・爆発は対象外(サブウェポンでスローを出さない決まりは今のまま)。
- 今の止め: ナイフ・鞭・刀=当たった敵だけの止め(`impactHitStunPatch`・`meleeHitStunPatch`)+描画だけの自分の止め(v0.25.5858・武器が敵の真ん中に来た瞬間)。格闘=`brawlerStopPlan`(自分と相手の止め・技の時計ごと止まる)。画面全体の止め(`triggerHitstop`)はプレイヤー本人の近接では使わない(2026-11-14 の決め・今のまま)。
- 今の撃破演出: ボス級の撃破=白い閃光 0.32・輪2本・崩れ・長い揺れ・スロー 0.35×520ms・アテンション(`getsDeathAttention`)。プレイヤーの死亡=寄り+スロー(`PLAYER_DEATH_SLOW_MS` 820)。

## 2. 作るもの(推薦1〜8・社長「推薦の通り」)
1. **当てた敵だけ震える・自分は震えない**: 止めの間、当たった敵の**絵だけ**を震わせる。自分の体は v0.25.5858 のまま止まるだけ。
2. **絵だけ・判定は動かさない**: 震えは描画のずれだけ(store の位置・当たり箱は1pxも動かない)。
3. **地上の敵は横だけ・空中の敵は全方向**: 浮いている(`brawlerAirborne` 等の既存の浮き)敵だけ縦にも震える。
4. **幅は最初が大きく、止めの明けで0に収まる**: 幅=基準×(1−経過/止めの長さ)。震えの向きは16ms ごとに切り替える角ばった震え(正弦で滑らかにしない)。
5. **止めの長さ=ダメージ比例×技ごとの係数**: 係数の表を1か所に置く(叩き台: 1段目・軽い当たり 0.8 / 通常 1.0 / 各武器の締めの段・刀の一閃・抉り打ち 1.3 / 鞭の先端の当たり 1.6)。自分の止め(描画)と敵の止めの両方に掛ける。格闘は時計ごと止める作りなので**今回は係数を掛けない**(格闘の止めの長さは別件で社長判断待ち)。
6. **止めの間、刃先・鞭の先だけがじわっと進む**: 刀・ナイフの刃(手の武器の絵・斬撃の弧)と鞭の縄の先端だけ、止めの間に振りの時計をごく遅く(叩き台: 等速の 6%)進める。体・敵は止まったまま。止めが明けたら、止めた時刻の続きから等速で再開(進めた分は捨てる=明けで跳ばない)。格闘は対象外。
7. **画面が引いている時は震えを大きく**: 幅 ×(1 / ズーム倍率)(上限 ×2.5)。ズームは描画の今の倍率(`viewZoom`)。
8. **ボスストップ**: ボス級(`getsDeathAttention` が真になる撃破)を倒した一撃で、画面全体を短く白く光らせ(既存の閃光を強める・叩き台 0.55)、**全体の止め 300ms** → 既存のスロー(0.35)へ続ける。既存の輪・崩れ・揺れ・アテンションは消さない(止めの後に続く)。

## 3. 追加(社長「プレイヤーやボス倒した時にも…ヒットストップスローはいい感じに」)
- **プレイヤーが倒れた瞬間**: 致命の当たりの瞬間に全体の止め 220ms(叩き台)→ 既存の死亡スロー+寄りへ続ける。止めの間は当てた弾・敵の攻撃がプレイヤーにめり込んだ絵がはっきり見える(資料のファンタジーゾーン)。守護霊の死亡は今のまま(止めは足さない)。
- **ボスを倒した時**: 上の8。
- スローの規則: 止め→スローで等速へ戻す(既存の「ストップから必ずスローで等速へ戻す」と同じ)。

## 4. 入れないもの
- やられポーズへの補間(資料6): 敵の絵の多くにやられた姿勢のコマが無いので見送り。今ある「当たると白く光る」を使う。

## 5. 受け入れ条件
1. 4武器で敵に当てると、止めの間に敵の絵だけが震え、自分は震えない。敵の当たり箱・位置は変わらない(テスト)。
2. 地上の敵は横にだけ、浮いている敵は縦にも震える。震えは最初が大きく、止めの明けで0。
3. 止めの長さが技ごとに違う(係数の表・テスト)。格闘の止めの長さは変わらない。
4. 刀・ナイフ・鞭で、止めの間に刃先(鞭の先)だけがわずかに進み、明けで跳ばない。
5. ズームが引いている時ほど震えが大きい(上限あり)。
6. ボスを倒した一撃で白く光って止まり、その後に既存のスローと演出が続く。
7. プレイヤーが倒れた瞬間に止まり、その後に既存の死亡スローと寄りが続く。
8. 判定・ダメージ・押しの距離・段の間隔・カウンターは変わらない。銃・サブウェポンでは何も変わらない。

## 6. 品質監査(opus)1巡目の反映(2026-11-27・(A)7・(C)2 → 設計を直した。§2・§3 と食い違う所はこの節が正)
- **震えは既存の1本を使う**: 格闘とエアショットには止めの間の震え(`brawlerShakeUntil` の欄・pixiScene の `brawlerShakeWave`・当てた向きに沿う・残りとともに減る)が既にある。2026-11-14 の社長承認で「16ms の矩形波→正弦」に作り直された経緯があるので、**§2-4 の「角ばった震え」は撤回し、既存の正弦の波をそのまま使う**。ナイフ・鞭・刀の当たりも同じ欄を書く(二重にしない)。格闘は今の震えのまま。被弾ののけぞり(`hitFlinchPose`)は今のまま重ねる(元からある演出)。
- **震えの時計は専用の欄**(`brawlerShakeUntil` 系)。ボス級は `hitStunUntil` が書かれないので、格闘と同じくボス用の長さで震えの欄だけ書く=ボスも震える。
- **地上=横だけ/空中=全方向**: 既存の「当てた向きに沿う」を、地上の敵は向きの横成分だけ(縦は0)に、空中の敵は今のまま(当てた向き)にする。「空中」の判定は、描画で敵を持ち上げている高さ(格闘の浮き・締めの跳ね・鞭の弱浮き・鞭で投げられて飛ぶ 等、敵の絵を上へずらしている全ての高さの合計)が 2px を超えるかで決める。その合計を返す純関数を1本にする(震えの向き=見た目の判定用。格闘の当たる高さの判定は BRAWLER.md §40-4 の別の関数=用途が違う)。
- **止めの長さの係数(§2-5)**: v0.25.5858 の `MELEE_HITSTOP_STRETCH`(×1.5)を掛けた後に技の係数を掛け、会心・まとめ当ての上乗せはその後に足す。鞭の先端の当たりは既存の先端の判定(先端でボスを打った大ダメージの判定)を使う。
- **刃先のじわ進み(§2-6)を、跳ばない式に直す**: 止めの間、絵の時計は「止めた時刻+経過×6%」で進み、明けた後は「今−止めの長さ+止めの長さ×6%」(=進んだ所から続け、止めの残りがその分短くなる)。じわ進みするのは**斬撃の弧と鞭の縄の先**だけ。ナイフの手の刃は拳と一緒に止める(拳から離さない)。画面全体の止め(`hitstopFreezeNow`)の間は何も進まない(全体の止めが勝つ)。
- **ズーム(§2-7)**: シミュの `viewZoom` ではなく、描画の実際の倍率を、その端末の基準の倍率で割った値を使う。引いている時(<1)だけ震えを大きくする(×1/倍率・上限×2.5)。寄っている時は小さくしない(×1)。スマホの基準の寸法で結果が変わらないことをテストで固定する(PC の横長でも同じ式)。
- **ボスを倒した時(§2-8 を直す)**: ボス級の撃破には既にアテンション(時間停止+寄り・約5秒)と、近接のとどめなら `startKillFxCinematic`(止め+スロー)がある。**新しい止めは足さない**。代わりに次の3つ。
  1. 撃破の一撃の瞬間に、アテンションのカメラの寄りが動き出すのを 250ms 遅らせる(その間は画面もカメラも止まったまま=ボスストップの「ビタッ」)。白い閃光を強める(0.32→0.55)。
  2. 既存のスロー(0.35×520)がアテンションの止めの中で使い切られて見えていないので、止めが明けた時に始まるよう、`startKillFxCinematic` と同じ型(スローの長さ=止め+戻り・保持=止めの長さ)で張り直す。
  3. `startKillFxCinematic` が `hitstopUntil` を短い方で上書きしうるのを、長い方を採るよう直す(アテンションの止めを縮めない)。
  - 武器を問わない(ボスの撃破という出来事の演出。今のアテンションも武器を問わない)。サブウェポンでスローを出さない決まりは「サブウェポンの発動そのもの」の話なので、撃破の演出は対象外(今と同じ)。
- **プレイヤーが倒れた時(§3 を直す)**: 致命の当たりには既に止め(`damagePlayer` の `stopUntilNext`・段で 70/120/190ms)があり、死亡演出(寄り・スロー・結果画面への期限)はその止めが明けてからループが進んで始まる=もう「止め→スロー」の順になっている。**致命の当たりの止めを 240ms 以上にする**(長い方を採る)。継続ダメージ(止めが無い)で倒れた時も 240ms の止めを張る。死亡演出の各期限は止めの後から数える(今の順番のまま=削られない)ことをテストで確かめる。§1 の「`PLAYER_DEATH_SLOW_MS` 820」は誤り(実際は `DEATH_ZOOM_MS`=1700)。
- **受け入れ条件8を直す**: 「銃・サブウェポンでは何も変わらない」は近接の止めと震えの話。ボス撃破とプレイヤーの死亡の止めは、武器を問わない。

## 7. 格闘の決め技は止めを長く(KOF 参考)(社長指示2026-11-27)
- 社長の言葉: (追加)「空中投げ、スープレックスもか」
- 社長の言葉: 「格闘のヒットストップは、技によって長めに置いてもいいと思う。KOFを参考に。例えば、秘奥義の最後のヒットは長めとか、抉り打ちは長めに大きめに揺らすとか、地割れ、踵落とし、蹴り飛ばし、通常技5段目とか」
- 全部の格闘の止めを伸ばすと、つながり・秘奥義の入力・ハメ防止が崩れる(v0.25.5858 の調べ)。**決め技だけ**伸ばす。軽い段・つなぎの技(1〜4段・飛び蹴り1/2発目・蹴り上げ・気功・構え)は今のまま。
- 叩き台(今の止め × 係数。自分と相手の止め・相手の震えの長さに掛ける):
| 技 | 止め | 震え |
|---|---|---|
| 秘奥義の最後の当たり | ×2.0 | ×1.5 |
| 抉り打ち | ×1.8 | 幅 ×1.6(大きく) |
| 地割り(土竜を含む) | ×1.5 | ×1.2 |
| 踵落とし | ×1.5 | ×1.2 |
| 蹴り飛ばし(飛び蹴り3発目) | ×1.6 | ×1.3 |
| 通常5段目(掌底の突進) | ×1.6 | ×1.3 |
| 空中投げ(叩きつけ・爆撃の当たり) | ×1.6 | ×1.3 |
| スープレックス(密着・空中投げの続き・叩きつけの当たり) | ×1.6 | ×1.3 |
- 決め技の止めが伸びた分、その後の取り消しの受付(地割り→飛び蹴り/気功・踵落とし→地割り 等)は止めが明けてから数える(今の作りどおり=受付が削られない)ことをテストで確かめる。秘奥義の先行入力・ハメ防止(強個体の固まりが8発で切れる)は、軽い段が変わらないので崩れない見込み=既存テストで確かめる。
