# 熟練度(武器・サブウェポン)とステージ3以降の強化 設計 v1(2026-11-11)

## ゴール(社長の言葉のまま)
- 「ステージ３以降の敵の強さをもっと上げる。その代わり、武器とサブウェポンに熟練度を実装。それぞれ１０段階まで上がり、
  敵が強くなった分の差を埋めるくらいの強化度にする。熟練度は使うと上がっていく。」
- 「目的はプレイ時間を伸ばす、ステージを繰り返し遊ぶ意味を作る、成長を実感させる、です。なのでボスも強くします」
- 「熟練度設定しづらいサブウェポンとかは無理やりやらなくていいよ。最初からMAXで。(ff7のマテリアとかもそうで有る様に)」
- 「ちなみに、いまのプレイ中のレベル段階も残るので、それも考慮しといてね」

## 「ではない」条件
- 出撃の中のレベル(武器のTier・サブウェポンLv1〜3・レベルアップのカード)を置き換える物ではない。今のまま残し、熟練度はその上に掛ける別の層。
- 武器ごとの個性(連射・範囲・弾数)を伸ばす物ではない。**その武器のダメージだけ**が上がる。
- 敵の攻撃力を上げる話ではない(熟練度は受けるダメージを減らせない=埋められない)。上げるのは体力だけ。
- ゴールドで買う物ではない(永続育成「強化」とは別。使えば上がる)。
- ステージ1・2 の強さは変えない。

## 1. 熟練度の単位(何ごとに育つか)
| 区分 | 単位 | 数 | 理由 |
|---|---|---|---|
| 銃 | **種類(category)ごと**: ハンドガン / ショットガン / ライフル / グレネードランチャー / PHILLガン | 5 | 出撃の中で銃のキー(`handgun-t1` 等・全36)は拾い物で入れ替わる。キーごとだと育てた物が出撃の途中で消える |
| 近接 | **近接武器で1つ**(ナイフ・手斧・マチェット…は出撃の中でTierが上がって入れ替わる) | 1 | 同上。職業で固定の系統が1本ずつ |
| サブウェポン | **キーごと**(下の表の「育つ」だけ) | 19 | サブウェポンは選んで持ち込む物=育てる対象として一番分かりやすい |

### サブウェポンの線引き(「育つ」=ダメージを出す / 「最初から最大」=付けにくい)
| 育つ(19) | 最初から最大(8) |
|---|---|
| 手榴弾 `heavy-grenade` / ドッグ `dog` / 刀 `katana`(小烏丸 `murasame` は刀と同じ熟練度を使う)/ 鞭 `whip` / 錬金術 `alchemy` / 自動タレット `turret` / 発火ナイフ `fire-knife` / ドローンブーメラン `drone-boomerang` / ワイヤーアンカー `wire-anchor` / ホーミング弾 `homing` / 分身 `shadow-clone` / 火炎瓶 `molotov` / センサー地雷 `sensor-mine` / 援護射撃 `support-sniper` / ジャンクウェポン `junk-weapon` / 金環 `gold-ring` / 矢の雨 `arrow-rain` / 格闘 `brawler` / デコイ `decoy`(時間切れの爆発) | トラップ `marksman-trap` / クイックマガジン `striker-quick-mag` / ハンティング `striker-hunting` / シールド `shield` / 賢者の石 `sage-stone` / 救急鞄 `first-aid-kit` / フレアガン `flare-gun` / (退役)ダンスフロア `shijin` |

- 賢者の石は鞭の竜巻を強める物=鞭の熟練度が竜巻に掛かる(賢者の石そのものは育たない)。

## 2. 何で上がるか
- **その武器で敵に与えたダメージの合計**(出撃をまたいで積む)。倒した数・時間ではない。
- 積むのは「熟練度の倍率を掛ける**前**の値」(育つほど速く育つ雪だるまにしない)。敵の残り体力を超えた分(やり過ぎ)は数えない所まではやらない(今の与ダメの集計と同じ数え方でよい)。
- 計測の道(ボスメーカー・ボス連戦の部屋)と練習ランでは積まない(練習ランは保存の書き込みが元から止まる)。
- 守護霊・幻影・軍人(護衛)の与ダメは積まない(プレイヤー本人の当たりだけ)。

### 段階と必要量
- Lv1(はじめ)〜Lv10。Lv n → n+1 に要る量 = `MASTERY_BASE × MASTERY_GROWTH^(n−1)`(`MASTERY_GROWTH` = 1.5・後半ほど上がりにくい)。
- **`MASTERY_BASE` は実測してから決める(★未決 #1「必要量の基準」)**。狙い: その武器を主に使って、Lv2 まで1出撃・Lv5 まで約6出撃・Lv10 まで約40出撃。
  1出撃で1つの武器が出す与ダメの実測(ボットラン1回の `damageDealt` を銃/近接/その他で見る)が要る。

## 3. 上がると何が強くなるか
- その武器・サブウェポンのダメージに倍率: **Lv1 = ×1.0、1段ごとに +0.1、Lv10 = ×1.9**(`masteryDamageMult(level)`)。
- 出撃の中のレベルとの関係: 掛け算で重なる(Tier・サブLv・カードの倍率 × 熟練度)。出撃の中のレベルによる伸びは今の強さの釣り合いに既に入っているので、
  敵の上乗せは熟練度の倍率だけに合わせる(§4)。
- **効くのは次の出撃から**(出撃の開始時に、その時点の段階を倍率にして player へ焼く。永続育成と同じ作法)。出撃の途中で段階が上がっても、その出撃の間の倍率は変えない。
  上がった事は出撃の中で知らせる(§6)。

## 4. 敵とボスの強化(体力だけ)
`src/config/stageDifficulty.ts` の `STAGE_HP_MULT` を書き換える(攻撃 `STAGE_DMG_MULT` は今のまま)。
| ステージ | 今の体力倍率 | 熟練度の上乗せ | 新しい体力倍率 | ちょうど埋まる熟練度 |
|---|---|---|---|---|
| 3 | 1.2 | ×1.3 | **1.56** | Lv4 |
| 4 | 1.4 | ×1.5 | **2.10** | Lv6 |
| 5 | 1.6 | ×1.7 | **2.72** | Lv8 |
| 6 | 1.8 | ×1.9 | **3.42** | Lv10 |
- この台帳を読む敵は全部同じだけ強くなる=**雑魚・城ボス・賞金首・ゲート2の天使・裏ボス・偶像・変異体(初回と2回目の体力)**(今ステージの係数が掛かっている物・走査で確認済み)。
- 事実(台帳に乗っていない物=今回は変わらない): 死神・使者、幻影(守護霊のボス)、英雄・解放群の旗手、研究所の敵。
- **ステージ7(ラスボス)は階段の外**(2026-08-20 の裁定「2と7は固定値でいい」・体力は `bossHealth.ts` の固定 12000)。
  現時点の推薦: 7 にも 6 と同じ上乗せ(×1.9 → 22800)を掛ける。掛けないと、熟練度10 のプレイヤーにはラスボスだけ半分の硬さになる。**★未決 #2「ステージ7の上乗せ」**。
- スコアと換金の倍率(`stageScoreMult`)は今 `STAGE_HP_MULT` をそのまま流用している。体力倍率を上げると、スコアと換金も同じだけ増える(ステージ6 = ×1.8 → ×3.42)。
  現時点の推薦: 流用をやめ、スコア用の倍率は今の値(1.2/1.4/1.6/1.8)を別の表に写して据え置く(経済を動かさない)。**★未決 #3「スコアと換金の倍率」**。

## 5. 実装の形
### 5-1. データと純関数(依存の無い葉)
- `src/data/mastery.ts`: 熟練度のキー(`MasteryKey` = 銃5 + `'melee'` + サブ19)・「最初から最大」の一覧・サブウェポンのキー → 熟練度のキーの対応(`murasame` → `katana`)・定数。
- `src/utils/mastery.ts`: `masteryLevelFor(xp)`・`masteryProgress(xp)`(今の段階・次までの割合)・`masteryDamageMult(level)`・
  保存(キー `zombie.progress.mastery`・`normalizeMastery`/`loadMastery`/`saveMastery` の3点組=`utils/playerUpgrades.ts` と同じ作法)。
- 進行の全リセット(開発用)の `removeItem` の列に足す。

### 5-2. 焼き込み(出撃の開始)
- `resetGame` が、保存から各キーの段階を読み、倍率の表 `player.masteryMult: Partial<Record<MasteryKey, number>>` を player へ写す(無い欄 = 1)。
- 計測の道(ボスメーカー・ボス連戦)は全部 1(永続育成が 0 段で焼かれるのと同じ判断の所)。
- 守護霊・幻影の記録(`playerBuild.ts` の記録と復元の2か所)にも同じ表を対で持たせる(`growthAtkMult` と同じ扱い)。旧い記録(欄が無い)は全部 1。

### 5-3. 倍率を掛ける所
読み口は1本 `masteryMultOf(player, key)`(無ければ 1)。
- **銃**: 撃つ時の素ダメ `gunShotBaseDamage`(`weaponUtils.ts`)に `weapon.category` で掛ける。銃の別経路(`newGunsTick.ts` の銃ダメ・ガンブレードの近接・`playtestDriver`)にも同じ読み口で掛ける。
  カウンターの反撃(`counterReplyDamage`=銃の威力を元にした確定会心)には、その時の銃の種類で掛ける。
- **近接**: `meleeSwingBaseDamage` に `'melee'` で掛ける(気絶中の処刑枠・ボスへの5倍にも波及する=永続育成の攻撃力と同じ「素ダメへの前掛け」)。
  **格闘(`brawler`)を装備している時の近接の当たりは、`'melee'` ではなく `'brawler'` の熟練度**を使う(格闘は近接を置き換えるサブウェポン。気功も `'brawler'`)。
  刀・鞭の当たりは `'katana'`・`'whip'`(近接の熟練度は掛けない)。ワイヤーアンカーは `'wire-anchor'`。
- **サブウェポン**: 各サブのダメージを決めている所(走査の表の約20か所。`skillOutgoingDamageMult(player)` を掛けている式の隣)に、そのサブのキーで掛ける。
  弾として飛ぶ4種(タレット・ジャンク・ホーミング・援護射撃)は、弾を作る時の威力に掛ける。
  ★援護射撃の弾は `weaponKey` が本人のライフルと同じ値になっている=弾に `masteryKey` の欄を足して見分ける(§5-4)。
- 二重に掛けない: 1つの当たりに掛かる熟練度は1つだけ(例: 鞭の竜巻=鞭だけ。ホーミングの着弾の爆発=ホーミングだけ)。

### 5-4. 積む所(与ダメの記録)
- 出撃の間は、モジュールの中の表 `runMasteryXp: Record<MasteryKey, number>` に足すだけ(store の状態にしない=毎フレームの set を増やさない)。
- 足す所は倍率を掛ける所と対: 「当たりのダメージが決まって、敵の体力を減らす所」で `noteMasteryDamage(key, 熟練度を掛ける前の量)`。
  - 銃弾: 命中の所(`useGameLoop` の弾の当たり)で、弾の `masteryKey`(無ければ `weaponKey` から銃の種類)を見る。
  - 近接・刀・鞭・分身: `recordDamageDealt` を呼んでいる所の隣。
  - `damageEnemy` を通るサブ: 呼ぶ所の隣(`damageEnemy` に引数は足さない=引数がもう12個ある)。
- 保存へ流すのは「出撃の終わり(リザルトへ入る時)」と「一時停止した時」。流した分は表から引く。出撃し直し(`resetGame`)の時に残りがあれば流してから空にする。
- 段階が上がったかは、流す時ではなく、出撃の間に `保存済み + 表` で見る(§6 の知らせのため)。

### 5-5. 性能
負荷 1/10。当たりごとに表へ足し算1回と、倍率の表の引き1回。保存は出撃の終わりと一時停止だけ。React の購読は増やさない(HUD の知らせは既にある「通信の下の行」に1行積むだけ)。

## 8. 受け入れ条件(バッチA)
1. 全部の熟練度が Lv1 の時、ステージ1・2 の与ダメは今と1も変わらない(倍率 1・テストで固定)。
2. `masteryDamageMult`: Lv1=1.0・Lv10=1.9・間は 0.1 刻み。範囲の外は丸める。
3. 必要量: 段階は xp に対して単調。保存が壊れていても落ちない(正規化)。
4. 銃: ハンドガンの熟練度を上げてもショットガンのダメージは変わらない(種類ごと)。出撃の中で銃を拾い替えても、種類が同じなら同じ熟練度。
5. 格闘を装備中の近接の当たりは `'brawler'` に積まれ、`'melee'` には積まれない。刀・鞭も同じく自分のキーだけ。
6. 「最初から最大」のサブウェポンと退役のキーには積まれない・倍率も掛からない。
7. 計測の道・練習ランでは、倍率は 1・保存は増えない。
8. 守護霊・幻影・護衛の与ダメは積まれない。
9. 出撃の途中で段階が上がっても、その出撃の倍率は変わらない。次の出撃で上がる。
10. `STAGE_HP_MULT` = 3:1.56 / 4:2.10 / 5:2.72 / 6:3.42。`STAGE_DMG_MULT` は今のまま。台帳を読む全部の敵に効く(雑魚・ボスの各入口のテストの期待値を更新)。
11. 憲法テスト・既存のテストが通る(期待値の更新を除く)。

## 設計者が直す所(仕様は変わらない・穴の埋め)
1. **掛ける所と積む所の表を設計書に載せる**(監査 C-1)。`damageEnemy` を呼ぶ所は `useGameLoop` 32・`gameStore` 25、ほかに体力を直接減らす所(近接・刀・鞭・分身)。
   1か所ずつ「どの熟練度のキーか/付かない当たりか」を書いた表を作ってから発注する(走査を1回まわす)。
2. **関数の中で掛けない**(A-7・A-8・A-9)。`gunShotBaseDamage` は銃の種類を受け取らない呼び口がある(錬金の石の起爆・塊銃・衛星弾)。`meleeSwingBaseDamage` は格闘・気功・分身・
   ドローンブーメラン・スラッシャー追撃・スケボー・守護霊の処刑・シールドバッシュも使う=中で掛けると漏れと二重掛けが出る。共通の光線の口 `applyBeamPulse` は金環と光線の銃が同じ口。
   ⇒ 熟練度のキーは**呼び口が引数で渡す**。
3. **積む量は「実際に通った量」**(A-11)。`damageEnemy` は無効の当たり(空中の無敵・死体・すり抜け・幻影のガード)で早く戻り、通った当たりも中で増減する。
   `damageEnemy` が通った量を返す形にして、それを(熟練度の倍率で割り戻して)積む。割り戻しの丸めは「割ってから四捨五入・0 未満にしない」。
4. **積まない出撃を積む側で止める**(A-12・A-18): 練習ラン・ボスメーカー・ボス連戦・ボット・チュートリアル。書き込みの関所任せにしない(次の出撃の頭で流れてしまう)。ボットは倍率も 1。
5. **練習ランの倍率は本番と同じ**(A-13。永続育成が「通常の練習は乗る」なのと揃える。1 にすると練習のボスだけ本番より硬い)。倍率 1 は計測の道(ボスメーカー・ボス連戦)とボットだけ。受け入れ条件7を直す。
6. **守護霊・幻影の疑似プレイヤーは `masteryMult` を明示して上書きする**(A-14)。記録に無ければ全部 1(本人の今の値を引き継がせない)。記録の値は読む時に 1〜1.9 へ丸める(オンラインの記録)。
7. **保存の機会を足す**(A-15): 画面が裏へ回った時(`visibilitychange`・`pagehide`)にも流す。スマホで裏へ回して落とされると1出撃ぶんが消えるため。
8. **「この出撃で伸びた分」**(A-16): 出撃の開始時に保存の写し(ディープコピー)を取っておき、リザルトはそれとの差を出す。
9. **錬金術の線引き**(A-10): 銃の `glauncher-t2-alchemy` の弾と起爆=グレネードランチャーの熟練度。サブの `alchemy`(召喚の接触)=錬金術の熟練度。
10. **必要量の伸びの数字**(A-3): 「Lv10 まで約40出撃」を正にする=伸び率は 1.37 前後(1.5 だと約75出撃)。必要量は**単位ごとに決める**(A-2。与ダメが桁違いのサブがある=デコイ・ワイヤーアンカー・金環は少なく、タレット・ドッグは多い)。
    測り方は「その単位を主に使った1出撃の、通った与ダメ」を単位ごとに取る(今の集計は 銃/近接/その他 の3つしか無く、光線の銃は「その他」に入る=使えない。単位ごとの集計を先に入れてから測る)。
11. **後のステージほど速く育つのは意図**(A-4。体力が多いぶん与ダメが増える=繰り返し遊ぶ意味)。必要量の基準はステージ1の出撃で測る、と決める。
12. **事実の訂正**(A-6): 体力が上がり熟練度が付くと、与ダメの点(`damageScore = 与ダメ × 0.25`)は自然に増える=「経済を動かさない」は誤り。動かさないのはステージの倍率だけ。
