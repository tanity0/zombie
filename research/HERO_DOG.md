# 英雄の犬(スキル「英雄」の相棒)— 設計 v1(2026-10-15)

## 0. 社長のゴール(言葉のまま)
> 英雄のスキルに、犬が常時ついてくるようになり、近くの敵に噛みつき、敵のヘイトを取る(体力は100固定)ようになる。を追加。
> 死ぬと消えるが、10秒後に自動復活。これもHP満タン時のみ。

## 1. 何であるか / 何ではないか
- 犬は**ヘイト役(囮)**。火力役ではない(噛みの威力は小さい)。
- **ボスのヘイト系(プレイヤー/守護霊/軍人の3択バケツ)には手を入れない**=ボスの技の狙い先に犬は入らない(別件)。
  雑魚・強個体(`resolveEnemyTarget` を通る敵)が対象。
- 新規素材(絵・SE)は作らない。既存の犬の絵(`dog-walk-0/1`=ドッグの拾い物往復と同じ犬)を使う。
- HUD/UI の追加なし。犬の成長・強化なし。

## 2. 実体
- `Summon` の新 kind `'hero-dog'`(錬金術召喚と同じ配列 `summons`)。追従・接触噛み・被弾・影・描画の受け口を流用する。
- HP **100 固定**(`maxHealth=100`・レベル/強化/難易度で変えない)。
- 当たり判定 30×22。速度 `PLAYER_BASE_SPEED×1.25`(≒109px/s・主人の足に付いて行け、敵に追いつける)。
- 噛み: 間合い 44px(`ALCHEMY_ATTACK_RANGE`)・間隔 600ms(`ALCHEMY_ATTACK_INTERVAL_MS`)・威力 **8(仮値・実機で絞る)**。
  与ダメは `damageEnemy(..., 'dot', 'neutral')`(揺らさない・ボスのヘイトに積まない)。

## 3. 居る/居ない(「HP満タン時のみ」)
| 状態 | 何が起きるか |
|---|---|
| `skillHeroActive(player)`(スキル「英雄」所持 かつ HP満タン)で、犬が居ない かつ 復活待ちでない | **主人の足元に現れる**(下から浮き上がりながら濃くなる=既存の召喚の出方) |
| HP が満タンでなくなった | **犬は去る**(沈みながら薄れる 600ms=既存の召喚の消え方。去っている間は噛まない・当たらない)。復活タイマーは積まない |
| HP が満タンに戻った | **すぐ戻る**(死んでいなければ) |
| 犬の HP が 0 | **消える**(血のバースト+砂埃)。`heroDogRespawnAt = gameTime + 10000`。満タン中なら10秒後に主人の足元へ |
| ステージ終了/リセット | `summons` ごと消える・タイマーも消える |
- 時計は `gameTime`(ポーズ中は進まない)。
- 毎フレーム1本の純関数 `heroDogPresence({heroActive, hasDog, dogLeaving, respawnAt, gameTime})` → `'spawn'|'leave'|'keep'|'none'` で決める(テスト対象)。

## 4. 犬の意思決定(毎フレーム・`updateSummons` の hero-dog 分岐)
1. **狙い**: 主人から `HERO_DOG_HUNT_RANGE=300px` 以内で最寄りの噛める敵(死体・死神・昇天中・英雄(中立)は除く)。
2. **綱**: 犬は主人から `HERO_DOG_LEASH=380px` より離れない(狙いがそれより先なら追わず戻る)。
3. **狙いあり**: 敵の中心へ向かい、44px 以内で噛む(600ms ごと)。噛んでいる間は敵の方を向く。
4. **狙いなし**: **横に付く**=主人の向きの背中側(x−48・y+14)が定位置。定位置から 22px 内で止まり、50px 離れるまで動かない(不感帯)。現れてから一度定位置に着くまでは狩りに出ない。
5. **慣性(MUST)**: 速度 `vx,vy` を目標速度へ毎フレーム寄せる(蹴り出し 0.15s / 減速 0.35s=非対称・§11)。止まる時も滑って止まる。
6. 木・障害物: `resolveTreeCollision`(召喚と同じ)。
- 純関数 `stepHeroDog(dog, playerCenter, enemies, dt)` → `{x,y,vx,vy,biteTargetId?}`(テスト対象)。

## 5. ヘイト(「敵のヘイトを取る」)
- (a) **噛まれた雑魚・強個体は 5 秒間、犬を追う**(`enemy.dogHateUntil`。守護霊の `ghostHateUntil` と同じ型のハードラッチ。噛まれるたび更新。犬が居なくなれば通常規則へ)。★除外は `isTrueBossType`(本物のボス)だけ。`isBossType` は強個体を含むので使わない。
- (b) 犬は**雑魚の既定の最寄り候補**に入る(錬金術の通常召喚と同じ=気づく距離 380px 内でプレイヤーより近ければ犬へ向く)。
- (c) ボス: 対象外(§1)。
- 置き場所: `resolveEnemyTarget`(enemyUtils.ts)。射手(combatTick)も同じ関数で狙うので、犬を狙う雑魚は犬へ撃つ(**ただし敵弾は召喚に当たらない=今の錬金術召喚と同じ**。犬は接触でだけ傷つく)。

## 6. 犬が受けるもの
- 敵の接触(`checkEnemySummonCollisions` に `'hero-dog'` を足す)。威力=その敵の `damage`。被弾後 1 秒無敵(`INVULN_MS`・他の召喚と同じ)。
- **敵弾は当たる**(§11 A-2・プレイヤー/英雄の解決の後に残った弾)。ボスの技(非接触)・床・雑魚の技(噛みつき/振り)は当たらない(接触でだけ傷つく)。

## 7. 見た目(drawSummon の hero-dog 分岐)
- 絵 `dog-walk-0/1`。動いている間は 2 コマを進んだ距離で刻む(時計で刻むと足が滑る)、止まったら 0 コマ目。向きは動いた向き・噛む間は敵の方。
- 色は**素のまま**(金色 tint は「敵の絵の流用」を見分けるための文法。犬は味方にしか居ない絵なので要らない)。不透明。
- 影: 既存の召喚の影パス(`summonFootBox`)。`summonFootBox` に hero-dog の足元箱(絵 96×72 を幅 36 に収める)を足す。
- 頭上に小さな HP バー(傷ついている時だけ・召喚と同じ)。被弾フラッシュ/横揺れも同じ。
- 出入り: 出る=浮き上がり+濃くなる(360ms)/ 去る=沈み+薄れる(600ms)。死=血のバースト+砂埃(分類②=派手側)。
- SE: 犬の鳴き声素材は無い → 無し(新規素材は作らない)。

## 8. 文言
- `SKILLS['hero'].desc`: 「体力が満タンの間、移動速度とダメージが30%上がり、犬が付き従って近くの敵に噛みつき注意を引く。代わりに受けるダメージも30%増える」

## 11. 監査反映(v1.1・2026-10-15・着手前の品質監査A-1〜A-6+クリエイティブ監査の「直せる」分)
**品質監査(A)**
- A-1 速度: 固定109では英雄発動中の主人(124〜136px/s)に置いて行かれる → **主人の実効速度×1.15**(`heroDogSpeedFor`・下限109・上限196=スケボーには追いつかない)。
- A-2 敵弾: 犬を狙った射手の弾が犬を素通りして主人へ飛ぶ → **敵弾は犬に当たる**(`combatTick.applyEnemyProjectileHits`。プレイヤー/英雄の解決の後に残った弾。手榴弾は信管のみ)。
- A-3 帯: `clampRectToPlayableArea`(`shieldPlayableCtx`)を木の解決の後に通す。現れる位置も同じく帯の中へ。
- A-4 使役ペット: `persistent` は付けない(警察署の使役判定を潰さない)。錬金術の FIFO/レア入替は `kind==='hero-dog'` を保持。
- A-5 錬金術の召喚攻撃ボーナス(+20%/体)に犬は数えない。
- A-6 自由の女神持ちの英雄(mutant-liberty)も噛まない(`isBodyWallBoss`)。
- B-2 狙う300/手放し380のヒステリシス(噛み始めた相手 `biteTargetId` は綱の内に居る限り変えない=標的のちらつき防止)。
- B-3 優先順: 英雄の誘い → 守護霊ラッチ → **犬ラッチ** → ボスのヘイト → 距離規則(犬は錬金術召喚と同じ候補)。
- C-4 噛まれた敵が犬を追う時間は守護霊と同じ **5秒**。
- 時計: 復活=gameTime / 去りの薄れ(expiresAt)=Date.now(召喚の寿命欄の流用。ポーズ中も進むが0.7秒なので許容)。
**クリエイティブ監査(直せる分)**
- 現れ方: 地面から湧かない。主人から260px(最寄りの敵と反対側)から**走り込んで横に付く**。
- 去り方: 沈まない。**主人から離れる向きへ走り去りながら薄れる**(0.7秒)。去りかけに満タンへ戻れば向き直って戻る(透明度は寄せる)。
- 死: 血+砂埃に加えて**横倒しの倒れ絵**(`dog-walk-1` を源と反対へ90°・0.7秒保持→0.9秒で薄れる。描画専用の控え `heroDogDeathPose`)。
- 止まっている時のコマは脚が揃う `dog-walk-1`(0コマ目は疾走の脚)。停止中は速い呼吸の上下。
- 噛み: **跳び付き**(噛む瞬間に敵の方へ速度の衝撃→滑って戻る)+ドッグと同じ灰色の飛沫。
- 加速0.15秒/減速0.35秒(非対称)。足元の不感帯(70で止まり95まで動かない)。
- 被弾: ひるんで源と反対へ14px跳び退く(横揺れではなく位置の移動)。
- 文言: 「体力が満タンの間、移動速度とダメージが30%上がる。代わりに受けるダメージも30%増える。満タンの間は犬が一匹ついてきて、近くの敵に噛みついて引きつける。倒れても、しばらくすると戻ってくる」
**社長判断へ(未反映)**: ①ドッグ(拾い物)の犬と同じ絵=犬が2匹に見える(大きさ/色味で差を付けるか・ドッグの往復も英雄の犬がやるか) ②噛みにノックバックを付けるか ③去る時に噛み切ってから/点滅止めの最短時間 ④SE(吠え・キャン)の支給 ⑤ヘイトが取れたことの印(頭上の!) ⑥ボスのヘイト系への組み込み(別件)。
**(B)別案件へ**: 戻った瞬間の通知(カチッ+頭上マーク)/ 足元でのうろつき / ラボで見つかる前に犬が先に噛む可能性 / 倒れ絵のヘッドレス確認(sprite は可視・寸法正常だが画素が出ない。実機で確認)。

## 12. 検収反映(v1.2・2026-10-15・社長指示「イヌが出てる時、拾うだけの犬が出ないようにして」+検収監査)

  着いたら(26px)回収、安全網3秒。回収から0.4秒でCD開始(CDの式は従来どおり)。**犬が居ない間(倒れて復活待ち・去っている)は通常のドッグ効果**。代行の途中で犬が倒れた/去ったら、その場で通常のドッグ(拾うだけの犬)に引き継ぐ=主人の所から改めて往復(社長指示2026-10-15「英雄犬が倒れた時は通常のドッグ効果」)。幻影のドッグは従来どおり。
- 検収品質監査 A-1: 強個体・ハンターのヘイト(`isTrueBossType` に修正)。A-2: 透明度メモを個体ごと・時間基準に。B-4: 出現位置も木の解決を通す。
  (B)別案件: 犬の撃破を連続撃破の段に数えるか(社長判断)/ 0ダメージ時の数字(数字自体を出さなくした)/ 大きい敵の中へ入って噛む(ボスは対象外)/
  叫喚型の強化倍率を敵弾→犬に掛けていない / `resolveEnemyTarget` を通らないボス tick は犬を見ない(守護霊と同じ既知の穴)。
- 検収クリエイティブ監査(直せる分を反映): 横に付く定位置(背中側)/ 止まったら主人の方を向く / 湧きの浮き上がり撤去(走り込みのみ・120msで濃くなる)/
  現れたら一度横に着いてから狩り / 噛みは「跳んで→届いてから噛む→跳ね戻る」/ 歩幅26px(1周≒体長)・背の上下3px / 去る向き=最寄りの敵と反対 /
  ひるみ26px / 倒れ絵は足元Yソート・色は素のまま・1.6秒保持+1.2秒 / 噛みの飛沫は敵の血の色・数字は出さない / 敵弾の血9粒 / スキル説明を1文に畳む。
