# 全技 モーション予兆 台帳(走査専用・調査結果)

**この文書はコード変更を一切伴わない走査結果のメモ。実装判断・仕様変更はしていない。**

## 0. 社長指示の要約(背景)

- 全ての技は予兆を必ず必要とする。今は**赤いテレグラフ(予告ライン/円/帯)**がその役割を担っているが、
  **ヴィジュアル(本体や弾のモーション)でも必ず予兆を入れたい**。
  - 例: 骨刃・氷刃なら、次に飛んでくる刃が前もって震えながら少し後ずさる。
  - 例: 剣ならゆっくり振りかぶる。
  - 例: 突進なら震えながら後ずさる。
  - ジャンプは既にしゃがみがあるのでOK(実装済みという前提)。
- **銃弾(通常の敵弾)は対象外** — ただしこれは**「ポツポツ撃ち」(自動射撃・enemy_bolt の平常発射)だけ**
  の話であり、**銃を使う「技」(三連射・狙い撃ちバースト・全方位発射・レーザー系など)は予兆の対象**
  (社長追加指示・本走査中に着弾)。
- 予兆に新素材が必要なら用意する。
- **例外候補**: 連続技の2〜3撃目(剣振りコンボの後段など)は、初段の予兆がコンボ全体の合図になっていれば
  段ごとの予兆は不要かもしれない → 台帳では「例外候補」の印を付けて裁定に回す(採否は社長)。
- **予兆の語彙(社長指示で追加)**: しゃがみ / 縦縮み / 震え+後ずさり / 振りかぶり / **構え**
  (構えの例: 銃の技なら「一度銃を出してガチャっと構える(SE付き)」)。提案欄はこの5語彙から選ぶ。

(モーション列は**本体・武器スプライトの動き**のみを指す)。

## 3. ★要確認・判断に迷った箇所(勝手に決めていない)

1. ラフィ「bone」(骨刃設置)の windup 中モーション有無 — 個別描画ブロックを特定できず。
2. ラフィ jump-attack / トール jump-windup・jump-attack に**専用の本体squash(しゃがみ/縦伸び)が
   実装されているか** — pumpkin系squashブロックの対象型リストに rafi/thor が含まれていない可能性が高い
   (=汎用ジャンプ演出止まりで専用しゃがみは無いかもしれない)。要コード再確認。
3. ウリ downslash・thrust の windup 中の構えモーション有無(`drawKatanaReady`系を共有している可能性は
   高いが、個別呼び出し箇所を全て辿り切れていない)。
4. 城ボスg-*の一部(g-sweep, g-dash, g-slam, g-glide, g-quad, g-quad-breath, g-boon, g-tailslam)の
   windup 中モーションの有無 — 描画量が膨大でこの走査では全ブロックを読み切れていない。
5. **ゾンビ(zombie)のzpause→zrush(停止→2倍速突進)を「予兆が要る特殊攻撃」に含めるか** —
   赤テレグラフ自体が現状なく、雑魚の中でも最普及種のため、対象に含めるなら影響範囲が大きい。
6. **叫喚(screamer)の「叫び」を対象に含めるか** — プレイヤーへの直接ダメージ技ではなく周囲の雑魚を
   強化するバフのため、「攻撃技」の定義に入るかどうかは社長裁定が必要(現状は拡大リングの赤予告のみ)。
7. g-talon(爪3拍)・g-nihil(3段詠唱)・g-trijump(3連跳)を「例外候補」に挙げたが、社長の例外規定
   (「連続技の2〜3撃目」)に厳密に当てはまるかは要裁定 — これらは1回のwindupから連続して発生する
   「1つの技の中の複数拍」であり、「複数の別技が連鎖するコンボ」とは性質がやや異なる可能性がある。
