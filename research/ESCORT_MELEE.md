# 進軍NPCの近接(ナイフ)

社長の言葉(2026-10-11): 「**進軍NPC8体も近接攻撃する様にできる？ 装備はtiar1のナイフ 近接中は、銃を撃たない**」→ 推薦どおりで「はい」。

## 1. 何を作るか
- 進軍NPC(名簿8人・1出撃4人=`state.escorts`)が、敵が近接の間合いまで来たら**銃を止めてナイフで斬る**。間合いから敵が消えたら銃へ戻る。
- 対象: 通常の拠点ルートと洋館通路ルートの両方(射撃の2か所)。**M0の随行2人(台本で動く)には付けない**。
- 倒れている間・被弾の滑りの間(busy)・撃つ手が止まる直後(`fireHoldUntil`)は振らない(射撃と同じ扱い)。

## 2. 数値(プレイヤーの tier1 ナイフと同じ=「同じ装備の仲間」)
| 項目 | 値 | 出どころ |
|---|---|---|
| ダメージ | 8 / クリティカル 5%(×1.5) | `knife-t1`(weaponUtils)・`CRIT_DAMAGE_MULT` |
| 間合い | 敵の当たり判定の最近点まで 74px(入る)/ 94px(出る=ちらつき防止) | `MELEE_RADIUS` |
| 1振りの周期 | 溜め200ms → 刃200ms(刃の出だしで当たる)→ 間420ms = 820ms | `COUNTER_WINDOW` / `COUNTER_COOLDOWN` |
| 当たる範囲 | 狙った敵の方向 ±70° の扇、間合いの中の敵全部 | プレイヤーの薙ぎ(全周)より狭い=1人の兵士の一振り |
| 押し返し | プレイヤーのナイフと同じ(`KNOCKBACK_SPEED`×(0.5+近さ×0.5)・280ms・押し返しの間隔あり)。押されない型(`resistsChipKnockback`)は押さない | 同上 |
| ヘイト | 撃った時と同じく、その軍人のバケツへ(`escortHateSide`) | |

## 3. 見た目
- 立ち絵は**伸ばさない・縮めない・回さない**(歪み禁止)。**別スプライトのナイフ**(`knife-t1` の絵)を手元(胸の高さ)で振る。
- 動き: 溜め=刃を後ろへ引く(減速して止まる)→ 刃=前へ大きく振り抜く(加速→減速)→ 戻り。出る/消えるは武器スプライトの統一型(下から慣性つきズレ+フェード・§7-15 `weaponSpawnEase`)。
- 当たった敵に斬撃の弧(`spawnSlash`・振った向き)と血しぶき(`spawnBlood`・斬った軍人の方へ噴く)。どちらも既存の素材・派手さ側(判定を持たない)。
- 音: プレイヤーのナイフと同じ系統(振り/当たり)を、軍人の射撃音と同じ距離減衰で小さく鳴らす。
- 顔の向きは振る方向へ。

## 4. 赤い予告
- 味方の攻撃なので赤い予告は持たない(プレイヤーへ当たらない)。

## 5. 負荷 1/10
- 4人それぞれ、既に選んでいる最寄りの敵(`advance.target`)との距離を1回測るだけ。当たった時だけ近傍の敵を走査(最大でも数十体)。描画はナイフのスプライト4枚(プール)。

## 6. 受け入れ条件
1. 敵が間合いに入ると、その軍人は銃を撃たずにナイフを振り、当たれば 8(クリ 12)ダメージと押し返しが入る。
2. 間合いから敵がいなくなると銃に戻る(撃つ間隔は従来どおり)。
3. 倒れている間・被弾の滑りの間は振らない。M0の随行2人は振らない。
4. 立ち絵は歪まない。ナイフは慣性つきで出て、振り抜いて、消える。
5. スマホの配置は1pxも変わらない(HUD に触らない)。

## 7. 着手前の監査を受けて決めたこと(v0.25.4978)
- **当てる経路**(品質 A-1): 守護霊の近接と同じ形=`damageEnemy(id, dmg, false, crit, false, 'other', escortHateSide(id))` を1発ずつ。撃破・XP・死体化・サブクエ等は弾と同じく中央処理。
  プレイヤー専用の近接計測(`grantMeleeKillRewards`)・削岩型/伐採人の「近接被弾で離脱」・ミゲルの近接反応は**付けない**(プレイヤーの近接だけの仕様)。
  ヘイトは**ヘイト表を持つボスだけ**軍人のバケツへ(雑魚は弾と同じく区別なし)。
- **斬れない相手**(品質 A-2): 死体・昇天中の英雄・不倒の死神が目の前に居ても近接の構えに入らない(=銃のまま)。当たる相手からも外す(`escortCanSlash`)。
- **血**(品質 A-3 / 見た目 #1): 斬った軍人の方へ噴く(`spawnBlood` を直接・守護霊と同じ幾何)。**弧**(見た目 #2): 振った向き(`spawnSlash` の faceOverride)。
- **クリティカル**: ダメージ×1.5 だけ(気絶は付けない)。※着手前の監査は「気絶させる」を推したが、軍人の弾はクリ自体が無く、承認外の増設になるため外した=社長への提案として残す(下)。
- **瀕死の後ずさり**(品質 A-5): 撃ちながら下がる(近接は出さない)。
- **倒れた/滑った**(品質 B-2): その時点で振りを消す(倒れた体の上にナイフが残らない・当たりも出ない)。両ルート。
- **押し返し**(品質 C-1): 弾と同じく「押されない型」は押さない(社長裁定待ちにはしない: プレイヤーのナイフはボスも押すが、軍人4人が1.75秒ごとにボスの技を止め続けるのは強すぎるため)。
- **見た目**(見た目 #3〜#10): 救援アライ/分身と同じ焼き込みダガー3枚(振りかぶり→7コマの弧→残光・`meleeSwingEase`)。当たる瞬間(溜め明け)は弧の中盤=刃が敵の上を通っている。
  構え中は振りの合間も腰の前にダガー(出る/しまうは慣性つき)。振っている間は足を止め(立ち止まりコマ)、振る向きへ踏み込む(位置だけ)。上下の敵には振りの面だけ傾ける。1振りごとに順手/逆手(弧の上下反転)。
- 積んだ(B): 振り始めの位相を人ごとにずらす(見た目 #10 の一部)・フェイザーだけ構えを変える・銃の発砲に閃光/反動を付ける(見た目 #12=範囲外)。

## 8. 検収(実装後)を受けて直したこと
- 監査1巡目(A)5件→全て直した: 命中音は実際に当たった時だけ(空振りは振りの音だけ)/クリの気絶を外した(提案へ)/ダガーが構え→溜め→振り抜き→構えで瞬間移動していた→1本の連続した動きに(構え=腰の前・溜め=後ろへ減速・刃=前へ・戻り)/
  構えの出入りを武器スプライトの統一型 `weaponSpawnEase`(15px・220ms)に/ナイフで倒した時も撃破の一言(`npcKillReact`)。
- ダガーを一回り大きく(暗い地面で溶けていた)。順手/逆手は振りの回数で厳密に交互。
- 積んだ(B): 構え中に敵が反対へ回った時の顔の向き(次の振りで反転)/体力線は踏み込みに付いて行かない(6px)/2ルートの配線テスト。
- ~~社長への提案~~ → **v0.25.4980 で採用(社長「はい」2026-10-11)**: 軍人のナイフのクリで通常敵を気絶させる(=フィニッシュの窓が開く)。より面白くなる(軍人が作った隙をプレイヤーが刈る連携)が、バランスに効くため承認待ち。
  - 規則は銃のクリと同じ: 倒しきれなかったクリ → 通常敵は5秒気絶+黄色いリング。ボス(isBossType)は damageEnemy 中央の半減だけ。使者(hangedman)は止めない。気絶時間アップ(プレイヤーのパッシブ)は乗せない。
