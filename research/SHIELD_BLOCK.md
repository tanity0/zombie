# シールドで技を防ぐ(設計書・第3版)

## 0. 社長の言葉(2026-10-17・そのまま)
> シールドは、判定源からみてシールドの後ろにいれば防げる　にできれば一番よいが、重いなら範囲攻撃だけ対象外
> ただし、それはシールドから40px以内　であること(範囲攻撃は)
>
> レーザーとかは単純にそこで壁と同じ扱い

- 「重いなら範囲攻撃だけ対象外」: **重くない**(§6=1/10)ので、範囲攻撃も対象にする。範囲攻撃には 40px の条件が付く。
- 今の作りの前提:
  - シールド(`projectiles` の `weaponType:'shield'`)は、敵の体と `projectiles` の敵弾を止める。
  - 汎用の跳び・突進は、盾に当たると技ごと中断される(全部の盾が対象。gameStore 15378/15405/15792/16490/16570)。
  - **それ以外の技はシールドを見ていない**=盾の後ろでも当たる。
- 盾は世界に**同時に最大1枚**。置くたびに、持ち主を問わず既存の盾を全部消すため(useGameLoop 10449)。

## 1. 規則(第3版で単純にした)
第2版は技ごとに出どころを変えていた。そのため監査2巡で抜けが出続けた(爆風の中心がプレイヤー自身の技、空から降る技、往復する毬など)。
第3版では、**出どころを「攻撃した本人」に一本化**する。

- **R1 レーザー以外の攻撃(全部)**: 次の2つを満たすと、プレイヤーには当たらない。
  1. 攻撃した本人の**今の体の中心**から、プレイヤーの中心への線分が、味方の盾の矩形を通る。
  2. プレイヤーの体(矩形)と盾の矩形の距離が **40px 以内**。
  - 「範囲攻撃」は社長の言葉の 40px 条件の対象。それ以外(突進・突き・噛みつき)も、同じ 40px を付ける。
    盾の後ろ 40px より遠くで直接当たる非レーザーの技は、事実上「回り込み」なので区別しない。
  - 本人が居ない攻撃: 往復する物(舞妓の手毬・幻影のドッグ)はその物の今の中心、虫の卵の爆発は卵の中心を使う。
- **R2 レーザー**(光線・狙撃線・`beam` 印の付いた爆風の帯): 盾は**壁**。
  - 光線の長さを、**中心線が味方の盾に当たる所**で切る(`clipBeamAtShields`)。
  - **当たりも絵もこの長さを使う。** 当たりは「相手の中心を光線の中心線へ落とした位置が、切った長さより手前の時だけ」。
    切った先の丸い端は作らない。こうすると、見えている光と当たりが一致する(監査2巡目A-3)。
  - 切った長さは、その経路の**全部の相手**(プレイヤー・守護霊・英雄・軍人)の判定に渡す。光線を短くするだけなので、入口ごとの印は要らない。
- **R3 対象外**
  - 判定を持つ床(ジブリルの火・グレンの血溜まり): 足元に残る物で、「後ろ」が無い。
  - 体の接触(敵の体が重なる): 盾が体を止めている。
    ※死神の系統と裏ボスは盾をすり抜けるが、その接触は既存の仕様どおり対象外とする。
  - `projectiles` の敵弾: 盾が消している。
- **R4 味方の盾だけ**: `hostile !== true`(プレイヤー・守護霊の盾)。幻影の盾は何も止めない。
- **R5 守る相手**: R1 はプレイヤーだけ。共通路でプレイヤーへの当たりを落としても、守護霊・英雄・軍人への処理は続ける(`continue` で飛ばさない)。
  R2 は光線そのものが短くなるので全員。
- **R6 例外**: プレイヤーの中心、または出どころが盾の矩形の中にある時は防がない(「後ろ」が決まらない)。

## 2. 実装の形
- 純関数は **`src/world/shieldBlock.ts`** に置く(描画は import しない)。
  - `friendlyShieldRect(projectiles)`: 味方の盾の矩形。無ければ null。
  - `shieldBlocksFrom(src, playerRect, shield)`: R1 と R6。
  - `clipBeamAtShield(ox, oy, ux, uy, len, shield)`: R2 で切った後の長さ。
- **R1 の差し込み口**: プレイヤーにダメージを入れる各経路で、**カウンター判定より前**に「範囲に入った」の真偽を偽にする。
  防いだ時は何も起こさない: ダメージ・押し出し・英雄の回復・被弾反撃の窓・体勢削り・「斬」マーク・ヒットストップ・技の中断。
  - 溜めの最中に成立するカウンター(当たる時刻より前に決まる物)は、今までどおり。盾は当たる瞬間だけを見る。
- **R2 の差し込み口**: 各光線の `tproj` の上限(`MIMIR_LASER_RANGE` 等)と、守護霊・第三者へ渡す終端を、切った長さに替える。
  描画は store の盾を読み、同じ純関数で同じ長さを出して絵を切る。
  共通路の光線の帯は、push する所と、遅れて出る3本目を `giantDelayedHits` から書き写す所(gameStore 14823)の両方で `beam: true` を運ぶ。
- **防いだ演出**: 盾を光らせる(`shieldHitAt`)+小さな火花(`spawnBurst`)+音 `shield-deploy` を小さく鳴らす。
  音と火花は、盾の `shieldHitAt` から 250ms 以内なら出さない(状態は盾の欄だけ)。盾の耐久は減らさない(叩き台)。
  重い `shieldBlocks`(heavy-impact の音・画面の揺れ)は使わない。
- **bountyTick の狙いの点**: 1272/1831/1935 の判定は、狙いの点(守護霊のこともある)で行っている。この既存の判定は変えない。
  盾の線分だけ、本物のプレイヤーの中心を使う。

## 4. 予告の絵との関係(★社長確認中)
- 赤い予告: 盾の後ろでも赤が出たまま、当たらない。掟「赤いのに当たらない」に触れる。
- 紫(レーザーのカラオケ塗り): 溜めの塗りは全長で描かれる。盾の先は掟③に触れる。発射中の光は盾で切れる。
- 推薦: **盾は掟の例外**。予告はそのまま出し、防いだ瞬間に盾が光って鳴る。
- 発射の途中で盾が消えた時は、壁が無くなったのと同じ。次のフレームから全長で当たる。

## 5. 受け入れ条件
1. レーザー以外: 攻撃した敵から見て盾の後ろ、かつ盾から 40px 以内なら当たらない。41px 離れたら当たる。盾の横・前では今までどおり当たる。
2. 爆風の中心がプレイヤーにある技でも、出どころは敵なので防げる。
3. レーザー: 光は盾で止まり、止まった先では誰にも当たらない。光の端が盾の横を通る時は、見えている光に触れていれば当たる。光輪は1本ずつ。
4. プレイヤーまたは出どころが盾の中なら防がない。幻影の盾は何も止めない。
5. 防いだ攻撃では、ダメージ・押し出し・カウンター・被弾反撃・英雄の回復が起きない。守護霊・英雄・軍人への同じ技の当たりは今までどおり(レーザー以外)。
6. 盾が無い時の挙動は1bitも変わらない。
7. 防いだ演出は、同じ盾で 250ms に1回まで。
8. テスト:
   - 純関数: 線分・40px 境界・中に居る時・光線の切断長。
   - 結合: 共通路(爆風の中心がプレイヤーの技を含む)・ミミルのレーザー(プレイヤーと守護霊)・アンジェル系の帯・bountyTick の1経路・遅れて出る3本目の `beam`。
   - 絵: 光線が盾で切れていることを撮って確かめる。

## 6. 負荷
1/10。盾は最大1枚。当たる瞬間に線分と矩形を1回。光線の絵は毎フレーム、光線の本数ぶん。
