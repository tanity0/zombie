# シールドで技を防ぐ(設計書・第2版)

## 0. 社長の言葉(2026-10-17・そのまま)
> シールドは、判定源からみてシールドの後ろにいれば防げる　にできれば一番よいが、重いなら範囲攻撃だけ対象外
> ただし、それはシールドから40px以内　であること(範囲攻撃は)
>
> レーザーとかは単純にそこで壁と同じ扱い

- 「重いなら範囲攻撃だけ対象外」: **重くない**(§7=1/10)ので、範囲攻撃も対象にする。範囲攻撃には 40px の条件が付く。
- 前提(今の作り): シールド(`projectiles` の `weaponType:'shield'`)は、敵の体と敵の弾を止める。汎用の跳びと突進は、盾に当たると技ごと中断される。
  これは敵の盾も含めた全部の盾が対象(gameStore 15378/15405/15792/16490/16570)。
  **それ以外の技(範囲・帯・レーザー)はシールドを見ていない**=盾の後ろでも当たる。
  死神の系統と裏ボスは盾を体ですり抜ける(useGameLoop 14297)。

## 1. 規則
- **R1 範囲攻撃**(円・扇・帯で判定する、予告つきの技。着地の衝撃・薙ぎ・突き・振り・回転斬りなど)。
  出どころからプレイヤーの中心への線分が**味方の盾**の矩形を通り、**かつ**プレイヤーの体(矩形)と盾の矩形の距離が **40px 以内**なら、当たらない。
- **R2 突進**(走る体そのものが当たる技)。線分の条件だけで防ぐ(距離の条件なし)。
- **R3 レーザー**(光線・狙撃線・`beam` 印の付いた爆風の帯)。盾は**壁**。
  - **当たり**: 光線の始点から相手の中心への線分が味方の盾を通るなら、その相手には当たらない(距離の条件なし)。
    相手はプレイヤー・守護霊・英雄・軍人の**全員**。
    光線の判定は終端が丸く、幅がある。だから「長さを切る」だけでは、盾の真後ろにも届いてしまう(監査A-1・A-2)。必ずこの線分の判定で落とす。
  - **絵**: 光線の中心線が盾に当たった所で切る(`clipBeamAtShields`)。描画は store の盾の一覧を読み、同じ純関数でその場で計算する。
    敵に欄を持たせないので、1体が複数本持つ技(光輪6本・スリエルの2本目・巨人の三連射)も、1本ずつ同じ式で切れる。
- **R4 対象外**(「後ろ」が無い・盾が既に止めている・既存の仕様)。
  - 判定を持つ床(ジブリルの火 angelBossTick 3886・グレンの血溜まり combatTick 692・虫の卵 useGameLoop 15455)
  - 空から降る範囲(矢の雨 `liberty-arrow`)
  - 体の接触・噛みつき(combatTick 1784 / 1982)。盾が体を止めている。
  - 死神の系統・裏ボスの接触と覆いかぶさり(combatTick 1483 / 1982)。盾をすり抜けるのは既存の仕様。
  - 幻影のドッグの噛み(useGameLoop 10054)
  - 弾(combatTick 898)。盾が消している。
- **R5 味方の盾だけ**: `hostile !== true` の盾(プレイヤーと守護霊が置いた物)だけが守る/光線を止める。幻影の盾(hostile)は何も止めない。
- **R6 守る相手**: R1・R2 はプレイヤーだけ。R3 は全員(壁なので)。
- **R7 例外の形**:
  - プレイヤーの中心が盾の矩形の中にある時は、「後ろ」が決まらない=防がない(監査A-7)。出どころが盾の中にある時も同じ。
  - 舞妓の手毬(bountyTick 1935)は R2 と同じ扱い。出どころは投げた本人の位置。

### 1-1. 出どころ(監査A-5)
| 形 | 出どころ |
|---|---|
| 円の爆風 | 円の中心 `b.x,b.y` |
| 扇 | 扇の要 `b.fan.cx,cy` |
| 帯(突き・振り・薙ぎ・伐採人の薙ぎなど) | **持ち主の敵の今の中心**(`b.enemyId` から引く。帯の端点は使わない=伐採人の帯は横向きのため) |

## 2. 実装の形
- 純関数は **`src/world/shieldBlock.ts`** に置く(描画は import しない)。
  - `friendlyShieldRects(projectiles)`: 味方の盾の矩形。
  - `shieldBlocksHit(src, targetRect, shields, mode: 'area' | 'direct')`: R1/R2/R7。`area` は 40px の条件付き。
  - `clipBeamAtShields(ox, oy, ux, uy, len, shields)`: 絵の長さを返す。
- **順番(監査A-8)**: 防いだ攻撃は「範囲の外に居た」のと同じに扱う。だから**カウンターの判定より前**で落とす。
  防いだ時は、次のどれも起こさない: ダメージ・押し出し・英雄の回復・被弾反撃の窓・体勢削り・「斬」マーク・ヒットストップ・スリエル等の技の中断。
- **防いだ演出(監査A-9)**: 盾自身のヒット表現を使う(既存の `shieldHitAt`=盾のシェイクとフラッシュ+小さな火花)。
  鳴らすのは盾の軽い音。**同じ盾につき 250ms に1回まで**に間引く。
  重い `shieldBlocks`(heavy-impact の音・画面の揺れ)は使わない。盾の耐久は減らさない(叩き台)。
- **爆風の共通路**(combatTick 354〜): `inBlast` が真で、まだカウンター判定に入る前に `shieldBlocksHit` で落とす。
  光線の帯(ジブリルの槍・巨人の三連射・遅れて出る3本目)は、push する所で `beam: true` を付ける。`beam` の付いた帯は R3 で判定する。

## 4. 予告の絵との関係(★社長確認中)
- 赤い予告(範囲・突進): 盾の後ろでも赤が出たまま、当たらない=掟「赤いのに当たらない」に触れる。
- 紫(レーザーのカラオケ塗り): 溜めの塗りはプレイヤーの足元まで全長で描かれる。盾の先は「紫なのに当たらない」=掟③に触れる。
  発射中の光線は盾で切れる。
- 推薦: **盾は掟の例外**。予告はそのまま出し、防いだ瞬間に盾が光って鳴る。
- 未決の端: 発射の途中で盾が消えると(寿命・破壊)、次のフレームから光線が全長に伸びて当たる。壁が無くなったのと同じ扱いとする(推薦)。

## 5. 受け入れ条件
1. 範囲攻撃: 盾の後ろで盾から 40px 以内なら当たらない。41px 離れたら当たる。盾の横・前では今までどおり当たる。
2. 突進・手毬: 盾の後ろなら距離に関係なく当たらない。
3. レーザー: 盾の真後ろに居れば、プレイヤー・守護霊・英雄・軍人とも当たらない。光線の幅が盾より広くても、線分が盾を通れば当たらない。
   絵は盾の所で切れる(撮影で確かめる)。光輪の6本は1本ずつ切れる。
4. プレイヤーが盾の矩形の中に居る時は防がない。
5. 防いだ攻撃では、カウンターも被弾反撃も英雄の回復も起きない。
6. 幻影の盾は何も止めない。守護霊の盾はプレイヤーを守る。
7. 盾が無い時の挙動は1bitも変わらない(盾0枚なら関数は即 false / 長さそのまま)。
8. テスト:
   - 純関数(`shieldBlock.test.ts`): 線分・40px 境界・出どころ/プレイヤーが盾の中・光線の切断長・複数本。
   - 結合: 爆風の共通路・ミミルのレーザー・アンジェル系の帯の1経路ずつ。
9. 防いだ演出が毎フレーム鳴り続けない(同じ盾は 250ms に1回)。
