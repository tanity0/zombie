# シールドで技を防ぐ(設計書)

## 0. 社長の言葉(2026-10-17・そのまま)
> シールドは、判定源からみてシールドの後ろにいれば防げる　にできれば一番よいが、重いなら範囲攻撃だけ対象外
> ただし、それはシールドから40px以内　であること(範囲攻撃は)
>
> レーザーとかは単純にそこで壁と同じ扱い

前提(今の作り): シールド(サブウェポン「シールド」= `projectiles` の `weaponType:'shield'`)は**敵の体と敵の弾**を止める。
**技(範囲・帯・レーザー)はシールドを見ていない**=盾の後ろでも当たる。

## 1. 規則(1行ずつ)
- **R1 直線の技(突き・振り・突進・狙撃線など)**: 「出どころ→プレイヤーの中心」の線分が**味方の盾**の矩形を通るなら当たらない。
- **R2 範囲攻撃(着地の衝撃・薙ぎ・踏み鳴らし・回転斬りなど)**: R1 と同じ線分の条件に加えて、**プレイヤーの体(矩形)と盾の矩形の距離が 40px 以内**の時だけ当たらない。
- **R3 レーザー**: 盾を**壁と同じに扱う**=光線の中心線が盾に当たった所で光線が終わる。その先は当たらない(プレイヤー・守護霊・英雄・軍人とも)。
  見た目も盾で止める(光線の絵の長さを同じ値で切る)。
- **R4 対象外**: 体の接触・噛みつき(盾は既に体を止めている)/ 弾(既に盾が消している)/ **判定を持つ床**(ジブリルの火・グレンの血溜まり・虫の卵)=出どころが足元なので「後ろ」が無い。
- **R5 味方の盾だけ**: `hostile !== true`(プレイヤーと守護霊が置いた盾)。幻影が置いた盾(hostile)はプレイヤーを守らない。
- **R6 守るのはプレイヤーだけ**(R3 のレーザーは壁なので全員)。守護霊・軍人を盾の後ろで守るのは別件(指示なし)。

### 1-1. 用語
- **出どころ**: 技の判定の中心。範囲=爆心(円の中心 / 帯の始点 / 扇の要)。直線の技=帯の始点(=敵の位置)。突進=走り出した位置。
- **盾の矩形**: シールドの当たり判定そのもの(足元の板: 左右向き 16×108 / 上下向き 58×16)。
- **線分が通る**: `world/obstacles.segmentIntersectsRect`(既存・壁の遮蔽と同じ式)。出どころが盾の矩形の中にある時は「後ろ」が決まらない=防がない。

## 2. 実装の形
- 判定は純関数 **`src/world/shieldBlock.ts`**(描画を import しない)。
  - `friendlyShieldRects(projectiles)` → 味方の盾の矩形の配列。
  - `shieldBlocksHit(src, playerRect, shields, kind: 'direct' | 'area')` → boolean。R1/R2。
  - `clipBeamAtShields(ox, oy, ux, uy, len, shields)` → 盾で切った長さ(当たらなければ len のまま)。R3。
- 各経路で「プレイヤーに当てる直前」に `shieldBlocksHit` を挟む。防いだら**ダメージを入れず**、盾に「防いだ」演出(既存の `shieldBlocks` の火花+SE と同じ見た目)を出す。盾の耐久は**減らさない**(技を防ぐたびに壊れると R2 の 40px が無意味になるため。社長が実機で決める叩き台)。
- レーザーは長さの計算(`tproj` の上限)を `clipBeamAtShields` の値に置き換え、同じ値を敵の欄(例 `laserClipLen`)へ書いて描画が読む。

## 4. 赤い予告の掟との関係(★社長確認中)
- 掟「**赤いのに当たらない**はやってはいけない」に、盾の後ろが当たる。
- 推薦: **盾は掟の例外**とし、予告の赤はそのまま出す。防いだ瞬間に盾へ火花+音を出す(「盾が受けた」と読める)。レーザー(R3)は絵も盾で止まるので掟に触れない。
- 代案: 盾の後ろの部分だけ赤を欠けさせる(描画の作業が大きい)。

## 5. 受け入れ条件
1. 盾の真後ろ(出どころ→自分の線が盾を通る)で、直線の技は当たらない。盾の横・前では今までどおり当たる。
2. 範囲攻撃は、盾の後ろかつ盾から 40px 以内の時だけ当たらない。41px 離れたら当たる。
3. レーザーは盾で止まり、絵も盾の所で切れる。盾が無ければ今までどおり。
4. 幻影の盾はプレイヤーを守らない。守護霊の盾はプレイヤーを守る。
5. 盾が無い時の挙動は1bitも変わらない(盾の数0なら関数は即 false / len)。
6. 純関数のテスト(`shieldBlock.test.ts`): 線分の通過・40px 境界・出どころが盾の中・レーザーの切断長。

## 6. 負荷
1/10。当たる瞬間に1回、盾の数(同時に数枚)×線分と矩形。レーザーは毎フレーム1本×盾の数。
