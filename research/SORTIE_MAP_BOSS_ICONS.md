# 出撃画面の地図にボスの顔を出す(設計書)

## 0. 社長の言葉(2026-11-13・そのまま)
- 「一度出会って、まだ一度も倒していないボスは、出撃画面のマップに小さくアイコン表示(顔部分だけとか)。ただし、ハンター、死神、塊 は載せない。次にどこに徘徊が現れるかが分かる形に変更。(一度倒すまで)」
- 裁定(同日):
  1. 「毎回、出現の抽選20%は変わらず、出撃前画面表示で抽選タイミングにして、出現が確定したときだけマップに表示。毎回出たり消えたり変わるということ。」
  2. 英雄・解放軍群は「出さない」。
  3. 顔は「推薦で 年表くらい小さい絵から頭だけ丸いマスクで」。

## 1. 地図
- 作戦室(ホーム)の地図 `src/components/DsStoryMap.tsx`(`MissionSelect.tsx` の「出撃」ボタンの上)。座標は `src/data/opsMapPlaces.ts` の `OPS_MAP_PLACES`(原画 1816×866 に対する割合)。
- 出撃先を選ぶ画面(stageSelect)には地図が無い=対象外。

## 2. 載せるボス(=載せる条件)
地図に顔を出すのは、次の **A または B** で、かつ **出会った記録あり・倒した記録なし** のボス。
- **A. ステージ固定のボス**: `PRACTICE_SLOTS`(`src/utils/bossPractice.ts`)の `reachable:true` の枠(城ボス `giantbat@stage-N`・ゲートの天使・深層の裏ボス・idol・phillboss・賞金首)。その枠の `stageId` の場所に出す。
- **B. 徘徊の枠(宇宙飛行群・亡霊・孫悟空)**: §3 の抽選で「次の出撃で出る」と確定した時だけ、確定したステージの場所に出す。
- **載せない**: ハンター(`hunter`)・死神(`reaper`・使者 `hangedman` 含む)・変異塊(`lab-crawler`)・英雄(`mutant-hero`)・解放軍群(`mutant-liberty`)。**判定には型の除外一覧として明示的に入れる**(今は A の母集団に元々入っていないが、`reachable` を将来変えても漏れないように・監査C9)。
- **照らすキーは `encounterSlotKey` の形に統一**(監査A5): 城ボス=`giantbat@stage-N`、賞金首=`bounty-ranged` 等、変異体=`mutant-astro` 等、拳鬼=`phantom-brawler`。`PRACTICE_SLOTS` の `slotKey`(`…@practice`)では照らさない。出会い・倒しの両方とも同じ形。
- 出会った記録=既存 `src/utils/bossEncounter.ts`(`boss.encountered.v1`)。倒した記録=§4 で新設。
- **出会っていない徘徊のボス**は、抽選で確定しても**顔は出さない**(出現そのものは確定どおり起きる=初めての出会いは驚きのまま)。倒した後の徘徊のボスも顔は出さない(出現の抽選には今どおり入る)。
- 場所を持たない/地図に無いステージ(`OPS_MAP_PLACES` に座標が無い・まだ行けないステージ)には出さない。

## 3. 徘徊の枠の抽選を「出撃前画面」へ移す
- **今**: ステージに入った後、ゲームループの最初に `rollRunPatrolSlot`(20%で枠が開き、開いたら宇宙飛行群・亡霊・拳鬼から均等に1人。拳鬼はステージ1なら城ボスを一度倒した後だけ)を引く。対象ステージ=`HERO_PATROL_STAGES`(1・3・4・5)。
- **変更後**: 作戦室(ホーム)の画面(`screen.name==='home'`)が表示された時に1回だけ引き(**地図の部品には置かない**=`?dsmap=0`・旧ホームでも引く・監査C10)、結果を「次の出撃の徘徊」として保存する。
  1. 20%(`RUN_MUTANT_BOSS_CHANCE` そのまま)で枠が開く。開かなければ「なし」。
  2. 開いたら、顔ぶれ(宇宙飛行群・亡霊・拳鬼=拳鬼は出せるステージが1つでもある時だけ)から均等に1人。
  3. その1人が出られるステージ(`HERO_PATROL_STAGES` のうち、今の進行で出撃できるステージ。拳鬼はステージ1なら城ボス撃破後だけ=`phantomBrawlerStageEligible` と同じ条件)から均等に1つ。出られるステージが無ければ「なし」。
  4. 結果 `{ boss, stageId }` を localStorage に保存(キー新設 `sortie.patrol.v1`)。**作戦室を開き直しても・アプリを再起動しても引き直さない**(出撃するまで同じ結果)。
- **出撃した時**: 出撃したステージが保存した `stageId` と同じならそのボスを出す(今の出現の処理=出現位置・時刻・ウェルカム中の待ち・前兆の一言はそのまま)。違うステージなら徘徊の枠は出ない。どちらでも保存した結果は消す(=次に作戦室へ戻った時に引き直す=「毎回出たり消えたり」)。
- **作戦室を通らない出撃(ゲームオーバー/撤退画面の「もう一度プレイ」=App.tsx の startGame 直行・監査A3)**: ★社長確認中。推薦=今どおりステージに入った時にそのステージで20%を引く(地図は通らないので表示とは無関係・1ランごと20%が保たれる)。
- **練習ラン・ボステスト・ボスメーカー**: 保存した結果を使わず、消しもしない(今どおり徘徊の枠は本編だけ)。確認用の強制出現(`?wraithnow=1` 等)は今どおり保存した結果より優先。
- 前兆の一言(「寒気がする・・・」等)は、そのランで実際に出るボスに対して今どおり言う。
- ※事実: 今は「どのステージへ出撃しても 20%」。変更後は「作戦室を開くたびに 20% で、確定したステージへ出撃した時だけ出る」。出撃先を自分で選ぶので、狙って会いに行ける(社長裁定1)。

## 4. 倒した記録(新設)
- `src/utils/bossDefeated.ts`(新設)・localStorage キー `boss.defeated.v1`・スロットキー(`bossEncounter` と同じ形: 城ボス=`giantbat@stage-N`、変異体=`mutant-astro` 等、拳鬼=`phantom-brawler`)の配列。
- 書く時: そのボスを本編で倒した時。**キルの経路は2つ**(近接の補助のキル gameStore.ts:7073 付近 と damageEnemy の合流点 :17824 付近)=**両方**で書く。**型・守護霊の同行の有無を問わず書く**(既存の `notifyBossClear` は賞金首・拳鬼を落とし、守護霊同行のランでは何もしない=相乗りしない・監査A1)。練習ラン・ボステスト・ボスメーカーでは書かない(`bossEncounter` と同じ扱い)。
- **書かない撃破**(監査A4): イベントで出た城ボス(`fromEvent` の giantbat)・グレンの第1形態(`glenForm===1`)。既存の `markCastleBossCleared`・年表の台帳と同じ除外。
- 拳鬼は撃破時の型が `guardian-phantom`=`phantomUnique==='brawler'` を `phantom-brawler` へ写して書く(監査A5)。
- **過去の撃破の取り込み**(この版より前に倒したボスに顔が出続けないように): 初回読み込み時に、既存の撃破の痕跡から足す。取り込みは1回だけ(取り込んだ印を同じキーの中に持つ)。
  - 城ボス=`zombie.progress.castleBoss`(ステージID配列)→`giantbat@stage-N`。
  - 年表の撃破の台帳 `${stageId}::boss::${type}`(gameStore.ts:6415 付近=天使・裏ボス・城ボスの初回撃破)→ 対応するスロットキー(監査A2)。
  - 討伐記録=`zombie-ghost-profile-v1` の `bossStyles` のキー(採用した物だけ=補助)。
  - **賞金首・拳鬼・変異体は過去の撃破の痕跡が無い**=この版の後に一度倒すまで顔が出る(取り込めない事実として受け入れる・社長へ報告済み)。

## 5. 顔(頭だけ・丸いマスク)
- 絵の出どころ=既存の `bossIconSrc`(`src/utils/bossIcon.ts`・年表と同じ1枚)。拳鬼は `kenki-idle`。
- 頭の切り抜きの表(新設 `src/data/bossHeadCrops.ts`): ボスの絵ごとに「頭の中心(絵の幅・高さに対する割合 u,v)」と「丸の半径(絵の高さに対する割合)」。地図に出し得る全ボスに行があることをテストで止める(台帳漏れ)。
- 地図の上の大きさ: 直径 約16px(スマホの箱 幅327〜382px で)。原画座標で書く(`U=5` の約3.2倍)。縁取り: 細い暗い縁+琥珀ではない色(行った場所の琥珀の四角・NEXT の菱形と区別できること)。
- 同じ場所に複数(stage-6・ex1・ex2 は座標が同じ/ステージ1は城ボス・裏ボス・賞金首・徘徊の4つが重なり得る)=**最大3つまで横一列**(間隔2px・点の真下に置く)。4つ目以降は顔を出さず、列の右端に小さな「+N」(監査A6)。列は「今いる所」の地名(点の上に出る)・NEXT(点の横)とぶつからないよう**点の下側**へ。地図の下端からはみ出す時は点の上側へ。
- 出方: 地図を開いた時に慣性つきでふわっと出る(CLAUDE.md 慣性MUST)。常時のアニメーションは付けない。
- 負荷: 地図を開いた時だけの SVG 数個=0/10。

## 6. 受け入れ条件
1. 出会った・倒していないステージ固定のボスの顔が、そのステージの位置に出る。倒すと次に作戦室を開いた時から出ない。
2. ハンター・死神・変異塊・英雄・解放軍群は、どんな状態でも地図に出ない。
3. 作戦室を開くと徘徊の枠が引かれ(20%)、確定した時だけ、出会った・倒していない徘徊のボスの顔が確定したステージに出る。開き直し・再起動で変わらない。出撃すると消え、次に作戦室へ戻ると引き直される。
4. 確定したステージへ出撃するとそのボスが出る。他のステージへ出撃すると徘徊の枠は出ない。
5. 練習ラン・ボステスト・ボスメーカーは保存した抽選を使わず消さない。
6. この版より前に倒した城ボス・討伐記録のあるボスには顔が出ない。
7. 地図に出し得る全ボスに頭の切り抜きの行がある(テスト)。顔は頭が丸に収まっている(撮影で目視)。
8. 抽選・ステージ選び・載せる条件・過去の撃破の取り込みは純関数でユニットテスト(乱数は注入)。
