## 3. 改善提案(17項目)

書式: 何が問題か / 案 / なぜ面白くなるか / 手本 / 手間 / スマホ・PC への影響 / 仕様変更か。

### P1「地図から直接出撃」(作戦室 ui_05 → 作戦地域 ui_20)
- **問題**: 地図に「NEXT」の印があるのに、押しても何も起きない。出撃するには「作戦地域」の一覧(札2枚+下半分が空)を1枚くぐる。
- **案A(推薦)**: 地図の下端に次の任務を1行で重ねる(例: 「DAY 26 避難回廊 殲滅作戦 SUB 0/1」)。出撃の帯を押すと、その任務の詳細へ直行する。別の場所へ行く時だけ、地図を押して一覧を開く。
- **案B**: 地図そのものを一覧にする。地図の上に行ける場所の印を出し、印を押すと任務詳細が開く(「作戦地域」画面は無くなる)。
- **なぜ面白くなるか**: 「次はここ」が地図の上で決まる。出撃までのタップが1回減る。
- **手本**: DS2 の地図端末(地図の上で目的地を選び、そのまま受注)。
- **手間**: A=小〜中 / B=大(地図に場所の印を置く作業)。
- **影響**: スマホ=地図の下端に1行増える。PC=同じ(横2列のまま)。
- **仕様変更か**: **当たる。画面の流れが変わるので社長の判断が要る。**

### P2「戦闘から音のボタンを降ろす」(HUD ui_31/34・PC ui_51)
- **問題**: 戦闘中、右下で音のボタンと一時停止が縦に並ぶ。親指がよく通る場所に、戦闘中に要らないボタンがある。
- **案**: 戦闘中の音のボタンを消し、一時停止の中に置く(一時停止には既に左上の音のボタンが出ている=ui_33)。
- **なぜ面白くなるか**: 戦っている間の画面から「設定」の気配が消え、誤って押す事故も無くなる。
- **手本**: DS2 は戦闘中の画面に設定の入口を出さない(私の記憶)。
- **手間**: 小。
- **影響**: スマホ=右下のボタンが1つ減る(phone-guard の基準の撮り直しが要る)。PC=同じ。
- **仕様変更か**: 当たらない(配置のみ)。ただし音を切る手数が1回増えるので、社長に確認したい。

### P3「レベルアップを“拾う”瞬間に」(ui_32)
- **問題**: 3枚のカードが同じ枠・同じ明るさ。レア度は右上の小さな札(NEW・ノーマル / NEW・レア)だけ。「除外」が赤系の地で、カードの中で一番強い色になっている。題字の下の「強化を選んでください」だけ丁寧語。
- **案**:
  1. **レア度を枠の光で見せる**: ノーマル=光なし、レア=枠の内側が一段明るく、縁が呼吸する。札の文字は残す。
  2. **1枚ずつ落とす**: 上から、少し間を置いて1枚ずつ落ちて止まる(ゆっくり止まる)。**一番レアな1枚は最後に来て、着地で一瞬光る**。
  3. **「除外」を赤から外す**: カードの右下に灰色の小さな文字で置くか、長押しで出す。赤は戦闘の文法(カウンター)に返す。
  4. 「強化を選んでください」を消す(題字だけで分かる)。
- **なぜ面白くなるか**: 1ランに何度も見る画面に「当たりが来た」瞬間ができる。レアが最後に光るまでの0.5秒が、毎回の小さな山場になる。
- **手本**: ディアブロの戦利品(レア度が光と色で一目で分かる)。DS2 の装備品を受け取る時の、重さのある出方。
- **手間**: 中。
- **影響**: スマホ・PC とも同じ部品(DOM)。止まっている間の画面なので、描画の負荷は 1/10(負担するのは DOM の CSS アニメだけ・数百ミリ秒・ポーズ中)。
- **仕様変更か**: 演出と見せ方だけなら当たらない。**「除外」を長押しにする場合は操作が変わるので社長の判断が要る。**

### P4「リザルトを配達評価に」(ui_40)
- **問題**: 深さの図が4割を取り、今回の数字は小さな枠に並ぶだけ。全部が一度に出るので、どこを見ればいいか決まらない。「もう一度プレイ」だけが明るい青(GameOverScreen.tsx 1295行の `rgba(96,165,250)`)で、作品の色(琥珀・紫)から浮く。「g」と「G」が混ざる。
- **案**:
  1. **順番に出す**: 題字(任務失敗/任務達成) → 生存時間 → 撃破 → 最大コンボ を1つずつ数え上げる(数字が回って止まる・1つごとに短い音) → 最後に**ランク札(怠・暴…)を押印のように押す** → 獲得 G を所持 G へ流し込む。押せば飛ばせる。
  2. 深さの図は、押印の後に「今回の到達」の線が下りてくる形で見せ、高さを今の半分ほどに。
  3. 「もう一度プレイ」を作戦室と同じ琥珀に。「メニューに戻る」は線だけ。
  4. 通貨は「G」にそろえる。「AIディレクター」の名前は既出(監査で据え置き)だが、プレイヤーに見える所に内部の呼び名が出ている点は再検討したい。
- **なぜ面白くなるか**: 数字が1つずつ止まるたびに「今回はここまで」が体に入る。良いランほど長く気持ちよく、悪いランはすぐ飛ばせる。
- **手本**: DS2 の配達評価(項目が順に数え上がり、最後に評価の印が押される)。
- **手間**: 中。
- **影響**: スマホ・PC 共通の DOM。負荷 1/10(ゲームが止まった後の画面)。
- **仕様変更か**: 見せ方のみなら当たらない。**深さの図を小さくするのは、社長が作った「深さ」の見せ方に触れるので確認が要る。**

### P5「戻るの型を1つに」(装備・強化・開発・資料室・任務詳細・ジョブ選択)
- **問題**: 「戻る」の形が数えて4種類ある。装備=矢印なしの文字だけ(ui_06)/強化・開発・資料室・守護霊・対策室・オプション・作戦地域=「‹ 戻る」+縦線(ui_14 ほか)/任務詳細=絵の上に黒い箱(ui_21)/ジョブ選択=枠付きの箱(ui_22)。さらに、どの画面でも右上の丸い音のボタンが見出しの隣に居座る。
- **案**: 見出しの部品を1つにする(左=戻る、中=題字+英字の小注記、右=空ける)。音のボタンは作戦室の最下段とオプションにだけ置く。
- **なぜ面白くなるか**: 迷わず戻れる。継ぎはぎの印象が消え、作戦室が1つの端末に見える。
- **手本**: DS2 の端末メニュー(どの画面でも同じ枠と同じ戻り方)。
- **手間**: 小〜中。
- **影響**: スマホ=見出しの位置が数 px 動く(phone-guard の基準撮り直し)。PC=同じ。
- **仕様変更か**: 当たらない。

### P6「最初の1画面を開発の記録にしない」(ui_01)
- **問題**: 初めて起動すると、タイトルより先に全画面の更新情報が出る。新しい方から30件のうち19件が「ゲーム内容の変更はありません」。
- **案A(推薦)**: 「変更はありません」の版は表示から外す(記録は changelog.ts に残す)。初回起動(何も見ていない端末)では全面を出さず、タイトルの NEWS にだけ置く。
- **案B**: ストアに出す版では更新情報の全面表示そのものを止める(開発チャネルは今のまま)。
- **なぜ面白くなるか**: 最初に見るのがこの世界になる。
- **手本**: DS2 は起動して最初に世界(映像)を見せる。
- **手間**: 小。
- **影響**: スマホ・PC 共通。
- **仕様変更か**: **当たる。v0.25.4234 で「更新情報は初回だけ全面」と決まっている(版の確認のため)。社長の判断が要る。** 版の確認は右上の版番号で足りるかが判断材料。

### P7「オープニングを毎回流さない」(ui_05b)
- **問題**: 2回目以降の起動でも、START を押すとオープニングが流れる(TitleScreen.tsx 531〜538行の `tapStart`。更新情報を既に見た起動では、START がオープニングを始める)。毎回スキップを押すことになる。
- **案**: 1度最後まで見た(またはスキップした)端末では、START から作戦室へ直行する。オープニングは資料室から見返せるようにする。
- **なぜ面白くなるか**: 遊びたい時にすぐ戦場へ行ける。オープニングは「見返したい物」になる。
- **手本**: DS2 も2回目以降は冒頭の映像を飛ばして続きから始まる(私の記憶)。
- **手間**: 小。
- **影響**: スマホ・PC 共通。
- **仕様変更か**: **当たる(起動の流れ)。社長の判断が要る。** 2026-10-24 の指示「オープニングはタイトルの前に」との関係も確認が要る。

### P8「タイトルの絵を縦いっぱいに」(ui_02)
- **問題**: 縦持ちで、絵が縦の真ん中7割ほどに収まり、上下が黒い帯。版番号だけが上の黒に浮く。
- **案**: 絵を縦いっぱいに敷き、上下は絵の端から色を伸ばす(紫の光と床の反射を縦に延長)。START は画面下から 1/5 ほどの位置へ下げ、題字との間を空ける。
- **なぜ面白くなるか**: 起動した瞬間に画面が全部この世界になる。
- **手本**: FF の縦長キービジュアル(題字と人物を縦いっぱいに使う)。
- **手間**: 小(CSS だけで済む場合)〜中(絵の上下を描き足す場合)。**素材の縦が足りるかは未確認。**
- **影響**: スマホのみ(縦長の時だけ)。PC は今のまま。
- **仕様変更か**: 当たらない。

### P9「空っぽの装備画面に、今持っている物を置く」(ui_06)
- **問題**: 初めて装備を開くと、1行の文と「サブ: なし/アバター: なし」だけで8割が黒。今持っているハンドガンすら出ない。
- **案**: 持ち替える物が無くても、今の銃をカードで1枚出す。その下に Tier 2・3 の枠を空の影で並べ、「開発施設へ」のボタンで直行できるようにする。
- **なぜ面白くなるか**: 「ここが埋まっていく」が最初の訪問で見える。集める目標が生まれる。
- **手本**: DS2 の装備棚(持っている物が棚に並び、空きの枠も見える)。
- **手間**: 小。
- **影響**: スマホ・PC 共通。
- **仕様変更か**: 当たらない。

### P10「値段の赤をやめる」(強化 ui_14・開発 ui_15)
- **問題**: 値段(50G/200G)が赤系。払えない時の色と思われるが、赤はこの作品で「カウンター/回避の対象」の色。
- **案**: 払える=琥珀、払えない=沈んだ灰+「あと 50G」。買った瞬間は、枡が1つ下から積まれるように埋まり(ゆっくり止まる)、短い音を鳴らす。
- **なぜ面白くなるか**: 何が買えて、あといくらかが一目で分かる。買った手応えが目と耳に残る。
- **手本**: DS2 の端末の数値(色ではなく明るさで状態を分ける)。
- **手間**: 小。
- **影響**: スマホ・PC 共通。
- **仕様変更か**: 当たらない。

### P11「資料室を鍵の壁にしない」(ui_16・既出 #13)
- **問題**: 開いて最初の画面が、鍵と「???(未習得)」の行で埋まる(見える範囲で17行)。NEW が付いているのに、新しい物がどこか分からない。
- **案**: 各章で、読める物を上に、未習得は章ごとに1行「未習得 14」にまとめる。NEW の物は章の頭に出し、開いた時にそこまで送る。
- **なぜ面白くなるか**: 開けた瞬間に「新しく分かったこと」へ行ける。まだ無い物の数は、集める目標として1行で効く。
- **手本**: DS2 の資料(持っている物だけが並び、件数で残りが分かる・私の記憶)。
- **手間**: 小。
- **影響**: スマホ・PC 共通。
- **仕様変更か**: 当たらない。

### P12「任務詳細は目的を1行で、札を重ねない」(ui_21)
- **問題**: 冒頭の説明文と「任務目標」が同じこと(研究所への進路を確保)を2回言う。「ジョブ選択」の文字の裏に「Enter」の札が重なり、文字が欠ける。
- **案**: 絵の下にまず目的を大きく1行(「大型変異体を殲滅/民間人2名を救助」)。説明文はその下に小さく、読む人だけ読む。Enter の札はボタンの外側(右肩)へ出す。
- **なぜ面白くなるか**: 何をしに行くかが出撃前に頭に入る。
- **手本**: DS2 の依頼票(目的地・条件・荷物が先、経緯は後)。
- **手間**: 小。
- **影響**: スマホ=文の順番だけ。PC=札の位置が直る。**Enter の札がタッチだけの端末で出るかは未確認**(ヘッドレスはマウスで押していた)。
- **仕様変更か**: 当たらない(文言の並べ替え)。文言を削る場合はクリエイティブ監査を通す。

### P13「ジョブ選択は、選んでから下で押す」(ui_22)
- **問題**: 技の説明の白文字が立ち絵の脚の上に直接乗る。START が説明文の横、ジョブ札の上にあり、「選ぶ(下)→押す(上)」と指が戻る。
- **案**: 説明文の下に暗い霞を敷いて文字を絵から離す。START をジョブ札の下へ、横いっぱいに。ジョブを替えた時は立ち絵が横から滑り込んで止まる。
- **なぜ面白くなるか**: 選んで、そのまま親指を下ろして出撃できる。替えるたびに人物が入れ替わる手触りが出る。
- **手本**: FF のキャラ選択(人物が入れ替わる時の重さ)。
- **手間**: 小〜中。
- **影響**: スマホ=配置が変わる。PC=横長の時は今のままでよい(全身が横に出る配置のため)。
- **仕様変更か**: 当たらない。

### P14「一時停止はスマホで1列に」(ui_33)
- **問題**: スマホでも2列。左はボタン2つの下が7割空き、右に情報が詰まる。体力の帯が琥珀色で、HUD の紫の玉と色が違う。
- **案**: スマホ(縦長)は1列: 上に深さの円(今の右上の図)を大きく、その下に討伐と装備、**一番下の親指の位置に「続ける」**。体力の帯は HUD と同じ紫に。PC(横長)は今の2列のまま。
- **なぜ面白くなるか**: 一時停止が「戦況を眺める時間」になり、続けるボタンは親指の下にある。
- **手本**: DS2 の一時停止中の地図(地図が主役で、操作は端に寄る)。
- **手間**: 中。
- **影響**: スマホのみ(縦長の時だけ分岐)。PC は1px も動かさない。
- **仕様変更か**: 当たらない。

### P15「HUD の数字は動いた時だけ出る」(ui_31/34)
- **問題**: 討伐数の札2枚(右上)と「手榴弾 Lv1」の札(右中)が、数字が動かない時もずっと同じ濃さで出ている。
- **案**: 数字が変わらない間は、数秒かけて薄くなる(消えはしない)。数が増えた瞬間に元の濃さへ戻って一拍光る。目標を満たした時は札に印が押される。副武装の名前は、持ち替えた時とレベルが上がった時だけ出す。
- **なぜ面白くなるか**: 戦場が広く見え、増えた瞬間だけが目に入る。「あと1体」が光で分かる。
- **手本**: DS2 の HUD(要る時だけ出て、要らない時は引く)。
- **手間**: 小〜中。
- **影響**: スマホ・PC 共通。React は数字(プリミティブ)だけを購読し、薄くするのは CSS の不透明度の移り変わりで行う=毎フレームの再描画は増えない。負荷 1/10。
- **仕様変更か**: 当たらない。**ただし副武装の通知は「ブーメラン型に統一」の決まり(v0.25.2155)がある。名前の札は通知とは別物として扱う想定だが、社長に確認したい。**

### P16「PC の作戦室の文字を一段大きく」(ui_50)
- **問題**: 1280×720 で、英字の小注記(LOADOUT 等)や右の説明が非常に小さい。上部に 120px ほどの空きがある。
- **案**: 横長の時だけ、作戦室の文字と行の高さを一段上げ、地図と行を縦の中央に寄せる。
- **なぜ面白くなるか**: PC の距離から読める。地図が大きくなり、眺める楽しさが増す。
- **手本**: DS2(PC 版)の端末は、画面の距離に合わせた大きい文字。
- **手間**: 小。
- **影響**: PC のみ(横長の分岐)。スマホは1px も動かない(phone-guard で確認)。pc-guard も回す。
- **仕様変更か**: 当たらない。

### P17「書体を3つの役割で決める」(全画面)
- **問題**: 見出しの書体が画面ごとに違う。強化・開発・資料室・任務失敗・レベルアップ=明朝系、装備の見出しと任務詳細の「避難回廊」=ゴシック太字、作戦地域の札の「避難回廊」=明朝。明朝は `Georgia, "Hiragino Mincho ProN"` の直書きが components に12箇所あり、部品になっていない。
- **案**: 役割で決めて部品にする。**明朝=世界の名(地名・任務名・成否の題字)/ゴシック=操作と説明/数字=1書体**。装備の見出しをほかの画面にそろえ、同じ地名は画面が変わっても同じ書体で出す。
- **なぜ面白くなるか**: 明朝が出たら「この世界の言葉」と読めるようになり、地名や任務名に重みが乗る。
- **手本**: DS2(書体が少なく、役割がはっきりしている)。FF の題字の明朝。
- **手間**: 小(決まりと部品化)〜中(置き換え)。
- **影響**: スマホ・PC 共通。文字幅が変わる所は phone-guard の基準撮り直し。
- **仕様変更か**: 当たらない。過去の裁定: 英字は Rajdhani を作戦室だけで使う(UI_OVERHAUL §3-0)、全体は Orbitron 固定(font.ts)。この2つは触らない前提。
