# ミーミルの新技「紫の車輪」(回る全方位レーザー)

社長の言葉(2026-10-02):
「ミーミルの技追加。紫レーザーなんだけど、360度に発射して、そのレーザーが回転する。その中で移動すれば避けれるってやつ。
で、HP減ってきたらこの技が変化して、違いは、レーザー中に、追跡弾を撃ってくる。これはカウンター可能」

判断の物差し(CLAUDE.md): より面白くなる方。

## 1. 何をするか
- ミーミルが立ち止まり、体の中心から**6本の紫のレーザーを放射状に**撃つ。レーザーは**ゆっくり回る**(加速→一定→減速=慣性)。
- 避け方=**隙間(扇)の中に入って、回転に合わせて歩く**。止まっていると次の1本に轢かれる。
- 紫=カウンター不可(色と形の文法)。
- **HP60%以下(フェーズ2)では変化**: レーザーを回している間、**追跡弾**(赤い二重丸=全ボス共通の弾・カウンター可)を「2連→休み」の組で撃つ。
  弾は旋回に上限がある(=約140px手前から横へ切れば外せる)。追跡は一定時間で切れて直進になる。

## 2. なぜ面白いか(設計の芯)
- **近いほど楽・遠いほど苦しい**: 回転の角速度は一定なので、隙間の横の速さは距離に比例する(速さ=ω·r)。
  遠い(約250pxより外)と歩いても隙間に追いつけない=**寄る判断**を迫る(既存のレーザーは「発射の少し前の切り返しで照準を振り切る」技=読みの軸が違う)。
  一方で近すぎると隙間が細い(下の受け入れ条件)。=**ちょうどいい半径を探しながら回る**遊び。
- 回る向きは毎回ランダム(時計回り/反時計回り)。**溜めの間に予告線がじわっと回り始める**ので、撃つ前に向きが読める。
- フェーズ2の追跡弾: 隙間の中で回りながら、**2連の弾を1振りでまとめて返す**か、**回転と同じ向きへ早めに切って外すか**を毎回迫る
  (回転と逆へ切ると先を行くレーザーに自分から当たりに行く=切る向きにも読みがある)。2連は1回のカウンター窓に両方入る間合い=「1振りで2つ返る」手応え。
  ※カウンターは歩きながら振れる(移動は止まらない)ので、「立ち止まって返す」ジレンマは無い(設計監査 C-1)。

## 3. 流れ(状態)
`wheel-windup`(溜め 1500ms・静止)→ `wheel-fire`(5000ms・静止)→ `wheel-recover`(硬直)→ 追跡へ。
- 溜めの頭で: 向き(±1)と、最初の角 θ0 = (ヘイトの相手への角)+ π/本数(=相手は**隙間の真ん中**から始まる)を決める。
  フェーズ2かどうか(追跡弾を撃つか)もここで決めて持つ(途中でHPが割れても変わらない)。
- 角度は溜めの頭からの経過 t の**1本の純関数** `mimirWheelAngle(t)` で決める(予告線と判定と絵が同じ式を読む):
  - 溜め中: 角速度 0 → ωw(0.10rad/s)へ直線に上がる(=予告線がじわっと回り始める)。
  - 発射の頭 rampMs(900)で ωw → ωmax(0.42rad/s)へ。中盤は ωmax。最後の decelMs(600)で 0 へ減速。
  - 角速度が連続(慣性MUST)。角は単調(逆回転しない)。
- 判定: 発射中、6本それぞれ「中心→長さ MIMIR_LASER_RANGE」の線分±halfWidth(22)に相手(プレイヤー/守護霊)が入れば damage(30)。
  原点は**今のボスの中心**(押されたらレーザーごと動く=判定と絵が一致)。
  **1本の通過で当たるのは1回**(`mimirWheelLastHitK/At`。近くでは1本が1秒以上かけて通る=無敵1秒が明けてもう1回、を作らない・設計監査 B-3)。
  どの本にも居ないフレームで記録を消す=抜けてからもう一度入れば、また当たる。
  間引きの無敵は既存どおり**全ダメージ源で共通の1本**(damagePlayer の i-frame)。
- フェーズ2の追跡弾: 発射の頭から `mimirWheelShotOffsetMs(k)` = startMs(500) + ⌊k/2⌋·(pairGapMs 250 + restMs 1500) + (k mod 2)·pairGapMs に撃つ
  (5秒で3組6発)。速さ170・旋回上限0.75rad/s・追跡は homingMs(2200)で切れて直進・寿命5000ms・威力30(=レーザーと同じ。弾をわざと受けて
  無敵の間にレーザーを横切る、を得にしない・設計監査 A-4)。追跡するのは相手がプレイヤーの時だけ(守護霊が相手なら直進)。
  打ち返されたら追跡しない(**新しい規則**: 追跡の更新が `reflected` を見て止め、reflectProjectile が追跡の持ち物を落とす)。
- フィールド名(描画・判定・弾が同じ名前を読む): `mimirWheelAt`(溜めの頭=角度関数の t=0)/ `mimirWheelTheta0` / `mimirWheelDir` /
  `mimirWheelHoming`(変化か)/ `mimirWheelShots`(撃った数)/ `mimirWheelReadyAt`(CD)。弾は `hostileHomingTurn` / `hostileHomingUntil`。

## 4. 予告(赤い予告の掟)
- 紫の線(6本・全長)が**溜めの頭に出る**(掟②)。溜めの間は根元から先へ塗りが伸びる(ミーミルのレーザーと同じカラオケ塗り=掟①の唯一の例外と同じ見せ方)。
  塗りが先まで届いた瞬間=発射=予告線は消え、レーザー本体に替わる(掟③)。
  ※**事実として**: 掟①の例外は「ミーミル/バス停のレーザー(紫)のカラオケ塗り」の1件。この技はミーミルの紫レーザーなので同じ扱いにした。
  社長が流星に揃えたいなら差し替える(推薦はカラオケ=ミーミルのレーザーの読み方を1つに保つ)。
- 予告線は判定と同じ式で回る(溜め中も)。発射の瞬間、予告線のあった所にちょうどレーザーが出る。
- レーザー本体は当たり得る間ずっと見えている(掟④)。発射が終わった瞬間に判定は消え、絵は芯が細って消える(180ms・判定なし)。
- 追跡弾は弾の文法(赤い二重丸)=予告は持たない(既存の弾と同じ)。

## 5. 抽選・カウンター
- `MimirMove` に `wheel` を足す。重み melee15 / near20 / mid20 / far10。**CD 20秒・溜めの頭で打つ**(撃ち終わってから約13秒。気絶等で潰されても残る)。
- カウンター: 溜め・発射は紫=**カウンター不可**(HIDDEN_COUNTER_WINDUP_STATES に載せない・体当てでの中断も無し=既存レーザーの「発射直前だけ体当てで壊せる」専用機構は持たない)。
  硬直 `wheel-recover` は他の硬直と同じく体当て('body')で取れる。体幹への影響は既存のまま(この技で足さない)。
- 守護霊のAI台帳(ghostTelegraph)は 'none'(全方位に届く回る線=外へ逃げる円も帯1本も当てはまらない。守護霊は既存の被弾規則で受ける)。
- 台本: `wheel: ['wheel', 'dash', 'bite']`(回り終わって離れた相手へ突進→噛みつき。既存レーザーの台本と同じ形)。
- ボスメーカー: 「回る全方位レーザー」を再生ボタンとパネル(数値)に足す。

## 6. 数字(叩き台・`HIDDEN_MIMIR_TUNING.wheel`)
windupMs 1500 / fireMs 5000 / spokes 6 / halfWidth 22 / damage 30 / omegaWindup 0.10 / omegaMax 0.42 / rampMs 900 / decelMs 600 /
recover 900(下限つき)/ cdMs 20000 / homing { startMs 500, pairGapMs 250, restMs 1500, speed 170, turnRadS 0.75, homingMs 2200, lifeMs 5000, damage 30 }。

## 7. 受け入れ条件(テストで固定するもの)
1. 角度関数: t=0で0。角速度は連続(溜め→発射、加速→一定→減速の継ぎ目で飛ばない)。単調増加。発射の終わりで角速度0。
2. 隙間が抜けられる: 体の横の縁(ボス中心から幅の半分=112px)より外では、隙間の横幅 2πr/本数 − 2·halfWidth − 自機28 > 0。
   ※体の真上/真下(半身62px)のすぐ外は隙間がほぼ無い=縦に貼り付いて回ることはできない(意図: 寄りすぎは罰)。
3. 寄れば追いつける: 角速度 ωmax で、歩速(104.4)で追いつける半径(=歩速/ωmax)が体の縁より十分外(≥200px)。
4. 相手は隙間の真ん中から始まる: 溜め開始時点の相手の角と最寄りのレーザーの角の差 = π/本数。
5. 追跡弾の旋回: 1フレームで回る角は turnRadS·dt 以下。追跡時間を過ぎたら向きを変えない。
6. 打ち返した追跡弾は追跡しない。
7. 歩きで外せる: 歩速/旋回上限(=追い切れなくなる距離)≥ 130px。
8. 返せる: 2連の弾の間隔(速さ×pairGapMs)< カウンター窓(400ms)に弾が進む距離。組と組の休み > カウンターの1周期(820ms)。

## 8. 後始末・状態の漏れ
- ノックバックだけで止まっている間は、技の時計(溜めの頭の時刻・次の弾の時刻・状態の期限)を同じだけ繰り下げる(既存の規則)。
- 気絶・紫・罠などで潰れたら、既存どおり追跡へ戻る(レーザーは消える)。撃ち終わった追跡弾はそのまま飛ぶ。
- 記録に使う技名: 'mimir-wheel'(死因表示「回る光輪」)。

## 9. 負荷 1/10
判定=線分6本の距離計算/フレーム。絵=溜め中は線6本×6 stroke+円、発射中は線6本×3 stroke+円2/フレーム(投影影を落とす光源は足さない)。追跡弾=最大6発の向きの更新。
