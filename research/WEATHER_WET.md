## 2. 見た目(ステージ1・`?weather=wet`)
1. 色調整: 画面全体(世界の層)を少し彩度を落とし、青く冷たく、暗部をわずかに持ち上げる(1回の色行列)。HUD には掛けない。
2. 水たまり: 帯1・帯2の水たまりを地面に散らす(決まった乱数=出撃ごとに同じ配置でよい・道や拠点・壁・木の足元を避ける・地面の層=キャラより下)。帯2の小物を水たまりの周りに少し添える。
3. 映り込み: 水たまりの中にだけ、空の色・近くの松明/光だまりのにじみ・近くを通るキャラの逆さの薄い映りを描く(今ある地面の映り込みの仕組みを流用・水たまりの形で切る)。水面の端に細い光の線をときどきゆっくり走らせる。
4. 雫と波紋: 木の下でときどき雫→地面/水たまりに波紋(帯の波紋3コマ・少数を使い回し)。誰かが水たまりを踏んだら波紋。
5. 霧: 今の霧を少し薄く・冷たい色に。
6. 空: 雲の切れ間・月を少し明るく(今の空への色の掛け方で。空の素材が届いたら差し替え)。
- 慣性: 波紋の広がり・光の線・雫はすべて加速/減速つき。
- 負荷の目安 2/10(色行列1回・使い回しの粒・影を落とさない光)。ズーム最大引き(?zoomlock=0.4)で破綻しないこと。

## 4. 周回で天候を決める(社長指示2026-11-22「ステージ1の2周目は必ず雨の舞台にして。その後は晴れと雨でランダムで。」)
- **何周目か**は STAGE1_FIRST_LOOP.md §2 の定義に従う(クリアで進む・出撃の回数ではない):
  - 1周目 = この出撃が1周目(`isStage1FirstLoopRun`・端末の「1周目クリア済み」が未)。
  - 2周目 = 1周目クリア済みで、ステージ1は未クリア(城ボスの周。死んでも撤退しても2周目のまま=次も雨)。
  - 3周目以降 = ステージ1クリア済み(`getClearedStages` の stage-1)。
- **決め方**(純関数 `decideStageWeather`・`src/utils/weatherWet.ts`): 1周目=晴れ(月夜) / 2周目=必ず雨 / 3周目以降=晴れと雨を半々。
  - 乱数は出撃の開始(App の startGame)で1回だけ引き、`pendingStageWeather` → `resetGame` が store の `stageWeather` へ入れる。出撃の間は変えない(「もう一度プレイ」も出撃の開始なので引き直す)。
  - 周回に数えない出撃(ベンチ・練習(ボスモード)・ガントレット・ボス試験 `?castlenow` 等・`?smoke`)は晴れ。フリー(周回)出撃は端末の周回どおり(1周目にはならないので2周目か3周目以降)。
  - 開発用のツマミ `?weather=wet`(雨に固定)/ `?weather=clear`(晴れに固定)が全部に優先する。
- 描画(pixi)は `stageWeather` を読むだけ。雨に結び付く物(色行列・濡れた土・木の色・雲影・月明りの筋・霧・蛍・水たまりの絵の先読み)は全部この1つの値から出る(`syncWeatherWet` の `weatherWetOn`/`wetLightMix` を経由)。
- 新しい保存値は足していない(既存の「1周目クリア済み」と「ステージクリア」だけで決まる)。
