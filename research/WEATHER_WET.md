# ステージの天候「雨上がり」(設計書)

## 0. 社長の言葉(そのまま・2026-11-20)
- 「ステージの雰囲気を綺麗に少し変えるテクニックないかな」「ステージを周回ごとに少し雰囲気変えたりしたいんだよね」「雨上がりいいね、ステージ1でやってみたい」
- 素材(社長支給・原本は art-masters/weather-puddles-water-2026-11-20.png と weather-puddles-ground-2026-11-20.png)。

## 0-1. 「ではない」条件
- 敵・地形・当たり判定・遊びの中身は変えない(見た目だけ)。赤で画面を染めない(赤=敵の予告)。周回で切り替える仕組みは次の段(今回は URL で見比べられるまで)。数値は叩き台。

## 1. 素材(1枚の帯から切り出す・原本は加工しない)
- 帯1(水面の水たまり・897×34): 丸い水たまり5サイズ / 細長い3 / 小さい群れ2(1つ目は2つの塊が近接=まとめて1つ) / 波紋3コマ。
- 帯2(縁に草・土の水たまり・1216×34): 丸い5 / 細長い3 / 群れ2 / 小物6(小石・丸太・草・落ち葉・小枝・枝) / 波紋3コマ。
- 透明の隙間で区切る(近接の小塊は12px以内ならまとめる)。public/sprites/weather/ 以下へ置き、素材の台帳を更新。起動時には読まない組(このステージで雨上がりの時だけ)。

## 2. 見た目(ステージ1・`?weather=wet`)
1. 色調整: 画面全体(世界の層)を少し彩度を落とし、青く冷たく、暗部をわずかに持ち上げる(1回の色行列)。HUD には掛けない。
2. 水たまり: 帯1・帯2の水たまりを地面に散らす(決まった乱数=出撃ごとに同じ配置でよい・道や拠点・壁・木の足元を避ける・地面の層=キャラより下)。帯2の小物を水たまりの周りに少し添える。
3. 映り込み: 水たまりの中にだけ、空の色・近くの松明/光だまりのにじみ・近くを通るキャラの逆さの薄い映りを描く(今ある地面の映り込みの仕組みを流用・水たまりの形で切る)。水面の端に細い光の線をときどきゆっくり走らせる。
4. 雫と波紋: 木の下でときどき雫→地面/水たまりに波紋(帯の波紋3コマ・少数を使い回し)。誰かが水たまりを踏んだら波紋。
5. 霧: 今の霧を少し薄く・冷たい色に。
6. 空: 雲の切れ間・月を少し明るく(今の空への色の掛け方で。空の素材が届いたら差し替え)。
- 慣性: 波紋の広がり・光の線・雫はすべて加速/減速つき。
- 負荷の目安 2/10(色行列1回・使い回しの粒・影を落とさない光)。ズーム最大引き(?zoomlock=0.4)で破綻しないこと。

## 3. 受け入れ
- `?weather=wet` でステージ1が雨上がりになり、付けなければ今と1pxも変わらない。スマホの配置(HUD)は動かない。
