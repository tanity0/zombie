# 踏み込み回避(守護霊・幻影)— 設計書

状態は PROJECT_STATUS.md。この文書は仕様だけ。土台は research/AI_HUMANIZE.md の B1(コマ台帳=記録)・B2(守護霊の再生)。

## 0. 社長の言葉(2026-10-04・正本)
> 守護霊と幻影に、近接移動回避の概念を組み込みたい。詳しくは、スティック振り切った状態で指を離すと、移動してから近接を放つ操作が既存であるけど、これを利用して技などを回避する行動のこと。技の範囲内から、範囲外に、近接移動で 出る というトリガーの癖を学習する事になるのかな？と思う。

設計チャットの提案(①記録 ②守護霊 ③幻影の3段)に社長「はい」(2026-10-04)。

## 1. 用語と、いまの事実
- **踏み込み**: 走りながら(傾き0.7以上か実速度が基礎の75%以上)指を離した近接。**PC(キー/マウス/パッド)も同じ関数を通るので、実速度の判定で同じ踏み込みが出る。**前隙200msの頭90msで、離した瞬間の向き(`lastDirection`)へ**30px**(鞭20px)滑る。立ち/歩きで離すと0px(その場で振る)。無敵なし(接触ダメージだけ通らない)。カウンター窓(300ms)は押した瞬間に開く。
- 守護霊の踏み込みは**常にボスの方へ**30px(走り扱い固定)。回避は歩きだけ。
- 記録(B1のコマ)は「着弾の瞬間Tの立ち位置(図形に対する位置)」と「押した時刻(T基準)」だけ。**押した時に踏み込んだか・どちらへ踏み込んだかは録っていない。**
- 幻影は、プレイヤーの近接の範囲を危険として読んでいない(避けるのはプレイヤーの弾だけ)。

## 2. 記録(段L1)
### 2-1 何を足すか
コマ(`HabitEpisode`)に **`lg`(踏み込みの向き・任意の欄)** を1つ足す。そのコマに帰属した押下について:
| 値 | 意味 |
|---|---|
| 0 | 踏み込まなかった(立ち/歩きで離した=その場で振った) |
| 1 | **外へ**(その技の図形の外へ向かう向き。外向きとの角度が60°以内) |
| 2 | **横へ**(60°〜120°) |
| 3 | **内へ**(120°超=図形の中心・ボスの方へ) |
| 欄なし | 押していない(pressOfs=null)/旧データ/**踏み込みを持たない経路の振り**(刀の一閃・縮地・追撃など。押下時刻と踏み込みの始まりが揃わない) |

- 「外向き」は**押した瞬間の自分の位置**で、その州の図形(コマが既に持つ図形と同じもの)から出す:
  - 円: 円の中心 → 自分。
  - 帯: いちばん近い帯の軸から、自分のいる側への垂直。
  - 体: ボスの体(矩形)の最近点 → 自分(体の中なら中心 → 自分)。
- 踏み込みの向きは、押下と同じ瞬間にプレイヤーへ書かれる踏み込み速度(`lungeVx/lungeVy`)の向き。0なら `lg=0`。
- **押した位置**: 打刻(commit)は前隙の後=抜けた後なので使わない。`playerTraits` が**踏み込みの始まり**(`lungeUntil` が変わったフレーム)でプレイヤーの中心と向きを控え、押下時刻(`meleeSwingPressedAt`)と **50ms 以内**なら同じ押下とみなして添える。踏み込みの長さ90msは `MELEE_LUNGE_MS_REC` に写してある(本体の `MELEE_LUNGE_MS` との一致はテストで固定)。時計はどちらも実時間=混ざらない。
- **版は上げない**(`HABIT_EPISODE_FORMAT_VERSION` は pressOfs の意味が変わる時だけ。`lg` は欄の追加で、無いコマは「分からない」=今の動きのまま)。

### 2-2 記録しない場面(B1と同じ)
守護霊が出たラン・撃破+リザルトを通らなかったランは録らない(既存のゲートをそのまま通る)。

## 3. 守護霊の再生(段L2)
### 3-1 段1(その技のコマが3件以上)= 癖どおりに踏み込む
- **立ち位置**(品質監査 A-1): コマの位置は着弾の瞬間=**抜けた後**。抜けの記録(外・横)を目標にする時は、振るまでは**着弾時の位置から踏み込みの距離(30px)ぶん戻した点**(=抜ける前の位置)に立ち、抜けの振りを出した後は着弾時の位置へ立ち直す(中へ歩き戻らない)。
- 振る時刻は今のB2どおり(T−500msの位置に最も近いコマの pressOfs)。**同じコマの `lg` で踏み込みの向きを決める**:
  - 1 外 → いまの自分の位置での外向き(§2-1と同じ式)。
  - 2 横 → 外向きを90°回した向き(回る側=守護霊の今のオービットの向き)。
  - 3 内 → 今と同じ(ボスの方)。
  - 0 → **踏み込まない**(その場で振る)。
  - 欄なし → 今と同じ(ボスの方)。
- **外・横の踏み込みは「カウンター窓がTを覆わなくても振る」**(B2裁定#17「窓がTを覆えない記録では振らない」の例外)。この振りの目的は抜けることで、カウンターではないため。窓がTを覆う時だけカウンターの請求を積む(覆わない時は積まない=意図と請求を一致させる)。
  - **着弾を過ぎたら振らない**(CD待ち・pressOfs>0 の記録とも。着弾の後に抜けても意味が無い)。
  - 抜けの振りも**カウンターの周期(820ms)を消費する**(プレイヤーの抜けの振りも押した瞬間にカウンターのCDが回る=同じ条件)。
### 3-2 段2・段3(コマが足りない)= 既定の「当たる直前に外へ一直線」
- 条件(全部):
  1. 技ロールが**避ける**(`dodge`)。
  2. 標的が着弾時刻の分かる予告中(`windupImpactAt` あり)で、その州の図形が取れる(B2の再生と同じ図形)。
  3. 守護霊がその図形の**中**にいる。
  4. 着弾まで **180ms 以下**(踏み込み90ms+余裕)。
  5. 通常の近接CDが明けている。
- → 近接を出し、**外向きへ**踏み込む。カウンターの請求は積まない。1つの予告につき1回(鍵=標的×州×**構えた時に凍結した着弾時刻**。生の着弾時刻は賞金首のKB中などで後退しうるので鍵に使わない)。
- 技への反応の表(counter/hit/dodge)が無いプロファイル(固定の守護霊20体・新規)では「避ける」ロールが出ないので、この既定の抜けも出ない(意図: 抜けるのは「この技は避ける人」の写しだけ)。
- 図形が取れない技(B2の対象外の州)では出さない(今どおり歩いて避ける)。
### 3-3 変えないもの
- 踏み込みの距離・時間(プレイヤーと同じ式)・前隙・CD・カウンターの成立の判定・刀の一閃。
- カウンターを狙う振り(段3の `counter` ロール・段1でlgが内/なし)は今どおりボスの方へ。

## 4. 幻影(段L3)— 案2で決着(社長「守護霊と幻影も避けさせよう」2026-10-05)
### 4-0. 前提(事実)
- 幻影の中身は**その回の人格**(`phantomIdentity`)=固定の先人20人の誰か、またはオンラインの実プレイヤー。**あなた自身ではない**(旧§4の案2の「あなたの lg」は誤り=ここで直す)。
- 踏み込みの記録(コマの `lg`)は手元のプロファイルの `moveHabits` にある。**固定の20人は持っていない**(コマも技への反応表も無い)。**オンラインの共有プロファイルはコマを通さない**(`shared/ghostSanitize.mjs` が項目を選んで組み直す=`moveHabits` は落ちる)。⇒ 案2のために、送る時にコマから**抜け方の要約 `lungeStyle`**(抜ける割合・横の割合・先読み・コマ数)を作って載せ、サニタイザに通り道を足した(§4-2)。**サーバ側(wrangler)の再デプロイまでは、オンラインの人格も要約を持たない=既定で動く**。
- 幻影の近接: 前隙200ms・振り始めにプレイヤーの方へ踏み込む(`meleeLungePx`=30px、鞭持ちの人格は20px)・周期820ms(`PHANTOM_MELEE_PERIOD_MS`)・届く距離=幻影の中心からプレイヤーの矩形の最近点まで74px(`edgeDistTo`)。反応の下限は人間の250ms(`HUMAN_REACTION_MS`)。
- 幻影は今、プレイヤーの弾を**歩きで**横へ避けている(`projectileDodge`)。プレイヤーの近接の範囲は避けていない。
### 4-1. 何に対して抜けるか(2つ)
**(a) 弾**: プレイヤーの弾が自分に当たる線に乗っていて、**歩きでは抜け切れない**時に、弾の線から外れる向き(`projectileDodge` と同じ向き)へ踏み込む。
- 条件(全部): ①弾がまだ自分の手前にある ②弾の線から自分の中心までの横ずれ < 自分の半径(縦横の大きい方の半分)+弾の半径(=このままだと当たる。実際の当たりは矩形なので**広めに見積もる=踏み込みが多めに出る側**) ③着弾までの時間 t(弾の線に沿った距離÷弾速)のうちに、歩き(幻影の速さの上限×減速の倍率)では外れ切れない ④踏み込み(人格の踏み込み距離/90ms)+残りの歩きなら外れ切れる ⑤弾が出てから反応の下限(人格の反応・最低250ms)が経っている=**`nowMs − 弾の createdAt`(どちらも実時間)** ⑥近接の周期が明けている ⑦前隙中でない(カウンターで弾かれた tick も出さない)。
- 1発の弾につき1回(弾のidで覚える。直近24発だけ持つ)。(a)と(b)が同じtickに立ったら(a)。どちらも普段の振り(縁74以内)より先に見る。
**(b) 詰められた時**: プレイヤーが走って寄ってきて、プレイヤーの近接が届く距離に入る直前に、抜けの踏み込みを出す(見てから振りを避けるのは原理的に間に合わない=寄ってくる動きを読んで先に動く)。
- 「詰めてくる」= プレイヤーの速度(`vx/vy`)のうち幻影へ向かう成分が、プレイヤーの基礎の速さ(`speed`)の60%以上。これが**人格の反応時間以上続いている**(gameTime で測る)。
- 「届く距離」= プレイヤーの近接の届く距離(素手/刃=74px・鞭=鞭の長さ150px)+走りの踏み込み(`meleeLungePx`=30px・鞭20px)。距離はプレイヤーの中心から幻影の矩形の最近点。到達までの予測時間 t = (今の距離−届く距離)÷向かってくる速さ(既に内側なら0)。
- t ≤ 構えの先読み(下の表)になったら1回だけ判定する(詰めの1回ごと=向かう成分が60%を切ったら次の詰め)。その時に振れない(周期中・前隙中)なら判定を持ち越し、**振れるようになった最初の tick で判定する**(その時 t=0=既に届く内側、もあり得る=抜けが潰れない側)。
- 近接の周期が明けている・前隙中でない、の時だけ。
### 4-2. 抜け方を何から写すか(案2)
| 項目 | 人格が記録を持つ時(`lg` 付きで押したコマが3件以上) | 持たない時(固定の20人・記録の少ない人) |
|---|---|---|
| 記録の在りか | 手元のコマ(`moveHabits`)、オンラインは共有の要約(`lungeStyle`) | — |
| (b)で抜けるか | その人のコマ(全州を合算・押していて `lg` 付きのもの)のうち、外/横へ踏み込んだ割合で抽選 | 50%(叩き台) |
| 抜ける向き | 外/横をその人の割合で抽選。外=プレイヤーから離れる向き / 横=その垂直(回る側=今のオービットの向き) | 外 |
| 構えの先読み | その人の外/横のコマの押下時刻(着弾の何ms前に押したか)の中央値。120〜400msに収める(外/横が0件なら250ms) | 250ms |
- 抽選で抜けなかった時は今のまま(届けば普段どおりプレイヤーの方へ振る)。
- (a)の弾の向きは記録を使わない(線から外れる向きは1つに決まる)。
- ★AI_HUMANIZE の大原則「幻影は対幻影戦の数値だけ」(社長裁定2026-08-28)の**例外**になる(社長が案2を選んだ=2026-10-05)。例外は**この踏み込み回避の(b)だけ**。他の癖は今のまま。
### 4-3. 振りの扱い
- 抜けの踏み込みは**近接の振りそのもの**(プレイヤーと同じ=振らずに踏み込む手段は無い)。前隙200ms・カウンター窓・周期820msの消費・SE・絵は普段の振りと同じ。**振る向き(当たり・斬撃の絵=`gpSwingAngle`)はプレイヤーの方**のまま、**滑る向きだけ**抜ける向きにする(`gpLungeAngle`)。描画の本体の踏み込み(22pxの視覚の揺れ)も `gpLungeAngle` の向きへ出す=体と絵が逆へ割れない(品質監査 A-2)。
- 届かない振りは空を切る(プレイヤーが空振りするのと同じ)。届けば当たる=詰めてきた相手に「引きながらの一太刀」になる。プレイヤーは①その振りをカウンターする ②周期の820msの間に追い付いて斬る、で返せる。
### 4-4. 変えないもの
- 歩きでの弾避け・間合いの取り方・普段の振り(縁74px以内で周期が明けたら前へ踏み込んで振る)・カウンターとパリィの裁き・ダメージ。

## 5. 受け入れ条件
1. 走りながら離した近接が予告の中で出た時、その州のコマに `lg`(1〜3)が付く。立ち/歩きで離した時は `lg=0`。押していないコマには付かない。
2. 段1の守護霊は、外へ踏み込んだ記録が最も近いコマの時、**図形の中(抜ける前の位置)から**着弾前に外へ踏み込んで出る(窓がTを覆わなくても振る・着弾を過ぎたら振らない)。内/欄なしは今どおりボスの方へ。0は踏み込まない。
3. 段2・3の守護霊は、`dodge` ロールの予告で図形の中にいて着弾180ms前になったら、外へ踏み込む(予告につき1回)。
4. `counter` ロール・`tank` ロール・B2対象外の州の動きは今と変わらない。
5. 外・横の踏み込みでカウンターの請求は積まない(窓がTを覆う時だけ積む)。
6. 幻影: プレイヤーの弾が線に乗っていて歩きでは外れ切れない時、弾の線から外れる向きへ踏み込む(弾1発につき1回・反応の下限より早くは出ない)。
7. 幻影: プレイヤーが走って詰めてくると、届く直前(既定250ms前)に抽選で(既定50%)、プレイヤーから離れる向きへ踏み込みながら振る。記録を持つ人格は、その人の抜けの割合・向き・時刻で。
8. 幻影の抜けの振りも、普段の振りと同じくカウンターでき、周期を消費する。

## 6b. 積んだもの(品質監査の(B)・この巡では直さない)

- (段L3 検収)(a)はプレイヤー側の弾を全部弾として扱う(照明弾・ドローン等の当たらない物にも踏み込み=周期を浪費)。既存の歩き避けも同じ扱い=絞るなら両方同時に。
