# 踏み込み回避(守護霊・幻影)— 設計書

状態は PROJECT_STATUS.md。この文書は仕様だけ。土台は research/AI_HUMANIZE.md の B1(コマ台帳=記録)・B2(守護霊の再生)。

## 0. 社長の言葉(2026-10-04・正本)
> 守護霊と幻影に、近接移動回避の概念を組み込みたい。詳しくは、スティック振り切った状態で指を離すと、移動してから近接を放つ操作が既存であるけど、これを利用して技などを回避する行動のこと。技の範囲内から、範囲外に、近接移動で 出る というトリガーの癖を学習する事になるのかな？と思う。

設計チャットの提案(①記録 ②守護霊 ③幻影の3段)に社長「はい」(2026-10-04)。

## 1. 用語と、いまの事実
- **踏み込み**: 走りながら(傾き0.7以上か実速度が基礎の75%以上)指を離した近接。**PC(キー/マウス/パッド)も同じ関数を通るので、実速度の判定で同じ踏み込みが出る。**前隙200msの頭90msで、離した瞬間の向き(`lastDirection`)へ**30px**(鞭20px)滑る。立ち/歩きで離すと0px(その場で振る)。無敵なし(接触ダメージだけ通らない)。カウンター窓(300ms)は押した瞬間に開く。
- 守護霊の踏み込みは**常にボスの方へ**30px(走り扱い固定)。回避は歩きだけ。
- 記録(B1のコマ)は「着弾の瞬間Tの立ち位置(図形に対する位置)」と「押した時刻(T基準)」だけ。**押した時に踏み込んだか・どちらへ踏み込んだかは録っていない。**
- 幻影は、プレイヤーの近接の範囲を危険として読んでいない(避けるのはプレイヤーの弾だけ)。

## 2. 記録(段L1)
### 2-1 何を足すか
コマ(`HabitEpisode`)に **`lg`(踏み込みの向き・任意の欄)** を1つ足す。そのコマに帰属した押下について:
| 値 | 意味 |
|---|---|
| 0 | 踏み込まなかった(立ち/歩きで離した=その場で振った) |
| 1 | **外へ**(その技の図形の外へ向かう向き。外向きとの角度が60°以内) |
| 2 | **横へ**(60°〜120°) |
| 3 | **内へ**(120°超=図形の中心・ボスの方へ) |
| 欄なし | 押していない(pressOfs=null)/旧データ/**踏み込みを持たない経路の振り**(刀の一閃・縮地・追撃など。押下時刻と踏み込みの始まりが揃わない) |

- 「外向き」は**押した瞬間の自分の位置**で、その州の図形(コマが既に持つ図形と同じもの)から出す:
  - 円: 円の中心 → 自分。
  - 帯: いちばん近い帯の軸から、自分のいる側への垂直。
  - 体: ボスの体(矩形)の最近点 → 自分(体の中なら中心 → 自分)。
- 踏み込みの向きは、押下と同じ瞬間にプレイヤーへ書かれる踏み込み速度(`lungeVx/lungeVy`)の向き。0なら `lg=0`。
- **押した位置**: 打刻(commit)は前隙の後=抜けた後なので使わない。`playerTraits` が**踏み込みの始まり**(`lungeUntil` が変わったフレーム)でプレイヤーの中心と向きを控え、押下時刻(`meleeSwingPressedAt`)と **50ms 以内**なら同じ押下とみなして添える。踏み込みの長さ90msは `MELEE_LUNGE_MS_REC` に写してある(本体の `MELEE_LUNGE_MS` との一致はテストで固定)。時計はどちらも実時間=混ざらない。
- **版は上げない**(`HABIT_EPISODE_FORMAT_VERSION` は pressOfs の意味が変わる時だけ。`lg` は欄の追加で、無いコマは「分からない」=今の動きのまま)。

### 2-2 記録しない場面(B1と同じ)
守護霊が出たラン・撃破+リザルトを通らなかったランは録らない(既存のゲートをそのまま通る)。

## 3. 守護霊の再生(段L2)
### 3-1 段1(その技のコマが3件以上)= 癖どおりに踏み込む
- **立ち位置**(品質監査 A-1): コマの位置は着弾の瞬間=**抜けた後**。抜けの記録(外・横)を目標にする時は、振るまでは**着弾時の位置から踏み込みの距離(30px)ぶん戻した点**(=抜ける前の位置)に立ち、抜けの振りを出した後は着弾時の位置へ立ち直す(中へ歩き戻らない)。
- 振る時刻は今のB2どおり(T−500msの位置に最も近いコマの pressOfs)。**同じコマの `lg` で踏み込みの向きを決める**:
  - 1 外 → いまの自分の位置での外向き(§2-1と同じ式)。
  - 2 横 → 外向きを90°回した向き(回る側=守護霊の今のオービットの向き)。
  - 3 内 → 今と同じ(ボスの方)。
  - 0 → **踏み込まない**(その場で振る)。
  - 欄なし → 今と同じ(ボスの方)。
- **外・横の踏み込みは「カウンター窓がTを覆わなくても振る」**(B2裁定#17「窓がTを覆えない記録では振らない」の例外)。この振りの目的は抜けることで、カウンターではないため。窓がTを覆う時だけカウンターの請求を積む(覆わない時は積まない=意図と請求を一致させる)。
  - **着弾を過ぎたら振らない**(CD待ち・pressOfs>0 の記録とも。着弾の後に抜けても意味が無い)。
  - 抜けの振りも**カウンターの周期(820ms)を消費する**(プレイヤーの抜けの振りも押した瞬間にカウンターのCDが回る=同じ条件)。
### 3-2 段2・段3(コマが足りない)= 既定の「当たる直前に外へ一直線」
- 条件(全部):
  1. 技ロールが**避ける**(`dodge`)。
  2. 標的が着弾時刻の分かる予告中(`windupImpactAt` あり)で、その州の図形が取れる(B2の再生と同じ図形)。
  3. 守護霊がその図形の**中**にいる。
  4. 着弾まで **180ms 以下**(踏み込み90ms+余裕)。
  5. 通常の近接CDが明けている。
- → 近接を出し、**外向きへ**踏み込む。カウンターの請求は積まない。1つの予告につき1回(鍵=標的×州×**構えた時に凍結した着弾時刻**。生の着弾時刻は賞金首のKB中などで後退しうるので鍵に使わない)。
- 技への反応の表(counter/hit/dodge)が無いプロファイル(固定の守護霊20体・新規)では「避ける」ロールが出ないので、この既定の抜けも出ない(意図: 抜けるのは「この技は避ける人」の写しだけ)。
- 図形が取れない技(B2の対象外の州)では出さない(今どおり歩いて避ける)。
### 3-3 変えないもの
- 踏み込みの距離・時間(プレイヤーと同じ式)・前隙・CD・カウンターの成立の判定・刀の一閃。
- カウンターを狙う振り(段3の `counter` ロール・段1でlgが内/なし)は今どおりボスの方へ。

## 4. 幻影(段L3)— ★未決 #1
- 幻影の「技」は**プレイヤーの攻撃**。プレイヤーの近接は前隙200msしかなく、幻影の反応の下限(人間の反応=250ms)より短い=**見てから外へ抜けるのは原理的に間に合わない**。
- 軸が2つある(品質監査 A-5): **何に対して抜けるか**と、**抜け方(向き・時刻)を何から写すか**。
- 選べる案:
  - (案1) **弾だけ**: プレイヤーの弾が自分の線に乗っていて、歩きでは抜け切れない時に横へ踏み込む。写しは不要(見てから間に合う)。
  - (案2) 案1+**詰められたら抜ける**。プレイヤーが走って寄ってきて間合いに入る瞬間を「来る」と読んで踏み込む。**抜け方は対ボス戦で録ったあなたの `lg` と時刻を使う**。※AI_HUMANIZE の大原則「幻影は対幻影戦の数値だけ」(社長裁定2026-08-28)の変更が要る。
  - (案3) 案1+詰められたら抜ける。**抜け方は対幻影戦で新しく録ってから使う**(大原則どおり。録り溜まるまで出ない=第2弾・AI_HUMANIZE ★未決#4と同じ扱い)。
- 推薦=案2。対幻影戦で「自分の得意な抜け方を、自分の癖のまま相手にされる」が初戦から出る。案3は大原則に沿うが、録り溜まるまで何も起きない。

## 5. 受け入れ条件
1. 走りながら離した近接が予告の中で出た時、その州のコマに `lg`(1〜3)が付く。立ち/歩きで離した時は `lg=0`。押していないコマには付かない。
2. 段1の守護霊は、外へ踏み込んだ記録が最も近いコマの時、**図形の中(抜ける前の位置)から**着弾前に外へ踏み込んで出る(窓がTを覆わなくても振る・着弾を過ぎたら振らない)。内/欄なしは今どおりボスの方へ。0は踏み込まない。
3. 段2・3の守護霊は、`dodge` ロールの予告で図形の中にいて着弾180ms前になったら、外へ踏み込む(予告につき1回)。
4. `counter` ロール・`tank` ロール・B2対象外の州の動きは今と変わらない。
5. 外・横の踏み込みでカウンターの請求は積まない(窓がTを覆う時だけ積む)。

## 6b. 積んだもの(品質監査の(B)・この巡では直さない)
- 帯の外向きは垂直方向だけ=帯の**端**(軸方向)から出る抜けは「横」に分類される。
- 円の中心ぴったり(外向きが決められない)は「内」に倒している(再生は今どおりボスの方へ)。
- `lg` は「押した時に図形の中にいたか」を見ない(外から更に離れた振りも「外」)。KB中の押下は実際には踏み込まないが `lg` は付く。
- 段2では回避抑止(族平均位置への位置取り)中に既定の抜けが出る=整合の確認だけ。
- 体だけの州(`giantbat:g-bolt-windup` は弾技)で「体から外へ」は弾を避けない。
