## 1. 今の作り(事実)
- ステージ7の初回だけ、戦闘前の会話が**時間を止めずに**流れる(`campaign.ts` stage-7 の `dialogue`):
  1. グレン「きてくれたか……」
  2. ミラ「本部が襲われたのは、私たちのせいなの」
  3. ミラ「でも、薬はできた」
  4. ミラ「最後に、一つだけお願い」
  5. ミラ「……終わらせてあげて！」(`GLEN_FINAL_LINE`)
  6. グレン「グガガガガガガガガ！」(`GLEN_ROAR_LINE`・変異した顔の立ち絵。5行目が表示に入った時に useGameLoop が積む)
- 6行目の表示が終わると(`utils/glenIntro.isGlenBossSpawnReady`)、**その時のプレイヤーの位置から北へ 380px**(`STORY_BOSS_SPAWN_DIST`)に第一形態(giantbat・stage-7)が湧き、出現の輪・光・破片と登場カットインが出る。
- 既読後・再挑戦は会話データが空(`introSkipped`)=即出現。
- 場には誰も立っていない。**単独の**人間のグレンの絵は無い(グレンとミラが並んだ二人組の場の絵 `quest-futari.png` 94×66 は他のステージで使っている)。
- 会話はプレイヤーの操作で早送り・閉じる手段が無い(`updateNpcDialogue` の時刻だけで進む)。アテンション中は会話の時計が止まる(v0.25.3989)。

## 2. 作るもの
### 2-1. 素材
- 社長支給の2枚(チャットに添付・透過PNG・原寸。セッションの uploads に `e7787775-image.png`=苦しむ 51×65 / `b9dc5273-image.png`=立ち姿 35×64)を `public/sprites/npc/` に入れる(原盤=寸法そのまま):
  - `glen-human-stand.png`(35×64)/ `glen-human-suffer.png`(51×65)
- `npm run assets:ledger` で台帳を更新。2枚で数KBなので遅延組には入れない(起動時常駐でよい)。
- **大きさ**: 二人組の場の絵 `quest-futari.png`(高さ66 → 場では `EVENT_NPC_TARGET_HEIGHT`=108 に合わせて描く)と同じ倍率=**108/66 を2枚とも同じに掛ける**(1枚ずつ高さに合わせない=体の大きさが絵ごとに変わらない)。遠近の縮み・ズームは他の人物と同じ扱い。
- **2枚の切り替えで体が横に跳ばない**: 2枚とも「足元の行の不透明画素の横の中心」を足元の点に合わせる(実装時に画素から測って定数にする)。下端は2枚とも足元。
- **向き**: 反転しない(絵のまま)。

### 2-2. 流れ(社長指示2026-11-25「会話の変身直前にフェードインさせて、カメラ寄せてズームして変身」)
**会話の1〜5行目(グレン「きてくれたか……」〜ミラ「……終わらせてあげて！」)の間は、今までどおり場に誰も居ない。** 変身の直前から、時間を止めた寄りの中で一続きに見せる。
- **始まり**: 咆哮の行(`GLEN_ROAR_LINE`)が表示に入った瞬間。
- **位置**: 今のボス出現と同じ式=その時のプレイヤーの中心から北へ `STORY_BOSS_SPAWN_DIST`(380px)。**ボス(当たり判定 120×120)の箱**を `clampRectToPlayableArea` で行ける帯に収め、その**箱の下辺の中央=人間のグレンの足元**とする。第一形態はこの箱にそのまま出す(=人間が立っていた足元にボスの足元が来る)。※今のボス出現は帯に収めていないので、出現位置が帯の外になる場合だけ変わる。
- **時間を止めて寄る**: 始まりの瞬間に、人間のグレンの体の中心へアテンション(`triggerAttention`・時間停止・寄り)を張る。ホールドは下の場面の尺ぶん延ばす(`extraHoldMs`)。**時間が止まるのでプレイヤーは動けない**=プレイヤーの上にボスが湧く事故・南へ歩いて見逃す事故は起きない。会話の時計もアテンション中は止まる(既存の凍結)=咆哮の文字は場面の間ずっと出ている。
- **場面の時計**: アテンション中はゲーム時間が止まるので、場面の全ての動き(フェード・震え・光の脈・沈み・よろめき)は**実時間(`Date.now()`)の、場面の開始からの経過**で決める。光・輪も実時間で消える既存の物を使う(=時計が揃う)。
- **段取り(実時間・叩き台。合計 約2.6秒)**:
  | 時刻 | 場の人間のグレン |
  |---|---|
  | 0〜450ms | 立ち姿で**現れる**: 下から体の高さの8%ぶん上がりながらフェードイン(ease-out)。カメラは寄りの途中。 |
  | 450〜700ms | 立ち姿で止まる(ごく小さく肩の上下=位置だけ・体の高さの1.5%) |
  | 700ms | **苦しむ絵へ切り替え**+**膝が落ちる**: 下へ体の高さの6%沈む(速く落ちて、底で少し跳ね返る)。呻き=既存の `zombie-growl` を低い音程(0.7)・控えめな音量で1回。胸の赤い光の1回目。 |
  | 700〜2300ms | **苦しみが強くなる(4段・400msごとに1段)**。下の表。 |
  | 2300〜2600ms | 震え最大のまま、胸の光が速く強く脈打つ(80msおき)。 |
  | 2600ms | **弾ける**: 今のボス出現の輪・光・破片・フラッシュを、人間のグレンの胸の高さの点を中心にそのまま出す。同時に人間のグレンは 120ms で消える(弾けの光の中・ease-in)。**同じ瞬間に第一形態を 2-2 の箱に出す**。咆哮の行はここで閉じる(以後ボス出現の扱いは今までどおり=登場カットインは今のアテンションの後に続けて出る=既存の保留箱)。 |
- **苦しみの段(数値は叩き台・「動きは大きく」に従い、寄ったズームで読める大きさ)**:
  | 段 | 震え(位置の揺れ・左右) | 震えの速さ | 胸の赤い光 | よろめき |
  |---|---|---|---|---|
  | 1 | 体の高さの2% | 9Hz | 600msおき・控えめ | なし |
  | 2 | 3% | 12Hz | 450msおき | 段の頭で横へ体の高さの8%(行って戻る・慣性つき) |
  | 3 | 4.5% | 16Hz | 300msおき・明るく | 段の頭で逆側へ10% |
  | 4 | 6% | 20Hz | 180msおき・最も明るい | 段の頭で膝がもう一段落ちる(3%) |
  - 震えは等速の正弦にしない(段ごとに揺れの間隔を少しずつ乱す)。呻きは段2と段4の頭で1回ずつ(音程を 0.65・0.6 と下げる)。
  - **胸の赤い光**: `spawnGlow` を `noShadow`(投影影を落とさない)で、半径は `STRONG_GLOW_RADIUS` 未満の範囲で一番大きく(小さくされる倍率 `SMALL_GLOW_RADIUS_SCALE` が掛かることを見込んで決める)、色は赤(`rgba(239,68,68,`)。点は人間のグレンの足元から体の高さの55%上=新方式(proj)では足元を投影し高さを `projLiftPointInto` で上げた点に置く(エフェクトが地面の座標で置かれる仕組みに合わせて、描画側で持ち上げる)。
- **出す/出さないの条件は1つの関数にまとめる**: 人間のグレンの場面を出す条件 = **今のボス出現の条件と同じ組み合わせ**(`isM7 && !introSkipped && !cineSuppress && !FORCE_GATEBOSS && (!noSpawn || practiceWantsCastleBoss())`)。既読・再挑戦(`introSkipped`)では場面を出さず、今までどおり即出現。ボスメーカーからの出撃でも出さない(初回会話が無い経路)。
- **状態の置き場所**: store に `glenTransform: { startedAt: number(実時間); footX; footY; bossBox } | null` を持ち、`resetGame` で null に戻す。段・時刻の計算は純関数(`src/utils/glenIntro.ts` に足す)にしてテストする。pixi はこれを読んで描くだけ。
- **場面の途中で終わる時**: プレイヤーが倒れる・ステージを抜けるなどアテンションが途中で切れた時は、人間のグレンを消し、ボスは今のゲートどおりに出す(人間のグレンとボスが両方残る/どちらも出ない、を作らない)。
- **ミラは場に立たせない**(社長確認2026-11-25)。

### 2-3. 決まり
- **人間のグレンは絵だけ**。当たり判定・弾の的・敵の狙い・押し合いを持たない(敵配列に入れない)。
- **上下の5つの副作用**(CLAUDE.md の表): 北へ置くので ①地平線フェード ②帯の外の減光 ③遠近の縮み ④可視域 ⑤行ける帯 を確かめる。行ける帯に収め、ボスと同じ遠近の扱いで描く(新方式 proj では足元を `projectInto`)。
- 慣性: 現れる・沈む・よろめき・消える、の全てに加減速を入れる。
- **絵の伸縮・回転で苦しさを出さない**(震え・沈み・よろめき=位置の移動だけ)。二人組の場の絵の描画の前例にある拡大縮小の呼吸(`breathX/breathY`)は**真似しない**。
- **元からあるエフェクトは消さない**(ボス出現の輪・光・破片・カットイン・咆哮の会話はそのまま。出す中心の点だけ人間のグレンに合わせる)。
- 負荷: スプライト1枚+`noShadow` のグローと既存のリングだけ。強glow・投影影の光源は足さない。

### 2-4. 対象外
- 第一形態→第二形態の変わり目(残り1/3で「討伐」の帯→崩れる→第二形態)は今回触らない(別件で社長に提案済み・未決)。
- 会話の文言は一言一句変えない(統合正本の確定稿)。
- ミラを場に立たせることはしない。

## 3. 受け入れ条件
1. 初回のステージ7で、会話の1〜5行目の間は場に人間のグレンは居ない。咆哮の行が表示に入った瞬間に時間が止まり、カメラが北の一点へ寄り、立ち姿の人間のグレンが慣性つきで現れる(画面に見える)。
2. 約0.7秒で苦しむ絵へ変わり膝が落ち、震え・赤い光の脈打ち・よろめきが段ごとに強くなる(寄った画面で読み取れる大きさ)。
3. 約2.6秒で赤い光が弾け、人間のグレンが消え、同じ足元に第一形態が現れ、続けて登場カットインが出る。人間のグレンとボスが同時に見えるのは弾けの光に隠れた短い重なりだけ。
4. 既読・再挑戦・`?cine=1`・`?nospawn=1`・ボスメーカーでは人間のグレンは出ず、今までどおり。
5. 人間のグレンは当たり判定を持たない。場面の間プレイヤーは動けない(時間停止)。
6. スマホ 430×932 と PC 1280×720 で、寄った画面の人間のグレンの大きさが二人組の場の絵の人物と同じ倍率で描かれている(撮って確かめる)。2枚の切り替えで体が横に跳ばない。
7. `?zoomlock=0.4` で破綻しない。
