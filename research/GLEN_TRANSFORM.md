# ステージ7 グレンの変身の場面(人間の姿 → 苦しむ → 第一形態)

## 0. ゴール(社長の言葉)
- 「ステージ7のグレンが変身するシーンってできあがってる？苦しそうにするところ」
- 支給の絵2枚(立ち姿・体を折って苦しむ姿)を見せて「これだよ」。
- 今ある戦闘前の会話に合わせて、場の人間のグレンを動かす案に「はい」(2026-11-25)。

## 1. 今の作り(事実)
- ステージ7の初回だけ、戦闘前の会話が**時間を止めずに**流れる(`campaign.ts` stage-7 の `dialogue`):
  1. グレン「きてくれたか……」
  2. ミラ「本部が襲われたのは、私たちのせいなの」
  3. ミラ「でも、薬はできた」
  4. ミラ「最後に、一つだけお願い」
  5. ミラ「……終わらせてあげて！」(`GLEN_FINAL_LINE`)
  6. グレン「グガガガガガガガガ！」(`GLEN_ROAR_LINE`・変異した顔の立ち絵。5行目が表示に入った時に useGameLoop が積む)
- 6行目の表示が終わると(`utils/glenIntro.isGlenBossSpawnReady`)、**その時のプレイヤーの位置から北へ 380px**(`STORY_BOSS_SPAWN_DIST`)に第一形態(giantbat・stage-7)が湧き、出現の輪・光・破片と登場カットインが出る。
- 既読後・再挑戦は会話データが空(`introSkipped`)=即出現。
- 場には誰も立っていない。人間のグレンの絵はプロジェクトに無い。

## 2. 作るもの
### 2-1. 素材
- 社長支給の2枚を `public/sprites/npc/` に入れる(原盤=寸法そのまま):
  - `glen-human-stand.png`(35×64・立ち姿)
  - `glen-human-suffer.png`(51×65・体を折って苦しむ姿)
- 大きさは他の人物(衛生兵 `medic-walk` 1コマ高さ66 等)と同じ縮尺で描かれている前提。画面に並べて撮って確かめる。
- `npm run assets:ledger` で台帳を更新。読み込みは stage-7 だけで使うので、遅延組に入れられるなら入れる(`DEFERRED_SPRITE_GROUPS`)。

### 2-2. 流れ(会話の行に同期。時間は止めない=今の会話と同じ)
| 会話 | 場の人間のグレン |
|---|---|
| 会話が始まる(1行目が表示に入る) | **置く位置を決める**: その時のプレイヤーの位置から北へ `STORY_BOSS_SPAWN_DIST`(380px)を、行ける帯(`clampRectToPlayableArea`)に収めた点。立ち姿で**慣性つきで現れる**(下から少しずれて上がりながらフェードイン・約400ms・ease-out)。以後この位置は動かさない。 |
| 1行目 グレン「きてくれたか……」 | 立ち姿のまま。ごくわずかな呼吸の上下(位置の移動だけ・絵は伸縮しない)。 |
| 2行目 ミラ 表示に入った瞬間 | **苦しむ絵へ切り替え**。切り替えの瞬間に小さく沈む(膝が落ちる:下へ数px・慣性つき)。 |
| 2〜5行目 | **苦しみが段ごとに強くなる**(行が進むたびに1段上がる。4段): ①絵の小刻みな震え(位置の揺れ。振幅と頻度が段で増える) ②胸のあたりの赤い光の脈打ち(既存のグロー/リングの素材。間隔が段で短く、明るさが段で増える) ③時々よろめく(横へ数px・慣性つき)。呻き声は既存の SE から選ぶ(段の切り替わりで1回)。 |
| 6行目 咆哮が表示に入った瞬間 | 震え最大・赤い光が強く脈打つ。 |
| 6行目の表示が終わる=今のボス出現の時刻 | **赤い光が弾ける**(既存の出現の輪・光・破片をそのまま使う)と同時に人間のグレンは消え(弾けの白/赤に隠れて短くフェード・慣性つき)、**第一形態がその人間のグレンが立っていた点に現れる**(今のプレイヤー基準の位置ではなく)。以降の登場カットイン・戦闘は今のまま。 |

### 2-3. 決まり
- **人間のグレンは絵だけ**。当たり判定・弾の的・敵の狙い・押し合いを持たない(敵配列に入れない)。プレイヤーは重なって通れる。
- **出す/出さない**: ステージ7の初回(会話が流れる時)だけ。`introSkipped`(既読・再挑戦)・`?cine=1`・`?nospawn=1`・ゲート2練習など、今ストーリーボスを出さない条件では人間のグレンも出さない。ボスメーカー(練習)からの第一形態/第二形態の出撃では出さない。
- 会話がプレイヤーの操作で早送り/閉じられた場合も、**ボスが出る時刻=人間のグレンが消えて弾ける時刻**は必ず一致させる(人間のグレンが残ったままボスが出る/ボスが出ずに消える、を作らない)。プレイヤーが倒れた・ステージを抜けた時は人間のグレンも消す。
- 判定は world/store/utils 側(どの行か→段、位置の決定)を純関数にしてテストする(`src/utils/glenIntro.ts` の並び)。描画(pixiScene)は読むだけ。
- **上下の5つの副作用**(CLAUDE.md の表): 北へ置くので ①地平線フェード ②帯の外の減光 ③遠近の縮み ④可視域 ⑤行ける帯 を確かめる。行ける帯に収め、ボスと同じ遠近の扱いで描く(新方式 proj では足元を `projectInto`、高さは `projLiftPointInto`)。
- 慣性: 出現・切り替えの沈み・よろめき・消える、の全てに加減速を入れる。
- **絵の伸縮・回転で苦しさを出さない**(震え=位置の揺れ、だけ。歪みの代用モーションは使わない)。
- **元からあるエフェクトは消さない**(ボス出現の輪・光・破片・カットイン・咆哮の会話はそのまま)。
- 負荷: スプライト1枚+既存のグロー/リングを段の切り替わりで出すだけ。強glow・投影影の光源は足さない。

### 2-4. 対象外
- 第一形態→第二形態の変わり目(残り1/3で「討伐」の帯→崩れる→第二形態)は今回触らない(別件で社長に提案済み・未決)。
- 会話の文言は一言一句変えない(統合正本の確定稿)。
- ミラを場に立たせることはしない。

## 3. 受け入れ条件
1. 初回のステージ7で、1行目が表示に入るとプレイヤーの北(行ける帯の中)に人間のグレンが立ち姿で慣性つきに現れ、画面に見える。
2. 2行目が表示に入った瞬間に苦しむ絵へ変わり、2→5行目で震え・赤い光の脈打ちが段ごとに強くなる。
3. 咆哮の表示が終わった瞬間に、人間のグレンが消え、同じ点で赤い光が弾けて第一形態が現れる。人間のグレンとボスが同時に見えるフレームが、弾けの光に隠れた短い重なり以外に無い。
4. 既読・再挑戦・`?cine=1`・`?nospawn=1`・ボスメーカーでは人間のグレンは出ず、今までどおり。
5. 人間のグレンは当たり判定を持たない(弾が当たらない・敵が狙わない・押されない)。
6. スマホ 430×932 と PC 1280×720 で、人間のグレンの大きさが他の人物と揃って見える(撮って確かめる)。
7. `?zoomlock=0.4` で破綻しない。
