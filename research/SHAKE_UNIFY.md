# 揺れの整理(プレイヤー起因のダメージ揺れを1本にする)— 相談用設計案 v2(監査1巡を反映)

- 発端: 社長 2026-09-14「揺れについては一度綺麗に整理したい。銃だけじゃなくて、近接攻撃とか爆発とかその他プレイヤーが使うダメージも含めて、
  全てのプレイヤーから発せられるダメージに対して一気にできた方がいい。純粋なダメージに対する揺れ幅と、爆発・クリティカル・キルなど特殊な
  パターンにはさらに倍率をかけるのがクリアなのでは」。
- 状態: **社長承認2026-09-14(「はい」=§4 の推薦どおり)→ v0.25.4284 で実装済み。数値は叩き台=実機で絞る。** §1 は実装前の実態(事実の記録)。
- 実装の要点(v0.25.4284): `src/utils/impactShake.ts`(純関数+テスト)/ store `registerImpact`→`flushImpacts`(tick末・useGameLoop)/ `damageEnemy` の自動登録
  (旧 `nonLethalBoss` 旗を `blast`=爆風の印に再利用)/ 近接3経路とスケボーは自前で登録 / 境界は channel `'dot'`(召喚・味方・連続源)と `GHOST_FX_SHAKE_ENABLED=false`。
  詳細は DEVELOPMENT_LOG v0.25.4284。
- 対象: **プレイヤーが敵に与えるダメージ**に伴う画面の動き(揺れ・反動キック)。
- 対象外(この案では触らない): 被弾の揺れ(`SHAKE_MAG` 16)・敵/ボスの技や召喚・登場の着地・四神技/竜巻の発動・ボス撃破の演出(長い低い揺れ+スロー)・
  ヒットストップとスローの長さ・ズーム。これらは「ダメージの通知」ではないので別の物差しのまま。

## 1. 今の実態(事実。数えたもの・全部 `triggerShake`/`triggerKick` 経由・描画のみ)

描画側で全ての振幅に `SHAKE_GLOBAL_MULT`=2 が掛かる(下表の px は掛ける前の値)。重なった時は「強い方優先・長さは延長」。

| いつ | 何が | 振幅px / 長さms | 出どころ | ダメージとの関係 |
|---|---|---|---|---|
| 発砲時 | 反動キック(銃のみ・射線の逆へ・ease-out) | 0.8〜9.5 / 間隔の75% | `recoilSpecForWeapon` | **唯一ダメージを見ている**(1発威力×0.055+基礎1.6、連射は√で減衰) |
| 銃が当たった時 | (無し) | 0 | — | — |
| 銃以外が当たった時(爆発・サブ武器・スキル。damageEnemy経由) | 一瞬の揺れ | 4 / 90(間60ms) | `NONGUN_HIT_SHAKE` | 無関係(グレネード140でも刀12でも同じ) |
| 近接の通常ヒット(カウンター/刀/鞭の3経路) | スイングの揺れ(敵の方向へ) | 7 / 110 | `MELEE_SWING_SHAKE` | 無関係 |
| クリティカル(全経路) | 大きい揺れ+光源 | 14 / 200(間320ms) | `CRIT_SHAKE` | 無関係(7ダメの連射クリも140の擲弾クリも14) |

| パニッシャー巻き込み | 揺れ | 4 / 200 | `PUNISHER_SHAKE` | 無関係 |

**読み取れる歪み(事実)**
1. 物差しが無い。値は「社長指示で倍化」を個別に重ねた結果で、**4 / 7 / 8 / 10 / 14** はお互いに比べて決めた数字ではない。
2. 逆転がある: 刀の一振り(12ダメ)は 7px、擲弾の爆発(140ダメ・複数体)は 4px。レールガン(87)のヒットは 0px。
3. ダメージを見るのは反動キックだけ。しかも「当たった時」ではなく「撃った時」。
4. 特殊パターン(クリ/フィニッシュ/カウンター)は**定数の上書き**で表しているので、弱い武器のクリと強い武器のクリが同じ揺れ。

## 2. 案(社長案を具体化・v2)— 「純粋なダメージの揺れ」×「特殊パターンの倍率」の2層+土台1つ

### 2-0. 言葉の定義(監査で「未定義」と出た3つ。先に固定する)
- **ダメージ**: その事象で敵に**実際に入った**値(実効)。**過剰分は切る**(残HP1の敵にロケット275→1)。**クリティカルの倍率(×1.5/ボス×5)は掛ける前**の値
  (クリの「大きさ」は2層目の倍率で1回だけ表す=二重に効かせない)。
- **1つの事象**: 同じ**発生源1回**が同じフレームに与えた命中の束(散弾の1発=粒5つ、爆発1回=巻き込み3体、刀の一振り=2体、擲弾の直撃+爆風=同じ擲弾)。
  鍵は発生源の種類(実装 v0.25.4284: `'gun'` / `'blast'` / `'melee'` / `'skate'` / `'other:<channel>'` の定数=同じフレームの同じ種類は1事象。
  弾ごとのIDではない=同フレームの2つの爆発・二丁の左右も1事象に溶ける。監査(C)で記述を実態に合わせた)。
  **別の種類が同じフレームに重なった時は、今と同じ「強い方優先」で1つに**(合算しない)。
  事象のフラグ(クリ/キル/爆発)は**束の中の1つでも該当すれば事象に付く**(粒1つがクリなら散弾1発がクリ)。
- **プレイヤー起因**: **本人の武器・サブ武器・スキルの直接命中**(投げナイフ・四神技の命中も本人)。**召喚(犬/使役/タレット)・味方・守護霊・幻影の
  与ダメは揺らさない**(0)。**連続源**(火炎放射器・アイレーザー・氷槍の床・金環・竜巻・火床・棘・パニッシャーの脈)は**揺らさない**(0。発動/発生の瞬間の
  既存演出はそのまま)。事実: 今は火炎放射器/アイレーザーの脈が 4px を 60ms 間隔で鳴らしている(=常時の微震)。

### 2-1. 土台: レート正規化(「1秒あたりの揺れの総量」に天井)
- 同じ源が **REF=300ms より短い間隔**で当たる/撃つなら、1回ぶんの振幅を `min(1, 間隔/REF)` 倍に絞る(間隔=その武器の cooldown/パルス間隔)。
  マシンピストル(100ms)=1/3、ハンドガン(420ms)=等倍。**「間(gap)で捨てる」はやめる**(監査16: 連射と間のエイリアシングで不規則な引っかかりになる)。
  今の3種の間(銃以外60・クリ320・パニッシャー無し)と `rapidFireKickMult`(√減衰)は**これ1本に置き換わる**。
- 反動キックも命中揺れも同じ土台を通る(キックには今、間も減衰の共通則も無い=監査15)。

### 2-2. 1層目: 純粋なダメージ → 振幅(1本の純関数・`src/utils/impactShake.ts`・テスト可)
```
base(D) = clamp(K * sqrt(D), 0, BASE_MAX)        // D=§2-0 のダメージ(実効・クリ前・過剰切り)
```
| 記号 | 叩き台 | 意味 |
|---|---|---|
| K | 0.65 | 擲弾Ⅲの爆発1体(140)でちょうど天井の手前(7.7)。**天井に着くのは 150 以上だけ**(監査1: 強い一撃で倍率が潰れないように、天井を低く・遠くに) |
| BASE_MAX | 8 | 倍率前の天井 |
| HARD_MAX | 11 | 倍率込みの天井。**被弾(16)の約0.7倍**=「殴られた方が必ず大きく、しかも区別がつく」(監査5: 16に揃えると被弾と見分けがつかない) |
| FINISH_MAX | 14 | **処刑(finish)だけの天井**(社長裁定2026-09-14・クリエイティブ監査15: 処刑が11に貼り付いてレールガンのクリキルと並んでいた) |
| MELEE_MIN | 3 | **近接だけの床**(社長裁定2026-09-14・クリエイティブ監査16: 刀12ダメ=2.3px は旧7の1/3。近接は「当たった体感」が主) |
| MIN | なし(近接のみ MELEE_MIN=3) | 銃・爆発・サブの弱い命中は小さいまま(下限で持ち上げない。連射の微震を作らないため) |

### 2-3. 2層目: 特殊パターンの倍率(振幅と長さの**2値**・叩き台)
長さは `ms = (60 + 8 * mag) * msMult`(倍率前 mag 2→76ms、8→124ms)。1式に縛らず、フラグごとに **msMult で性格を残す**(監査4: 爆発=長く低い/クリ=短く鋭い)。

| フラグ | 振幅 | 長さ | 備考 |
|---|---|---|---|
| クリティカル / ヘッドショット | ×1.6 | ×0.8(短く鋭く) | 光源(`spawnCritImpact` の強glow)はそのまま |
| キル(**本人の直接キル**。召喚/味方/DoTのキルは対象外) | ×1.3 | ×1.0 | 今は無し。10体連続のスローはそのまま |
| 爆発(爆風で入った束) | ×1.3 | ×1.6(長く低く) | 面の読みは光/砂埃(②派手側)が担う |
| カウンター成立 | ×1.5 | ×1.0 | ストップ100+寄りズームは不変。揺れは**ストップ明けに**(§2-5) |
| 近接フィニッシュ(処刑) | ×2.0 | ×1.2 | **今と同じく `JUICE_CD_MS` の中で1回だけ**(監査12: 酔い対策 v0.25.1523-1524 を崩さない)。CD中の処刑は「キル」扱い(×1.3) |
| シールドバッシュ | ×1.5 | ×1.1 | ストップは不変 |
- 倍率は**掛け合わせ**(クリで倒した=×2.08)、最後に HARD_MAX(11)で止める。例: レールガンのクリ 6.1×1.6=9.8、クリで倒す 12.7→11。

### 2-4. 銃の扱い(キックと命中揺れの合成・決めてほしい点②)
- **(推薦) 銃は1層目を「発砲時のキック」で出し、命中時は2層目のぶんだけ足す。** 弾が速い銃では発砲と命中が同フレームに重なり、
  「射線の逆へキック」+「命中点へ揺れ」が**逆向きで濁る**(監査14)。よって銃は**方向を1つに固定=全部「射線の逆」**、
  キック=`base(1発威力)`(土台の正規化込み)、命中時は**フラグがある時だけ** `base×(mult) ` を同じ向きへ(通常命中は追加なし=今と同じ0)。
  近接・爆発・サブは「命中点へ」(既存の dirfx)。**弾の遅い擲弾・ロケット**は発砲キック(小)と着弾の爆発揺れ(大)が時間で離れるので両方出る=自然。
- 代替: キック廃止。銃も当たった時だけ揺れる(最も単純。外した弾は無反応。反動は1日前 v0.25.4268 に社長指示で入れたもの=事実)。

### 2-5. 順序と畳み方(実装の掟・監査11)
- 登録は `registerImpact({source, D, flags, x, y})` の**キュー**。tick 末に事象ごとに合算→**ヒットストップ明けまで保留**→1回だけ `triggerShake`。
  今の `triggerHitImpact` は `shakeUntil=0` で消してから `setTimeout(stop)` で揺らしている。即時に鳴らすと**ストップに食われる/消される**ので、
  保留(deferUntil=hitstopUntil)を体系に入れる。
- 描画は既存の shake 経路のまま(`SHAKE_GLOBAL_MULT`=2 も据え置き=絶対値は実機で絞る)。ズームとの結合: 揺れは**画面px**(目に対する量)で据え置く。
  事実: 処刑は最大ズームイン中、爆発は 0.40 の引き中に起きるので、同じ px が世界に対しては 2.5 倍違って見える(実機で「処刑が大きく見えない」なら
  ズーム倍率で補正する余地=(B)積み)。

### 2-6. 触らないもの(範囲外・明記)
- 被弾 16/280、敵・ボス・召喚・登場の揺れ、ボス撃破の長い低い揺れ、竜巻/四神技の**発動**揺れ、エンディングの爆撃。
- ヒットストップ(100)・スロー・ズームの長さと順序。光・血・砂埃などの絵。
- **守護霊の揺れ(決めてほしい点④)**: 事実として**今は鳴っている**(`GHOST_FX_SHAKE_ENABLED=true`: 一閃=7px・カウンター=8px)。
  §3 で撤去する定数を参照しているので、**(推薦) 守護霊は揺らさない**(社長指示v0.25.4271「プレイヤー以外の銃で揺れないで」と同じ線)。
  残すなら守護霊専用の定数へ退避。

## 3. 実装の形(承認後・見積り)

  監査8: 今は爆発を区別するフラグが無く全部 'other'。**爆発は1本の `applyExplosionDamage(eventId, victims)` に寄せ、直接 damageEnemy を呼ぶ爆発が

  `PUNISHER_SHAKE_*`・`rapidFireKickMult`・3種の gap。

## 4. 決めてほしい点(まとめ)
1. **曲線**: √(推薦。弱い武器でも読め、強い一撃は天井の手前で倍率が読める)/線形(純比例。近接・弱い銃はほぼ無揺れ)。
2. **銃**: キックを残し1層目をキックで出す(推薦)/キック廃止で命中時のみ。
3. **境界**: 「本人の武器・サブ・スキルの直接命中だけ。召喚・味方・守護霊・連続源は0」でよいか。
4. **守護霊**: 揺らさない(推薦)/専用定数で残す。
5. **倍率表の顔ぶれ**(§2-3): 足す/外すパターンがあるか(例: ボス級への命中、体勢崩し成立、ヘッドショットをクリと別扱い)。
6. **「被弾を超えない・被弾より短い」**(HARD_MAX=11・最長≈180ms vs 被弾16/280)を体系のルールにしてよいか。
