# アクラシエル再構築・画角追従の検収記録 (2026-09-10)

## 変更の意図

放射棘の判定を細い放射線から8分割の扇形へ変更。指定された空きセクター以外の小さな抜け道をなくす。
予告と判定は `acrasielSectorPolygon` の同じ頂点を使用する。空きの向きは予告開始時に固定し、
壁・ゲート拘束円・移動可能距離・プレイヤーの幅を満たす退避点を確保する。左右の候補順を変え、
毎回現在地が安全になる配置を避ける。配置できない場合は予告を出す前に転移を選択する。
第3フェーズは槍の予約済み起爆時刻と棘の実行を合わせる。槍も退避点を塞がない位置に配置する。

## W1〜W9 の対応

| 掟 | 技・状態と実装 |
|---|---|
| W1 | 棘 `spike-windup` は危険セクター全域、槍 `spear-windup` は全着地点、爆発 `burst-windup` は円、転移 `warp-out/in` は着地点円、凝視 `gaze-windup` は射線を最初から表示。設置槍の円も起爆まで維持 |
| W2 | 全5技のwindup/activeは本体位置を固定。転移は消失後に確定着地点へ移り、出現予告を経て衝撃を出す |
| W3 | 棘・槍射出・転移衝撃・爆発・凝視射出は全て専用recoverへ。カウンター中断もrecoverを経る |
| W4 | 原点・空き・槍の着地点・転移先・凝視の狙いを開始時に保存。予告中の再追尾・起爆時刻変更なし。カウンターによる中断は通常の報酬 |
| W5 | 下表のリードをフェーズによらず使用。第3フェーズの棘は予約済みimpactAtから1100ms前に開始する固定タイムライン |
| W6 | 全recoverで本体位置を固定、青白 `0xbfe8ff`。次の技抽選はchaseに戻ってから。複合技の後半は事前確定済みで再抽選しない |
| W7 | 全windup/recoverの本体重なりにカウンター受付を明示。activeは扇・円・共通弾の各判定に委ねる。同じ受付窓による接触の多重報酬を防止 |
| W8 | 結晶の棘・槍・破片、既存の目の凝視を使用。脚のない本体に歩行や突進を追加しない |
| W9 | 既存槍画像を構え・射出・硬直で保持。硬直中も青白く残す。転移の消失は本体と武器を一緒にフェード |

本体の溜め変形・棘の開閉・槍の飛行・転移のフェードはsmoothstepを使用する。
技選択、当たり判定、時刻は純関数/store側。Pixiは状態を読み描画するだけ。
上下を含む転移先は `clampRectToPlayableArea` とゲート拘束円で制限する。

## 時間値 (gameTime)

| 技 | 予告 | active | recover |
|---|---:|---:|---:|
| 棘 | 1100ms | 240ms | 900ms |
| 槍 | 射出700ms、射出から起爆2000ms | 射出350ms | 通常900ms、複合550ms |
| 転移 | 消失800ms + 出現1000ms | 200ms | 900ms |
| 爆発 | 1200ms | 300ms | 1200ms |
| 凝視 | 450ms | 射出160ms | 900ms |

複合技は350 + 550 + 1100 = 2000ms。ゲームループの1step上限50ms、timeScale上限1により、
複合硬直の遷移遅れを含めても500msの床を確保する。棘予告の画面表示開始は最大1tickの量子化差がある。
表示時間1100msの厳密な保証とは区別するが、大技の1000ms下限は下回らない。
