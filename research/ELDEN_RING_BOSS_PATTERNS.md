## この資料の使い方(2D移植時の注意)

- **最重要の2つの数値は「予備動作(wind-up)の秒数」と「攻撃後のパニッシュ窓の秒数」。**
  エルデンリングの戦闘は「予備動作を読む → 正しいタイミングで回避 → コンボの最終段の後だけ殴る」
  のループでできており、技single自体の見た目より **タイミングの設計** がゲーム性の本体。
- 本作の時間の基準系(プレイヤー側の数値。§1-6参照): ロール無敵 ≈0.42〜0.45秒、回復モーション ≈1秒。
  ボスの予備動作・ディレイ・パニッシュ窓はすべてこの2つの尺度と噛み合うように作られている。
  2D移植時は自ゲームの「回避の無敵時間」「回復の隙」を先に決め、それに対して本資料の比率を写すこと。

# 1. 横断分析 — エルデンリングのボス設計に共通する「型」

## 1-1. ディレイ攻撃の設計思想

**何が起きているか**: 武器を振り上げたまま不自然に長く静止し、プレイヤーの「アニメ開始を見て
反射的にロールする」癖を狩ってから振り下ろす。エルデンリングの看板設計。

- FromSoftware作品はシリーズを追うごとにディレイ攻撃が増え、エルデンリングでは
  **「ディレイ持ちの技の方が素直な技より多い」ボスが普通**(コミュニティ分析)。○
- 設計意図(コミュニティの整理): ディレイが無ければ回避はただの連打になる。ディレイがあることで
  「アニメ開始」ではなく**「振り下ろしの開始」を見る**ことを強制し、回避を反射ではなく読みのゲームにする。○
- **適応型ディレイ(重要)**: 一部のボスは、プレイヤーが早くロールすると**振りを加速**し、
  遅くロールすると**さらに溜める**とコミュニティで報告されている(例としてマルギットの
  「超ディレイ振り下ろし」が挙げられる)。△ — 2Dでは「予告開始後、プレイヤーの回避入力を検知したら
  発射タイミングを前後させる」実装に相当。強力だが理不尽感も強いので採用は要判断。
- ディレイの長さの定量値は今回の調査では出典が見つからなかった(不明)。体感ベースの通説では
  「一瞬(0.3秒前後)の見せ溜め」から「マレニアの突き・ラダゴンの掴みのような1〜2秒級」まで分布。△
  ラダゴンの掴みは複数出典で **「おそらく作中で最もディレイが長い攻撃」** と言われる。○
- **モーゴットは第1形態のほぼ全攻撃がディレイ持ち**(出典明記)。「左手の動きを見て回避タイミングを
  計れ」という攻略が定番=**ディレイ攻撃には必ず「本当の発射タイミングを示す第二の予兆」がある**。○
  2D移植ではここが肝: 「赤predict表示(危険告知)」と「発射の瞬間の小さな光/音(回避タイミング告知)」の
  2段テレグラフに分解できる。

## 1-2. コンボの段数分布と「最終段の後だけ殴れる」構造

- 段数の分布(出典から拾えた実例):
  - ミドラ: **コンボは最大3段まで**。ほぼ全コンボの後に**1〜2秒のパニッシュ窓**。✅(丁寧設計の見本)
  - マレニア: 3連斬り(最終段がディレイすることあり)、5連斬り、キック→4種派生。○
  - 約束の王ラダーン: 4連斬りコンボ。第2形態は各斬撃に聖光の追撃が付き**回避回数が2倍**になる。○
  - モーゴット(HP30%以下の切り札): 短剣連撃→聖剣連撃→ハンマー回転+叩きつけの超長コンボ。✅(発動閾値30%)
  - 坩堝の騎士: 踏みつけ→2連薙ぎの固定パターン等「絶対に派生しない安全な型」を2つ持つ。○
- **共通構造**: コンボ途中の隙は見せかけ(追撃が来る)で、**「コンボの最終段」だけが本物の隙**。
  最終段は (a)大振りで後隙が長い、(b)音・エフェクトが派手、(c)ボスが姿勢を立て直す動作を挟む、
  で見分けられるようにできている。マレニアの安全なパニッシュは「ディレイ振り下ろし後」「突進突き後」
  「3連斬りの最終段後」の3つで、**入る攻撃は1〜2発**が相場。○
- ホーラ・ルーの注意書きが象徴的: **「第2形態は第1形態より後隙が短い。回避後に殴るのは1発まで」**。○
  = フェーズが進むとパニッシュ窓を**技ではなく秒数で**削って難易度を上げている。
- レラーナの経験則(出典明記): **「速い攻撃の後には遅い攻撃が続きやすい。遅い/重い攻撃が来たら
  それがコンボの終わり=殴ってよい」**。○ — リズム設計の教科書。速→速→遅(終)。
- 例外(上級者向け嫌がらせ): 神肌のふたり等、コンボ終端が分かりにくいボスは不評が多い。△

**型の抽出**:
1. **閾値は50%が最頻**(モーグ/マリケス/メスメル/プラキドサクス/リカード実質/ゴドリック)。
   次いで60%(モーゴット/ゴッドフレイ/ミドラ)、外れ値として70%(獅子舞)・75%(PCR)・66%(バイル)・47%(火の巨人)。
2. **移行の瞬間は必ず「大技+長い無防備時間」のどちらかに振る**。
   - 攻撃型: マレニアの腐敗の花(開幕スクリプト・即死級)、ミドラの爆発、モーグのニヒル(対策アイテムが無いとほぼ即死)。
   - ご褒美型: ゴドリックの絶叫3〜5秒、モーゴットの水場生成の大隙。
   = 「フェーズ移行はプレイヤーへの脅しであると同時に、最大のダメージチャンスでもある」の二択設計。
3. 技追加の型は3種: (a)**既存技への属性/追撃の上乗せ**(PCR聖追撃・モーゴット呪血・レラーナ付与)
   (b)**モーションセットの入替**(マリケス・メスメル蛇・ホーラ・ルー)
   (c)**行動ルールの変更**(火の巨人=移動方式ごと変更、獅子舞=属性ランダム化)。
4. **第2形態でHPバーを新規に張り直す**大ボスが複数(レナラ/マレニア/リカード/エルデの獣)。
   実質「2本立てのボスラッシュ」。

## 1-4. 距離帯ごとの技の使い分けの型

- **遠距離に居させない設計**: 遠距離にいるプレイヤーには弾(マルギットの短剣、モーグの血槍、
  ゴドリックの風、レラーナの輝剣、竜装大騎士の火球)か高速接近技(突進・飛びかかり)を必ず当てに来る。
  竜装大騎士は**中〜遠距離だと火球を連発**し、しかも**回復行動へのパニッシュとして撃つ**ことが明記。○
- **近距離の張り付きへの解答**: 密着で回り込むプレイヤーには 360度攻撃(坩堝の騎士の尾撃2回転、
  メスメルの360スピン)、AoE(竜装大騎士の雷ノヴァ、モーグの血炎散布)、掴み(ホーラ・ルー、メスメル)。
- **特定距離だけ安全**という逆転設計も多い: スターズコージ・ラダーンは**密着している限り
  中遠距離の重力魔法を使わない**○。エレメールは**密着していれば飛剣操作中の本体が数秒無防備**○。
  = 「危険地帯は距離レンジで作り、正解距離を学習させる」。
- 遠距離技には**着弾追尾**(ラダーンの矢の雨=プレイヤーを追尾する矢柱○、エルデの獣のエルデの流星=
  走っても振り切れない誘導弾○)を混ぜ、「逃げ撃ち」を消す。

## 1-5. 「回避狩り」(ローリング狩り・行動狩り)の実装パターン

エルデンリングの入力読みの実体はコミュニティ検証で**「入力読みではなくアニメーション読み」**と
整理されている(datamine報道あり)。○
- 実装: プレイヤーの特定アクションのアニメ開始時に立つ**フラグをAIが監視**し、対応する迎撃行動を
  即座に発火する。全部のアクションを読むのではなく、**読む対象は行動ごとに選別されている**
  (回復は読む/ロールや攻撃は読まないボスが多い)。○
- **回復(聖杯瓶)狩り**が最も顕著: 飲むアニメの**開始数フレーム以内**に遠距離攻撃を差し込んでくる
  (瓶が見える前に発射される)。✅(「数フレーム」と報道)
- **ロール狩り**の型:
  1. ディレイそのもの(早ロールの無敵切れに振り下ろしを合わせる)— §1-1。
  2. 2連・3連の同一方向連打(1回のロール無敵で1発しか避けられない間隔で刻む)。△
  3. ロール後の硬直に置きAoE(モーグの血炎の残留、バイルの雷追撃=「着地後に遅れて雷が爆ぜるので
     ロールを1拍遅らせて2回目」○)。
  4. 適応型ディレイ(§1-1)。△
- 2D移植での要点: 「回避後の無敵切れの瞬間に2発目が重なる」多段技を1〜2本持たせるだけで
  「連打回避」を殺せる。ただし全技に入れると理不尽(エルデンリングでも不満が多い部分)。

## 1-6. 基準系: プレイヤー側の数値(パニッシュ窓・回避設計の物差し)

- ロールの無敵時間: 軽ロール・中ロールはほぼ同じで**約25〜27フレーム@60fps(≈0.42〜0.45秒)**、
  重ロールは約25フレーム。軽ロールは無敵の発生が2f早く、終わりが2f長い。✅(コミュニティ計測)
- 聖杯瓶(回復)の動作: **約1秒**。✅(体感報告ベース) 回復はこの1秒を安全に確保できる
  「ボスの後隙」でしか行えない=回復可能な窓もパニッシュ窓と同じ物差しで設計されている。
- パニッシュ窓の相場(出典から): ミドラ=コンボ後**1〜2秒**✅ / マレニア=安全な後隙で**1〜2発**○ /
  ホーラ・ルー=**1発(急いで2発)**○ / エルデの獣=**2発まで、3発目は欲張り**○。
  1発=R1一振り≈0.6〜0.9秒(武器種による・△)とすると、**標準的なパニッシュ窓は約1〜2秒**に収束する。
- 参考(唯一取れた技単位のフレームデータ): Waterfowl Dance(プレイヤー使用版の戦技)
  初段ヒットは発動から**47F=1.57秒**、以降 58F/1.93s → 64F/2.13s → 72F/2.40s。
  全ヒットの0.07秒後に追撃の風判定。1連目4hit/2連目2hit/3連目4hit。✅(wiki.ggのフレーム解析)
  ※マレニア本人版の数値ではない点に注意。ただし構造(3連フラリー・連間の短い間隔)は同一。

# 2. Tier1 ボス別詳細

> 各技の並びは「技名 / 種別 | 予備動作・ディレイ | 回避の正解 | 備考(条件・後隙・威力感)」。
> 秒数の無い箇所は出典に数値が無かったもの(不明)。

## 2-1. マルギット(忌み鬼、マルギット / Margit, the Fell Omen)

- フェーズ: HPを約1/3削ると光の大槌(以後は大剣も)を追加召喚。✅ 完全な第2形態ではなく「武器追加」型。
- **杖コンボ+超ディレイ振り下ろし** / 近接コンボ: 杖の2〜3連。最後の振り下ろしを頭上で長時間保持する
  「超ディレイ」が代名詞。早ロールすると加速して狩ってくるという報告あり(△)。回避は「振り始め」でなく
  「振り下ろし開始」を見て前/横ロール。○
- **光の短剣投げ** / 飛び道具: 遠距離で1〜2本投げる。**遠距離で2本投げたら次はジャンプ突きが確定**
  というテル(お約束)が明記されている。○ → 予備動作を「行動の並び」で教える設計例。
- **ジャンプ突き→(P2)ジャンプ大槌** / ジャンプ+AoE: 跳んで空中で一拍止まってから落ちる。
  「長めの開始動作→空中で静止→落下」で非常に読みやすい○。ボス側に向かって前ロール→着地後に数発の
  パニッシュ窓○。
- **光の大剣(横薙ぎ/叩きつけ)** / 近接: P2追加。大振りでディレイ持ち。○
- **尻尾**: なし(人型)。距離帯: 遠=短剣・ジャンプ系、近=杖コンボ。
- ダメージ感: 序盤ボスなので1発中〜大(当時のHPで2〜4発でデス)。△
- 出典: thegamer.com / eip.gg / gameskinny.com / vulkk.com / ludoatlas.com(検索要約)

## 2-2. モーゴット(忌み王モーゴット / Morgott, the Omen King)

- フェーズ: **60%で第2形態**✅。移行技=剣を地面に刺し水場を生成(大隙・攻撃チャンス、立ち上がる
  直前に離脱)○。P2アリーナは浅い水場になり**火耐性+20/雷耐性-20**(双方に適用)✅。
- **P1のほぼ全攻撃がディレイ持ち**✅。「左手の動きで本当の発射タイミングを読む」が攻略の軸。○
- **ハンマー振り/叩きつけ** / 近接: 大きな後隙。背面へロールで回り込むとパニッシュ確定。○
- **投げ武器(光の短剣・槍)** / 飛び道具: 中遠距離。○
- **呪血斬り(Cursed-Blood Slice)** / 突進: P2。剣を掲げ血炎を纏う→大きく踏み込む斜め斬り→小さく
  回って逆方向へ2撃目。**血炎の軌跡が残留し、遅れて爆発**する(置きAoEでロール狩り)。○
- **聖武器コンボ(切り札)** / 近接コンボ: **HP30%以下**✅で使用。短剣の連撃→聖剣に持ち替えて連撃→
  ハンマー回転+叩きつけで〆。2つの武器が交互に来るので「攻撃を潜る」より「離れる」回避が正解○。
  コンボ後に明確なポーズ=パニッシュ窓。○
- **ハンマー大上段のベイト**: 大上段を見たら距離を取ってから内側にロールすると、〆の
