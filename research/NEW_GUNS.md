# 新しい銃3種(設計書・第1版)

## 0. 社長の決定(2026-10-18・research/GUN_IDEAS.md §6〜§7)
- **塊弾**: 採用枠へ。
- **衛星弾**: 「回ってる間も当たり判定あるなら採用」。
- **スキャンセンサー**: 「狭目の扇状にスキャンが定期的に発生し、3秒間、マーキング。近接や他の武器のダメージが上がる。(弾がない分を補うほどのダメージ計算は監査)」。
- 判断の物差し: より面白くなる方。

## 1. 前提(今の銃の仕組み・2026-10-18 走査)
- **銃の扱い**
  - 銃は自動で撃つ。狙いは一番近い気絶していない敵で、射程内の時だけ撃つ。撃つのは常に1挺(`getActiveGun`)。
  - 台帳は `utils/weaponUtils.ts` の `CATALOG`。系統はハンドガン/ショットガン/ライフル/グレネードガンの4つで、それぞれ段は T1〜T3。
  - 特殊銃は、置く枠の標準の銃の火力の ±10%(狙いは 0〜+10%)に収める(`UNIQUE_WEAPONS.md` §5)。
- **実際の火力**(リロードは表の値の2倍が実際の時間)
  - ハンドガン: T1 15.8 / T2 28.1 / T3 37.5
  - ショットガン: T1 17.8 / T2 21.2 / T3 26.9
  - ライフル: T1 23.1 / T2 28.9 / T3 45.8
  - グレネードガン: T1 28.7 / T2 45.8 / T3 70.0
- **近接**
  - 指を離した時に振る。周り 74px の全員に当たる。1回の流れは最短 820ms。
  - 火力(会心込み): t1 10.0 / t3 28.5 / t5 68.6。
- **銃の火力を使っている別の仕組み**
  - カウンターの反撃ダメージ(`counterReplyDamage` が今の銃の `damage` を使う)。
  - 銃の会心は雑魚を5秒気絶させ、気絶した雑魚は近接で即死する。
  - 近接フィニッシュは今の銃に弾を戻す。
  - 守護霊は今の銃を写す。

## 2. 塊弾(かたまりだん)
- **枠**: グレネードガン系 T2 の特殊銃。標準 45.8 に合わせる。
- **動き**
  - 大きな塊(半径 26)を、狙った方向へゆっくり撃つ(秒速 70)。
  - 塊は 4 秒で消える。消える時は、0.4 秒かけて縮みながら薄れる。
  - 塊は敵を押しのけながら進む。触れている敵には 200ms ごとに 4 ダメージ(会心なし)。
  - 壁・木・岩に当たったら、そこで止まって、残りの時間はその場でダメージを与え続ける。
- **撃つ間隔**: 1.8 秒。弾倉 3、リロード 2.0 秒(実際は 4.0 秒)。
- **火力の検算**
  - 1体に触れ続けると 20/秒。同時に生きている塊は、撃つ間隔と寿命から約2個。重なれば 40/秒、リロードを込めると約 33/秒。
  - 1体ずつの火力は標準より低い。その代わり、帯の中の何体にも同時に当たる。
  - 廊下で群れに当てた時の合計で標準を上回る、が狙い(数字は監査で確かめる)。
- **見た目**
  - 暗い赤紫のどろりとした塊。触れた敵の足元に、粘りの飛沫を出す(派手さの絵)。
  - 撃った時の反動・塊の出だし・止まり際には、どれも慣性を付ける。
- **面白い所**: 廊下・ボスの進路に「置く」判断が生まれる。撃ちっぱなしの銃と違い、塊が届くまでの時間を読む。

## 3. 衛星弾(えいせいだん)
- **枠**: ショットガン系 T2 の特殊銃。標準 21.2 に合わせる。
- **動き**
  - 自分が動いている間、350ms ごとに弾が1つ増える。弾は自分の周り(半径 48)を回る。最大 8 個。
  - **回っている弾にも当たり判定がある**(社長の条件)。触れた敵に 5 ダメージ。同じ敵へは 400ms 空ける。弾は消えない。
  - **止まった瞬間**に、回っている全部が、その時の位置から外向きに一斉に飛ぶ(秒速 380・1発 9・射程 200)。
    - 飛ぶ向きは、それぞれの弾の「中心から見た向き」。そのため弾と弾の間に隙間ができる。
  - 止まって撃った後は、また動けば溜まり始める。動かずに居るだけでは溜まらない。
- **自動の照準は使わない**: 溜める・放つは「動く・止まる」で決まる。弾倉・リロードは無い。
- **火力の検算**
  - 走って 8 個溜めて止まれば、1回で最大 72。近い敵に数発が当たる想定で、1体に 2〜4発(18〜36)。
  - 溜め 2.8 秒+放ちの周期で、1体へ約 10〜15/秒。
  - 回っている弾が群れに触れる分を足して、標準 21.2 付近を狙う(監査で確かめる)。
- **見た目**
  - 小さな青白い光の粒が、少し揺れながら回る。回る速さは溜まった数で上がる。
  - 止まった瞬間に一瞬だけ収縮してから弾ける(慣性)。
- **面白い所**: 「走って溜め、止まって放つ」リズム。止まる場所と、その時の向きが腕になる。回っている間も触れれば当たるので、走りながら群れの縁を削れる。

## 4. スキャンセンサー
- **枠**: ハンドガン系 T2 の特殊銃(弾を撃たない)。
- **動き**
  - 1.2 秒ごとに、向いている方向へ狭い扇のスキャンが走る(扇の開き 40°・長さ 260)。
    - 向きは、最後に動いた向き。照準の自動追尾はしない。
    - 扇は 0.25 秒かけて、根元から先へ掃く(慣性)。
  - 扇に入った敵に **3 秒の印**。もう一度扇に入れば 3 秒に戻る(重ねても倍率は上がらない)。
  - 印の付いた敵が受けるダメージは **×N**。近接・サブ・守護霊・英雄・軍人・犬など、誰の攻撃でも上がる。
- **N の決め方**(弾が無くなった分を補う)
  - 近接だけで標準の銃の火力を補う倍率は N = 1 + G/(M×u)。G=失った銃の火力、M=近接の最大火力、u=近接が実際に当たる割合。
    - 序盤(ハンドガン T1+ナイフ t1): u=1 で 2.7、u=0.5 で 4.3。
    - 中盤(ハンドガン T2+t3): 2.05 / 3.1。
    - 終盤(T3+t5): 1.75〜2.15 / 2.5〜3.3。
  - サブ・仲間の火力(タレット 20〜38/秒、軍人 1人13/秒、英雄の犬 13/秒)にも同じ倍率が掛かる。そのため、近接だけで割った値より小さくてよい。
  - **案: N = 2.4**(段は T2 のみの1種)。
    - 根拠: 中盤で u≈0.6、サブ・仲間が近接と同じくらい当たる、と見て、失った銃の火力を印で取り戻せる値。
    - 監査に数字で確かめてもらう(「弾がない分を補う」を満たすか)。
- **銃の火力を使っていた仕組みの扱い**
  - カウンターの反撃: スキャンセンサーの `damage` は名目上 18(ハンドガン T2 の1回の撃ち 9×2 と同じ)にして、カウンターが今と同じ強さで出るようにする。銃としては撃たない。
  - 会心の気絶: 撃たないので起きない。代わりに **印の付いた雑魚には近接の会心率 +15%**(会心で5秒気絶→近接で即死、の流れを残す)。
  - 近接フィニッシュの弾の払い戻し: 弾倉が無いので何もしない。
  - 守護霊が写す時: 守護霊もスキャンを出し、守護霊の印も同じ効果(プレイヤーの印と区別しない)。
- **当て所**
  - `damageEnemy` の中(`resolvedAmount` を決めた直後・紅き夜の半減の前)に1か所。
  - 近接の各経路(ナイフの振り・分身・刀・鞭・スケボー)にも同じ関数 `markTakenMult(enemy, gameTime)` を掛ける。即死は対象外(もともと即死)。
  - ダメージの数字は、印の倍率を掛けた後の値を出す。
- **見た目**
  - 扇は淡い青緑の走査線(判定を持たない派手さの絵。危険の色の赤・紫は使わない)。
  - 印は敵の足元の細い輪と、頭上の小さな菱形。3 秒の残りは輪が欠けていくことで見せる。
  - 印のある敵に当てた時、ダメージの数字が少し大きく・色違いになる。
- **面白い所**: 撃たない代わりに「どこを向いて走るか」が攻撃になる。印を付けてから近接・サブで叩き込む段取りが腕になる。倒すのは自分の手。

## 5. 共通
- 入手: 既存の特殊銃と同じ(ドロップ・武器箱)。武器庫からは出ない。
- 名前は data の表記どおり(塊弾・衛星弾・スキャンセンサー)。
- 赤い予告の掟: どれも敵の技ではないので対象外。
- 負荷
  - 塊弾は同時2個×触れている敵の判定で、1/10。
  - 衛星弾は最大8個×敵の距離判定で、1/10。
  - スキャンは 1.2 秒ごとに扇の判定を1回で、1/10。

## 6. 受け入れ条件
1. 塊弾は、ゆっくり進んで触れている敵に当たり続け、壁で止まり、寿命の終わりに縮んで消える。
2. 衛星弾は、動くと溜まり、回っている間も触れた敵に当たり、止まると外へ一斉に飛ぶ。
3. スキャンセンサーは、向いた方へ扇を出し、扇に入った敵に3秒の印を付ける。印の敵は誰の攻撃でも ×N を受ける。カウンターの強さは今と同じ。
4. 3つとも、特殊銃の火力の約束(標準 ±10%)を、監査が数字で確かめる。スキャンセンサーは「印の倍率込み」で確かめる。
5. 既存の銃・近接・サブの挙動は、この3挺を持たない時は1bitも変わらない。
