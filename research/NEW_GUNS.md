# 新しい銃3種(設計書・第5版)

## 0. 社長の決定(2026-10-18・research/GUN_IDEAS.md §6〜§7)
- **塊弾**: 採用枠へ。
- **衛星弾**: 「回ってる間も当たり判定あるなら採用」。
- **スキャンセンサー**: 「狭目の扇状にスキャンが定期的に発生し、3秒間、マーキング。近接や他の武器のダメージが上がる。(弾がない分を補うほどのダメージ計算は監査)」
  - 追加の決定: 「プレイヤーだけで考えて」(=計算の前提) / 「他の銃にも印は効く。銃の弾と近接で倍率を変える」 / 「仲間は初心者救済なので変な抑え込みはしない」
- 判断の物差し: より面白くなる方。全ての動きに慣性。特殊銃は、置く枠の標準の銃の火力の ±10%(狙いは +側)。
  - **±10% は「距離120の敵1体」で測る約束。使い方による強弱(近くに置く・群れを通す・溜めて止まる・持ち替え)は許容する**(社長 2026-10-18「使い方によって強いのは許容してる?」→「はい」)。

## 1. 前提(2026-10-18 走査・監査で確かめた値)
- 銃は自動で撃ち、一番近い敵を狙う。撃つのは手に持っている1挺(`getActiveGun`)。持ち替えは無料・即時(`setActiveWeapon`)。
- 実際の火力(リロードは表の値の2倍)。グレネードガン T2 は 45.8、ショットガン T2 は 21.2、ハンドガン T2 は 28.1。
  - ハンドガン T2 の会心込みは、雑魚に 29.9、ボスに 42.7(ボスへの会心は ×5)。
- 近接は、指を離した時に振る。周り 74px の全員に当たり、1回の流れは最短 820ms。
  - 会心込みの火力(M): t1 10.0 / t2 17.8 / t3 28.4 / t4 45.2 / t5 68.6。
- 刀・分身・鞭は、コード上は**サブウェポン**(`subWeapons`)。刀の間は、ナイフの振りはダメージを出さない。

## 2. 塊弾(かたまりだん)
- 枠: グレネードガン系 T2 の特殊銃(標準 45.8)。
- 動き:
  - 大きな塊(半径 26)を狙った方へゆっくり撃つ(秒速 **110**)。
  - 塊は敵を押しのけながら進む。押しのけは区分のノックバック耐性に従い、ボス・強個体は押さない。押した敵は `clampRectToPlayableArea` を通す。
  - 壁・木・岩・ボス・強個体に当たったら、そこで止まり、残りの時間はその場で当たり続ける。
  - 寿命は 4 秒。最後の 0.4 秒は縮みながら薄れて消える(この間はダメージ無し)。
- ダメージ: 触れている敵に、200ms ごとに **9.5**(銃の扱い `'gun'`・銃のスキル倍率が乗る・会心なし)。
  - ダメージの数字は、同じ敵には 600ms ごとにまとめて出す。
- 撃つ間隔は 1.7 秒、弾倉 3、リロード 2.0 秒(実際は 4.0)。
- 検算(品質監査の実測。撃ち出し位置が18px前・塊の半径26・敵の半幅を入れる): 距離 120 の敵には約 0.6 秒で当たり始め、1発で 15〜16 回(当たり始めと200msの区切りの位相・fpsで1回ぶれる)。
  - 15回なら 3 発で 427.5、周期 9.1 秒 → **約 47/秒(+3%)**。16回(距離110〜120・30fps)でも **約 50/秒(+9%)**。
  - 使い方による差: 距離80 約+22% / 距離200 約−14% / 群れの中を通すと当たった数だけ上回る(許容)。
  - 経緯: 12 では距離120で +30%(実測)→ 10。10 でも16回の時に +15% になるため 9.5。数字はまとめた時に丸め、端数は次へ持ち越す。
- 面白い所: 廊下・ボスの進路に「置く」判断。届くまでの時間を読む。

## 3. 衛星弾(えいせいだん)
- 枠: ショットガン系 T2 の特殊銃(標準 21.2)。
- 溜まり方:
  - 動いている間、350ms ごとに 1 つ増え、自分の周り(半径 **64**)を回る。最大 8 個。
  - 回る速さは毎秒 1 周から、溜まるほど速くなり、最大で毎秒 1.6 周。
  - 「動いている」= 移動の入力がある時。押されて動いている間・近接を振っている間は「動いている」と数えない。
- **回っている弾も当たる**(社長の条件): 触れた敵に **5**。同じ敵へは **敵ごとに 400ms** に1回。弾は消えない。
- **止まった瞬間**(移動の入力が無くなって 0.15 秒)に放つ。
  - 全部が外向きに飛び出し、すぐ近い敵へ散って向かう(ゆるい誘導・秒速 380・射程 200)。
  - 1発 **6**。銃の扱い。会心あり(ショットガンの会心率)。
- 弾倉・リロードは無い。
- 検算: 放つ側は 6×8÷(2.8+0.15) ≈ 16/秒が上限。回る弾は、触れている時間を 50% として約 6/秒。合わせて **約 22/秒**(標準の +4%)。
- 面白い所: 走って溜め、止まって放つリズム。回る弾で群れの縁を削りながら走れる。

## 4. スキャンセンサー
- 枠: ハンドガン系 T2 の特殊銃(弾を撃たない)。
- 弾の仕組み: 火炎放射器の前例(`nonProjectile`)に合わせる。弾倉・予備弾を持たない。
  - 「弾切れ」とみなさない(拾った時の持ち替え・弾切れの自動持ち替えの対象外)。
  - 逆に、ほかの銃が全部弾切れになった時は、スキャンセンサーへ自動で持ち替える。
  - ストライカーの「弾切れで近接 ×1.5」は掛からない(`strikerMeleeMult` からスキャンを除く)。
- **スキャンの拍**:
  - 拍は持ち替えと関係なく、出撃中ずっと 1.2 秒ごとに回る。拍は画面の下の小さな目盛りで見せる。
  - 拍が来た時にスキャンセンサーを持っていれば、扇を出す。扇は向いている方へ、開き 40°・長さ 260。0.25 秒かけて根元から先へ掃く(慣性)。
  - 印は掃き終わった時、まだスキャンセンサーを持っている場合だけ付く。扇に入った敵に **3 秒**。もう一度入れば 3 秒に戻る。重ねても強くならない。
- **印の効き方**(社長「銃の弾と近接で倍率を変える」):

| 攻撃 | 倍率 |
|---|---|
| プレイヤーの銃の弾(どの銃でも・持ち替えた後も) | **Ng = ×1.6** |
| プレイヤーのサブウェポン(タレット・手榴弾・分身・ドローンほか) | ×1.6 |
| 仲間(守護霊・英雄・軍人・犬)の攻撃 | ×1.6(抑えない) |
| プレイヤーの近接(ナイフの振り・どの段でも) | **Nm = 雑魚 ×2.75 / ボス級 ×4.7** |
| 刀(どの Lv でも) | **雑魚 ×3.1 / ボス級 ×5.2** |
| 鞭 | 近接と同じ(雑魚 ×2.75 / ボス級 ×4.7) |

  - **近接の倍率は段に関係なく1つ**(社長 2026-10-18「倍率下げてっちゃうとtierを挙げる損がでちゃう」→ 1つに揃える案を承認)。
    - 値は、ナイフ t3 でちょうど弾が無い分を補う所(当たる割合は雑魚 0.6・ボス 0.4 で計算)。刀は Lv2 で補う所。
    - t1〜t2 では弾の銃より少し弱く、t4〜t5 では強い。段を上げれば印の上乗せも同じ割合で大きくなる=段上げの得はスキャンを持っていても減らない。
    - 面白い理由: 近接を育てた人ほどスキャンが光る。
    - 鞭は素のダメージが近接の 0.25 倍なので補いは足りないが、線で届く距離の強みがあるため、近接と同じ倍率にする。
  - **1振りで倍率が効くのは「一番近い印付きの1体」だけ**(刀の自動斬り・鞭の線も同じ)。周りの他の敵には通常のダメージ。
    - 面白い理由: 狙った1体に大きな数字が出る。群れを薙いでも数字が爆発しない。
  - 掛けない所:
    - カウンターの反撃(`postureImpact==='counter'`)
    - 打ち返した弾(`reflected`)
    - 紫の時間の報酬(`applyBrokenGunReward` / `applyBrokenMeleeFatal` が働く時)
    - 即死
  - 掛ける場所と順番:
    - `damageEnemy` では `gatedAmount` に掛ける(幻影の関門の後・紫の報酬と紅き夜の半減の前)。
    - プレイヤーの銃の弾は `directPlayerGun` で見分ける(タレットの榴弾・爆撃・スキル弾は 'gun' でもサブ扱い)。
    - `damageEnemy` を通らない近接の経路(ナイフの振り・分身・刀・鞭・スケボー)は、その経路で掛ける。
    - `damageEnemy` へ流れる近接(ワイヤー・フィニッシュの波及・追撃)は、呼び手が「印を使った」旗を渡して、二重に掛けない。
  - ダメージの数字は、倍率を掛けた後の値を出す。
- **カウンター**: 名目の `damage` は **9**(ハンドガン T2 の1発)。反撃は今と同じ強さで、印は掛からない。
- **ボスの体勢**: 撃たないぶん、銃の会心による削りが無くなる。代わりに、印付きのボスへの近接の当たりで、既存の 'melee' の削りを `impactMult` で 0.04→0.09 相当に増やす(別の呼び出しにしない=300ms の間引きで捨てられるため)。
- **近接の会心 +15%**: 印付きの雑魚だけ。色の補正の後・上限の前に足す。会心の気絶→近接で即死、の流れを残すため。
- **守護霊・幻影・ボット**: 3つとも、スキャンセンサーの代わりにハンドガン T2 で撃つ(既存の「手動専用の銃は代わりの銃で撃つ」前例どおり)。
- **持ち替えのコンボ**: 印を付けて強い銃へ持ち替えると、普通の腕で +15%、拍に合わせるうまい人で +33%。
  - 持ち替えるとリロードは取り消される(既存の仕様)。
  - 面白い理由: 拍を覚えるほど伸びるが、1挺を持ち続けるやり方も負けにならない。
- 見た目:
  - 扇は淡い青緑の走査線(派手さの絵。危険の色の赤・紫は使わない)。
  - 印は敵の足元の細い輪と頭上の小さな菱形。残りの時間は、輪が欠けていくことで見せる。
  - 印のある敵に当てたダメージの数字は、少し大きく色違いにする。

## 5. 共通
- 入手は既存の特殊銃と同じ(ドロップ・武器箱)。武器庫からは出ない。
- 負荷: 3つとも 1/10(塊弾は同時4個以下(間隔1.7秒・寿命4秒で実際は最大3個)、衛星弾は8個以下、スキャンは 1.2 秒に1回の扇の判定)。

## 6. 社長の決定(2026-10-18)
- 近接・刀・鞭の倍率は段に関係なく1つ(§4 の表)。この数字で3挺とも実装へ進む(「はい」)。
- 2026-10-18 監査の後の決定(社長「1かける 2のこす 3あとで考える 4たおす 5のこす 6だす 7つける」):
  1. 気絶中の強個体への一撃・盾のバッシュにも印の近接倍率を掛ける(1振り1体の枠を使う)。
  2. 衛星弾は持ち替えても回り続け、当たり続ける(増えない)。衛星弾を持っている時に止まった時だけ放つ。
  3. 入手方法は保留(開発施設の店に仮置き)。
  4. スキャンの扇は地面に倒す。絵と印の判定を同じ形で縦に潰す。
  5. 印の頭上の菱形は残す。
  6. 拍をキャラの足元にも出す(足元の弧が満ちて弾ける)。画面下の目盛りも残す。
  7. 衛星弾を放つ瞬間に専用の音(既存素材から)。

## 7. 受け入れ条件
1. 塊弾: ゆっくり進んで触れている敵に当たり続け、壁・ボスで止まり、最後は縮んで消える。
2. 衛星弾: 動くと溜まり、回っている間も触れた敵に当たり、止まると近い敵へ散って飛ぶ。
3. スキャンセンサー:
   - 拍に合わせて扇を出し、印を3秒付ける。
   - 印の倍率は §4 の表どおり。1振りで倍率が効くのは1体だけ。
   - カウンター・打ち返し・紫の報酬・即死には掛からない。カウンターの強さは今と同じ。
4. 3つとも、特殊銃の火力の約束を監査が数字で確かめる。
5. この3挺を持たない時、既存の銃・近接・サブの挙動は1bitも変わらない。
6. テストで固定する約束:
   - 近接・刀の倍率は段・Lv で変わらない(印付きの1振りのダメージは、段が上がるほど増える)。
   - 1振りで倍率が効くのは1体だけ。
   - 紫・カウンター・打ち返しには掛からない。
   - スキャンを持っている間、ストライカーの ×1.5 が付かない。
