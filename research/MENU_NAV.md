# メニュー操作の作り直し(キーボード・コントローラー)— 1回目

## 社長のゴール(社長の言葉)
- 「キーボード、コントローラーでのメニュー操作が最適化されてない。無理矢理対応してるだけって感じ。」
- 推薦「画面ごとの操作の地図」方式に「はい」(2026-10-10)。1回目=土台+よく通る画面。

## 「ではない」条件
- **スマホ(タッチ)の見た目・操作は1pxも変えない**(CLAUDE.md「PC版の作業はスマホを1pxも動かさない」)。カーソル・案内はキー/パッドを触った時だけ出る。
- 画面の作り直し(並べ方・文言の書き換え)はしない。宣言(属性)と、共通のカーソル・案内を足すだけ。
- キーの割り当て変更(リマップ)・マウスのホバー表現は対象外。
- ゲーム中(一時停止していない時)の操作は触らない。
- 2回目の画面(装備・開発施設・強化・資料室・守護霊・オプション・ショップ・レベルアップ・説明の窓)は今回は対象外=今の「近い所へ飛ぶ」のまま動けばよい。

## 現状(コードと実機相当で確認・v0.25.4962)
- `utils/menuNav.ts` が全画面に一律で「矢印の向きで画面上いちばん近い押せる物へ」を被せている。画面の並びを知らない。
- 画面に入っても何も選ばれない(最初の1押しは「選ぶだけ」)。タイトルで Enter を押しても始まらない(ヘッドレスで確認)。
- 押せる物の拾い方が DOM の `[tabindex]` 等なので、タイトル全体の枠・スクロール枠など押す物でない所に乗る(ヘッドレスで確認)。
- 選択の印は既定で 1px の枠。専用の見え方があるのは DS ホームの行・装備の一部・出撃ボタンだけ。
- 戻った時に前の選択を覚えていない。端で止まる。タブ切替・スクロール・値の調整・ボタン案内・移動音が無い。

## 仕様

### 1. 宣言(各画面が DOM に属性で書く)
| 属性 | 置き場所 | 意味 |
|---|---|---|
| `data-nav-screen="キー"` | 画面の一番外 | この画面の地図の名前。**前の選択を覚える単位**。 |
| `data-nav-group="名前"` + `data-nav-kind="list\|row\|grid"` (+`data-nav-cols`) | 並びの外枠 | 中の押せる物を**DOMの順**で並びとして扱う。list=上下、row=左右、grid=列数で折る。 |
| `data-nav-default` | 押せる物 | 画面に入った時に最初に選ぶ物(既存の属性を流用)。 |
| `data-nav-id="安定した名前"` | 押せる物(任意) | 覚える時の名前(無ければ並びの中の番号で覚える)。 |
| `data-nav-back` | 押せる物 | B/Esc で押す物(既存)。 |
| `data-nav-tabs` | タブの外枠 | LB/RB(キーは Q/E)で前後のタブを押す。 |
| `data-nav-scroll` | スクロール枠 | 右スティック/PageUp・PageDown でスクロール。押せる物が無い枠は上下キーでもスクロールする。 |
| `data-nav-skip` | 要素 | 押せても選択の対象から外す(大きな枠・装飾)。 |
- 宣言の無い画面は従来どおり(`pickNeighbor` の近い所へ飛ぶ)=壊れない。

### 2. 動き
1. **画面に入った瞬間に選択を置く**(キー/パッドを使っている時だけ): 覚えている物 → `data-nav-default` → 最初の並びの先頭。最初の決定(A/Enter)はそのまま押せる。
2. **並びの中**: list=上下、row=左右、grid=上下左右(列で折る)。**端では止まり、小さく「ぶつかる」**(カーソルが進む向きへ4pxはねて戻る+控えめな音。下の §4)。折り返しはしない(どこにいるか見失わない)。
3. **並びの外へ**: その向きに最も近い**別の並び**へ入る(入る位置=その並びで覚えている物、無ければ画面上で一番近い物)。並びの外にある単独の押せる物(例: 出撃ボタン)は1つの並びとして扱う。
4. **戻ってきた時**: 画面キーごとに最後に選んでいた物へ戻る(ラン中・セッション中だけ覚える。保存はしない)。
5. **タブ**: LB/RB・Q/E で `data-nav-tabs` の前後を押す(端では止まる)。
6. **スクロール**: 選んだ物が見えなくなる時は滑らかに見える所まで動かす(慣性 ease-out・200ms)。押せる物の無い長文(更新情報など)は上下でスクロール。
7. **値の調整**: `input[type=range]` を選んでいる時の左右は値を1段動かす(並びの移動にしない)。
8. マウス/タッチに触れたらカーソル・案内を隠す(既存の `kbnav` を外す動き)。

### 3. カーソル(見た目)
- 画面に1つだけの重ね絵 `NavCursor`(DOM・pointer-events:none)。選んだ物の外形に、**角の4つの鉤(L字)+ごく薄い面の明るさ**で乗る(DS ホームの琥珀色 `rgba(255,179,64,…)` と同じ色の家族)。
- 次の物へ**滑って移る**(位置と大きさを ease-out 140ms で補間=慣性MUST)。画面が替わった直後は滑らずにその場でふわっと出る(120ms)。
- 既存の専用の選択の見え方(DS ホームの行・出撃ボタン等)はそのまま出す(**消さない**)。カーソルはその上に重なる。1px の既定の枠は、カーソルが出ている間は出さない。
- 最終的な形・濃さはクリエイティブ監査で詰める。

### 4. 音
- 移動=`ui-move`(既存)。ぶつかる=`ui-deny` を小さく(音量0.35)。決定・戻るは各ボタンが今鳴らしている音のまま(二重に鳴らさない)。
- 押しっぱなしの連続移動は2つ目以降の移動音を間引く(80ms に1回まで)。

### 5. 案内(ボタンの表示)
- キー/パッドを使っている間だけ、画面右下に1行: 例「A 決定 B 戻る LB RB 切替」。その画面に無い操作は出さない(戻るが無い画面は B を出さない・タブが無い画面は LB/RB を出さない)。
- 表示は使っている機器に合わせる: パッド=A/B/LB/RB、キーボード=Enter/Esc/Q/E。
- 文字は既存の UI の書体・色(DS の小さいラベルと同じ家族)。最終的な形はクリエイティブ監査で詰める。

### 7. 実装の置き場所
- 純関数(テストする): `utils/navMap.ts`(並びの中の次の番号・端の判定・grid の折り・並びの外の行き先の選択・覚える/思い出すキーの作り方)。

- 各画面: 属性を足すだけ(並べ方・見た目は変えない)。

# v2 改訂(品質監査 A-1〜A-11・B・C/クリエイティブ監査20件を反映)— **上の §1〜§6 と食い違う所は、ここが正**

## 土台(品質監査 A-2/A-3/A-5/A-6)
- **入力の種類**: menuNav が最後のメニュー入力を覚える(`lastNavInput: 'key' | 'pad' | null`)。キーかパッドに触れた時だけ `html.kbnav` を付け、マウス/タッチで外す(既存)。案内の表記はこれで決める(B-2)。
- **画面に入ったことの検知**: menuNav が `document.body` を MutationObserver(childList+subtree・属性 `data-nav-screen`/`data-nav-modal`/`hidden`/`style`)で見張り、変化の後の次の rAF で「今の層」を計算する。React の各画面は**属性を書くだけ**(フックは要らない)。
- **層(モーダル)**: `data-nav-screen="キー"` は入れ子にしてよい。`data-nav-modal` を併記した物が出ている間は**それが今の層**(複数なら DOM で後ろ=手前の物)。無ければ見えている `data-nav-screen` のうち一番内側。**候補はその層の中だけ**(外は選ばない・押さない)。層が閉じたら下の層の記憶へ戻る。
- **選択を置く時機**: 層が替わったら、対象(記憶 → `data-nav-default` → 最初の並びの先頭)の**入りのアニメが終わるのを待って**置く(`el.getAnimations()` が全部終わるまで・最長400ms)(A-4)。キー/パッドを使っていない時は置かない=タッチでは何も起きない。
- **最初の1押し**: まだ kbnav でない時の最初のキー/パッドの入力は「kbnav に入って選択を置く」。それが決定(Enter/Space/A)なら**置いた物をそのまま押す**(タイトルが Enter 1回で始まる・A1)。
- **Enter/Space の経路(A-2)**: 選んでいる物(activeElement)が今の層の候補なら**ブラウザの標準動作に任せる**(menuNav は何もしない=二重に押さない)。候補でない時(body 等)だけ menuNav が `navActivate`。タイトルの枠は自分の keydown で始まる(既存)ので、その枠が選ばれている時は menuNav は Enter を拾わない。
- **候補の集め方(A-5)**: 宣言のある並びは**DOM の順で全部**(画面の外にある物も含む・`disabled`/`display:none`/`visibility:hidden`/`data-nav-skip` は除く)。可視判定は層の判定でだけ使う。宣言の無い所は従来の `candidates()`。
- **記憶**: menuNav のモジュール変数(画面キー → `data-nav-id` か並びの中の番号)。出撃で MissionSelect が消えても残る。保存はしない(C-4)。

## 並びの動き(A-7・A-11・C-1)
- **list/row**: DOM の順。**grid は幾何で動く**: 行=同じ高さに並ぶ物、上下=次の行で横位置が一番近い物、左右=同じ行の隣。列数の宣言は使わない(画面幅で列数が変わる・ロック枠が飛ぶ・A-7)。押せない枠(ロック)は行の計算には入れ、移動先には選ばない(その行に押せる物が無ければ次の行)。
- 並びの外への移動は幾何(左右の列も幾何で決まる=縦持ちで1列になってもそのまま動く・C-1)。
- **長文の窓(A-11)**: `data-nav-scroll` の枠が今の層にあって、押せる物がその外に1つしか無い時(更新情報)、**上下はスクロール**が勝つ(ぶつからない)。決定=その1つ。

## スクロール(A-10)
- 選んだ物を見せる時は、スクロール枠の見える範囲から**その枠の中の sticky/fixed の物が覆う帯を引いた残り**に入れる。先読み1行ぶんの余白を持って送る(クリエイティブ #12)。尺220ms・曲線 `cubic-bezier(.2,.7,.3,1)`。入れ子の枠は内側から順に。横スクロールの帯(キャラ選択)は横も同じ。
- 右スティック(標準配置の axes[2]/[3]のみ・非標準は使わない=B-1)/PageUp・PageDown で今の層の一番内側の `data-nav-scroll` をスクロール。

## 戻る(A-8・C-2)
- `data-nav-back` が今の層に複数ある時は**一番内側の層の物**を押す。対策室の詳細の「← ボス一覧」「一覧」に `data-nav-back` を付ける(詳細から B で一覧へ)。一時停止の「続ける」に `data-nav-back`(B=再開・案内に B が出る)。

## カーソルの見た目(クリエイティブ #1〜#4・#13・#19)
- **線だけ・面は持たない**。既存の語彙=**◆の目印+上辺のヘアライン**: 対象の外形の+3px外側、左端の中央に◆(5px)、上辺に1pxの琥珀ヘアライン(出撃の上辺と同じ「琥珀→透明」のグラデ・左から)。色は `#ffd28a`(既存の行の枠より明るく細い=別の層と読める)。
- 明るい面の上(`data-nav-cursor="dark"`・出撃ボタン)は `#12100a` に反転。
- スライダーを選んでいる時はつまみの幅へ縮み、値が動くたびつまみを追う。
- 既存の専用の選択の見え方(行の枠・出撃の hover)は**そのまま出す**。既定の 1px の枠(`:where(html.kbnav)` の outline)は、カーソルが出ている要素では出さない。

## 動き(クリエイティブ #5〜#11・#20)
- 曲線は家の署名 `cubic-bezier(.2,.7,.3,1)`。尺=隣へ90ms/2つ以上120ms/別の並びへ200ms(横断だけ 2〜3px 行き過ぎて戻る `cubic-bezier(.2,.8,.2,1.08)`)。位置が先、大きさは40ms遅れて追う。
- 層に入った時: 対象の入りのアニメが終わってから、1.04倍から締まって出る(140ms)。消える時: 不透明度100ms+1.02倍へ膨らんで消える。
- ぶつかり: 進む向きへ10px・50msで出て170msで戻る(非対称)。ぶつかった辺の◆/ヘアラインが一瞬1.5px潰れる。**1押しに1回**、押しっぱなしで端に着いたら1度だけ・離すまで黙る。
- 押しっぱなしの連続移動: 初回320ms・以後110ms(パッド・キーボードとも menuNav が間隔を決める。キーの OS リピートは間引く)。
- 案内はカーソルが着いてから120ms遅れて出る。
