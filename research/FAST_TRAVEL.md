# ファストトラベル(拠点のメニューのタブ)+解放済みの拠点の目印を残す

## 0. 社長の言葉(2026-10-13)
- 「拠点のメニューにタブを分けてファストトラベルの機能を追加したい。対象はショップが開けるようになったところすべて。」
- 「今って拠点が近づくと、もしくはそのエリアにいると、解放前の拠点はマップ表示されてるけど、解放されると表示されなくなるから、それを解放されても表示されるままにしておいてほしい。解放されてるかどうかは色分けかなんかで分かるようにしておいて。」

**ゴール(1行)**: ショップを開ける場所(武器商人・解放済みの拠点)どうしを、ショップの画面の別タブから一瞬で移動できる。画面の端の拠点の目印は、解放した後も色を変えて出し続ける。

## 1. 今(事実)
- ショップを開ける場所は3種類:
  ①武器商人(スタート付近・`weaponMerchant`・円に2秒居る=`MERCHANT_TALK_DWELL_MS`・`updateMerchantDwell`)
  ②解放済みの拠点の中央の「武器庫」の小さな円(`ARMORY_RADIUS`=50・指を離すと開く)
  ③研究所ステージだけの遠隔ショップ(`labArmory`・研究所では武器商人は出ない)。
- ショップの画面は `components/ShopMenu.tsx` の1枚(タブ無し)。ボス戦中・紅き夜の間は開かない(`facilitiesLocked` 等)。
- 画面の端の拠点の目印(琥珀の旗+矢印)は `pixiScene.ts` の `syncArrows` で、**未解放の拠点だけ**・画面の外・近く(画面上500px以内)の時に出る。解放すると出なくなる。
- 地面の拠点の円の色は、未解放=琥珀 `0xfbbf24`/解放済み=緑 `0x34d399`/安全な拠点=青。

## 2. 決め(叩き台)
### 2-1. タブ
- ショップの画面の上に**2つのタブ**: 「店」と「移動」。開いた時は「店」(今の中身はそのまま)。
- 「移動」タブは**行き先が1つ以上ある時だけ**出す(研究所は行き先が無い=タブを出さない)。
- PC/パッドのメニュー操作(`utils/menuNav`)のタブ切り替え(LB/RB 等)に乗せる。

### 2-2. 行き先
- 行き先=**ショップを開ける場所すべて**: 武器商人(ウェルカムが終わって姿を見せている時)+解放済みの拠点(東部/南部/西部/北部)。
- 並び: 武器商人 → 東 → 南 → 西 → 北。各行に**名前**(「武器商人」「東部拠点」…)と、**その拠点を守っている軍人の名**(拠点の行だけ)を添える。距離の数字は出さない。
- 今いる場所の行は「現在地」として押せない。
- **費用はかからない**(社長の言葉に費用の指定が無い。叩き台=無料)。

### 2-3. 移動の手順
- 行き先を押す → ショップを閉じる → **暗転して(約0.25秒)、行き先で明ける(約0.35秒)**。暗転の底でプレイヤーを行き先へ置く。
  - カメラは大きく離れると即座に寄せる仕組み(`CAMERA_SNAP_DIST`)が既にあるので、流れて見えない。
- 着く場所: 拠点=武器庫の円の**少し下**(円の外・拠点の円の中)/武器商人=商人の円の**少し下**(円の外)。着いた瞬間にショップがまた開かないようにする(閉じた直後の再オープン待ちも効く)。
  - 行ける帯(`clampRectToPlayableArea`)を通す。
- 着いた時の手応え: 足元に輪(着地の砂埃と同じ扱い=派手側)+短いSE(既存の素材から)。
- 移動中・移動直後に特別な無敵は付けない(暗転の間は一時停止のまま=敵は動かない)。
- **ついてくる軍人**: 置いていかれる(区域が変われば今の仕組みで拠点へ帰る=§ESCORT_FOLLOW の交代がそのまま働く)。

### 2-4. Y方向(上下)の移動の5つの副作用(CLAUDE.md の必須チェック)
- 北部拠点は原点の真上 4800px。**地平線フェード・帯の外の減光・遠近スケール・可視域・移動可能帯**は、どれも「歩いてそこへ行った時」と同じ状態になるだけ(拠点は元から歩いて行ける場所)。新しく起きることは無い。

### 2-5. 拠点の目印を残す
- 画面の端の拠点の目印を、**解放済みの拠点にも出す**(出る条件=画面の外・近く、は今のまま)。
- 色分け: 未解放=**琥珀**(今のまま)/解放済み=**緑 `0x34d399`**(地面の円と同じ色)。形(旗)は同じ、解放済みは旗の中を塗りつぶす(色だけに頼らない)。

## 3. 「ではない」
- ショップの品ぞろえ・値段・開く条件の作り直しではない。
- 地図画面(全体マップ)を新しく作るものではない(画面の端の目印の話)。
- 新しい画像・音の素材は作らない。

## 4. 負荷
**1/10**。移動は押した時の1回だけ。目印は拠点4つの判定が1つ増えるだけ。

## 5. テスト
- 行き先の一覧(武器商人+解放済みの拠点だけ・未解放は出ない・現在地は押せない・研究所は空)。
- 着く場所(武器庫の円・商人の円の外・拠点の円の中)。
- 移動したらショップが閉じ、すぐには開き直さない。

## 6. 受け入れ条件
1. 拠点(武器庫)で開いたショップにも、武器商人で開いたショップにも「移動」タブがある。研究所では出ない。
2. 「移動」タブには武器商人と解放済みの拠点だけが並び、今いる所は押せない。
3. 行き先を押すと、暗転して行き先に立っている。ショップはすぐには開き直さない。
4. 解放した拠点も、近くにいる時は画面の端に緑の旗で出る。未解放は琥珀のまま。
5. スマホの配置(phone-guard)は変わらない。

## 7. 着手前監査(FT-A1・品質+クリエイティブ合同)の反映=実装の現行(v0.25.5017)
- (A)①ショップを閉じると一時停止が解ける → 明け切るまで世界を止める(`hitstopUntil` = 着いてから `FAST_TRAVEL_REVEAL_MS`=0.6秒)。
  ②着く地点の障害物 → 行ける帯(`clampRectToPlayableArea`)+**木・施設・小物**(`resolveShieldWalls`=`resolveOutOfSolids` が木も見る)を通す。
  ③拠点の目印がパッと出る → 統一型の ease(`weaponSpawnEase`)で縁の外から滑り込みつつ濃くなる。
  ④安全な拠点(武器商人の居る拠点)は地面と同じく**青**。
- タブ: 「**補給**」「**輸送**」(軍の拠点網の言葉)。PC/パッドの LB/RB でも切り替わる(`data-nav-tabs`)。行き先が今いる所だけなら出さない。
- 行: 「東部拠点 ── エドガー」(守っている軍人の名)/今いる所は「ここ」(押せない)/襲われている拠点は「交戦中」を赤で出して**一覧の上へ**。
  武器商人が解放済みの拠点に居る時は、商人の行をその拠点の行にまとめる(「武器商人が居る」)。
- 手順: 押す → ショップの画面が速く暗転(0.2秒・ease-in)→ 底で行き先へ置く → 黒が長めに明ける(0.6秒)。足元に輪(拠点=緑/商人=琥珀)。
  拠点に着いたら、その拠点の軍人が迎えの一言(`FAST_TRAVEL_ARRIVE_LINES`・8人ぶん・通信の列の先頭)。着地の音(jump-land)は使わない(「落ちてきた」に読めるため)。
- 納品ロック中(`deliveryLocked`)は動かさない。
- 目印の形: 未解放=枠だけ(角だけ塗る)/解放済み=竿に旗が立つ。
- §6-5(phone-guard)は、ショップの画面が7画面に無いため**手撮りで見る**に読み替え(実際に 430×932 で撮って確認)。
- 社長判断(推薦どおり実装・変えるなら一言で戻せる): 費用=無料/襲われている拠点も行き先に残す(交戦中の印)。
- (B)積む: 区域の一跳び(0→2)で区域1の年表を飛ばし得る/遠くに置き去りの追跡敵が数に残る。

## 8. 納品時監査(FT-D1)の反映(v0.25.5018)
- (A)①商人が居ない出撃(練習・ボスメーカー・ストーリーボス専用等=半径0で世界の外へ退避)で「武器商人」の行が出て、押すと世界の端へ飛んだ → 半径0は不在扱い(テスト追加)。
  ②目印の消えが瞬断 → 最後に居た所で縁の外へ沈みながら消える(出と同じ統一型の ease の逆)。
  ③明けの黒が線形 → 最初の0.11秒は黒のまま、その後 ease-out で抜ける(flash に `curve: 'reveal'`)。
  ④武器商人の居る拠点で、商人の縁矢印と拠点の旗が重なった → その拠点の旗は出さない(商人の印が指す)。
- クリエイティブ: 輸送のタブでは見出しを「TRANSPORT / 輸送網」に、今いる所は一覧から外して見出しの下に「◯◯から」/帰還(撤収)は補給のタブだけ/
  行は2行目に「守備 ◯◯」(罫線をやめた)/未解放の印=旗の無い竿(解放で旗が立つ、と対)/着いた音=ヘリの着地(輸送の読み・薄く)/迎えの一言は表示中の行を差し替えて即出す。
- (B)積む: 目印が右の縁で武器の欄に乗る(既存の余白の問題)。
