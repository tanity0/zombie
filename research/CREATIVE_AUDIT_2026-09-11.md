# 第2回: UI/UX・タイポグラフィの「AI感」監査(2026-09-11・v0.25.4232時点・監査役=Fable)

社長の言葉: 「ゲーム内のフォント含めたUIUXがまだAI感ある。監査通して。ハードゲーム機に近づけるための対策を考えて。
例えば、フォントの問題ではないとしたら、ドロップシャドウとかテキストに枠線が無いからなのか、など」。
材料: 全画面17枚(タイトル/更新情報/作戦室/装備/強化/開発施設/守護霊/変異体対策室/資料室/オプション/作戦地域/任務詳細/HUD×3/一時停止)+ index.css / font.ts / GameHUD / MissionSelect / TitleScreen / PauseMenu / IntroDialogue / pixiScene の文字箇所 / changelog / tutorials。

## 結論(監査役)
**フォント(Orbitron)そのものは主因ではない。主因は「文字が絵になっていない(縁取り・影・焼き込みの不在)」と「均質」の2つで半分。**
縁取りを足すだけでは「縁取りの付いたSaaS画面」になる=③④も同時に要る。
