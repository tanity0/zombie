# 矢の雨(サブウェポン `arrow-rain`)

社長の言葉: 「**解放群を倒すと手に入る新ウェポン 矢の雨**」(2026-10-05)/「**エンドコンテンツなので10%くらい上振れでもいいよ の前提で進めて**」。
解放軍群(research/LIBERTY_HORDE.md)の旗手が敵として使う「矢の雨」を、倒した者が自分の武器として持てる。★未決 #2「旗手を倒した時の報酬」への答え。

## 1. 入手
- ストーリーの出撃(フリー周回を含む)で、**旗手(`mutant-liberty`)を初めて倒した時**に入手=**Lv1を持った状態**になる(開発施設で買う必要は無い)。トースト「矢の雨 入手」。
  - 既存の「ボスを倒すと設計図」の1か所(`triggerDramaticDeath` の `SUB_BOSS_UNLOCK`)に乗せる。設計図の台帳にも書く。Lv1の購入台帳(`purchasedSubLevels`)も、**初めての入手の時だけ・今が1未満の時だけ**1にする(監査 A-3: Lv3まで買った人が旗手を再撃破してもLvが下がらない)。
  - 練習ラン(ボスモード/ガントレット)・タイトルのボス戦テストでは入手しない(既存のガードどおり)。
  - 2回目以降の撃破では何も出ない。
- **Lv2・Lv3 は開発施設の棚**で他のサブウェポンと同じ値段・同じ形で解放する(=商人での出撃中の強化の上限が上がる)。
- 装備は他のサブウェポンと同じ(装備画面で1つ選ぶ)。

## 2. 効果
- **自動で撃つ**(操作なし)。間隔ごとに、プレイヤーの近く(足元から半径約420px・画面内の目安)で**敵が一番固まっている所**を的にして、矢の雨を降らせる。間隔は普通に進み、**明けても近くに敵がいなければ撃たずに待ち、敵が来た瞬間に撃つ**。
  - 的の候補から外すもの: 死体・昇天中の英雄・非終端の死神(照準の合流点と同じ)。
  - 刀モード中は止まる(他のサブウェポンと同じ)。帰還の円の中・スケボー中も撃たない。
- 1回の雨: 矢 N 本の**落ち始め**を約1.1秒の間にばらし、それぞれ0.42秒かけて落ちて刺さる。的の円(半径約110px)の中で、
  - 7割の矢は、雨が始まった瞬間に円の中にいた敵(ランダム)の足元を狙い、**その矢が落ち始めるまで敵の今の足元を追い直す**(監査 A-2: 1秒先には敵が動いている。狙った矢は当たる方が爽快)。
  - 3割は円の中のランダムな点。
  - 1本の矢は、刺さった点から**敵の体の矩形まで**24px以内の敵全員に当たる(監査 A-1: 中心距離で測ると背の高い敵に足元の矢が当たらない)。
  - 壁の判定は通さない(上から落ちるため)。ノックバックは無し。
- レベル(叩き台・社長の案どおり):

  | Lv | 本数 | 間隔 |
  |---|---|---|
  | 1 | 12 | 9秒 |
  | 2 | 18 | 8秒 |
  | 3 | 26 | 7秒 |

- **威力: 1本17**(スキルの与ダメ倍率は掛かる)。手榴弾(中心42・Lv1=1個/5秒、Lv2=2個、Lv3=3個)と比べ、敵が3体固まった場面の1秒あたりで **Lv1 約+13% / Lv2 約−4% / Lv3 約+5%**=社長の「1割くらい上振れ」の範囲。
- ボスにも普通に当たる(倒し切れる)。`damageEnemy(id, dmg)`=会心なし・体勢削りなし。
- **スローモーションを掛けない**(CLAUDE.md の禁則)。

## 3. 見せ方
- 矢の絵・落ち方は**旗手の矢の雨と同じ描き方を流用**(木の竿・赤茶の矢羽・鉄の鏃。上から加速して落ち、刺さった矢は少し残って薄れる)。
  - 落ちてくる向きは**プレイヤーの背後側から**(自分が射っている=援護射撃に見える)。
  - **赤い予告は出さない**: 赤=プレイヤーへの危険(色と形の文法)。自分の攻撃なので当たり判定の予告は要らない。
  - 地面の予告円は出さない。代わりに雨の始まりに、的の円の上へ**薄い金色の輪が一瞬**(派手さの絵=当たっても痛くないと分かる色)。
- 刺さった瞬間: 小さな砂埃(派手さの絵・大きめ)。当たった敵には既存の数字と被弾の白フラッシュ。
- 音: 雨の始まりに既存のクロスボウの発射音を2〜3回ずらして鳴らす(新しい音は社長の素材待ち)。
- 慣性MUST: 矢は上から加速して落ちる(等速にしない)。輪は広がりながら薄れる。

## 4. 「ではない」
- 守護霊(ゴースト)・幻影ボスは使わない(後の段)。
- 充電完了の通知(ブーメラン型)は付けない(自動で撃つため)。
- アイコンは既存の矢の絵(`fx/arrow`)を仮に使う。社長の素材が来たら差し替え。

## 4b. 監査
- 品質監査(Fable・着手前): (A)3件=当たりの幾何/狙いの時刻/再撃破でLvが下がる → 全て反映。(B)の置き場・候補の除外・間隔の文・damageEnemy の引数・壁/KB/刀・telemetry は反映。(B)進行リセットで設計図台帳が消えない件は既存の穴(金環も同じ)=別案件。

## 5. 負荷
2/10(シミュレーション・描画)。矢は1回の雨で最大26本・1.1秒だけ。描画は既存の矢の雨と同じ Graphics 1枚に描く。

## 6. 受け入れ条件
1. 旗手を初めて倒すと「矢の雨 入手」が出て、装備画面で選べる(Lv1)。練習ランでは出ない。
2. 装備して敵に近づくと、間隔ごとに矢が降り、刺さった点の近くの敵にダメージの数字が出る。
3. 敵がいない間は降らない。
4. 赤い予告は出ない。スローモーションは掛からない。
5. Lv2/Lv3 で本数が増え、間隔が縮む。
