## 位置づけ(狙い)
- 兵士が「パスを出す」=兵士と一緒に戦っている手触りを足す。受け取ったプレイヤーが近接で仕留める(=とどめの気持ちよさ)二人がかりの連係。
- 新しい強さの軸は作らない。既存の「会心→気絶→近接でとどめ」の流れの上に、**気絶した敵の置き場所をプレイヤーの目の前にする**だけを足す。

## 現状の事実(コードで確認)
- 兵士の会心は2経路ある。①銃の弾(`useGameLoop` の弾の命中処理・`weaponKey==='escort'`。会心で倒しきれなければ `stunEnemy`=5秒の気絶+黄色いリング) ②ナイフ(`gameStore.applyEscortMeleeHits`・会心率5%・同じ規則で気絶)。ボス級(`isBossType`)と使者(hangedman)は気絶させない。
- 気絶中の敵への近接は「とどめ」(`stunnedMeleeOutcome`: 雑魚=即死 / 強個体=3倍の重い一撃。紫の完全気絶中の強個体は即死)。**=「クリティカル中と同じ扱い」とはこの気絶のこと。**
- 気絶中の敵は接触でプレイヤーを傷つけない(`combatTick` の接触判定が気絶中を素通り)・弾も撃たない。
- 敵のノックバックは `knockbackVx/Vy` を `knockbackUntil` まで、残り時間に比例して減速しながら滑らせる(固定長 `KNOCKBACK_DURATION`=280ms で割っている=長さを変えられない)。壁は `resolveMove` が止める。画面外回収の境界の内側にクランプされる。ボス級は押されない(`canShoveEnemy`)。

## 仕様 v3(社長指示2026-10-13)
### 1. いつ起きるか
- **対象の敵=いま気絶中(会心で止まっている=`stunUntil`)の敵**。誰の会心で気絶したかは問わない(プレイヤーの会心・兵士の会心・カウンター・処刑の窓…全部)。※v2 の「兵士の会心の瞬間に飛ばす」は廃止。
- 型・状態の対象外は v2 と同じ(ボス級・使者・押されにくい型=パンプキン系、囲いの敵 `fromEvent`、リバティの取り巻き、跳び/突進の最中、死体、眠り)。
- 敵の中心からプレイヤーの中心まで **160〜640px**(近すぎると蹴る意味が無い/遠すぎると届かない)。
- 気絶の残りが **1.2秒以上**(兵士が寄って蹴るまでの間に気絶が切れないように)。
- **蹴る兵士**: その敵から **300px 以内**にいて、倒れていない・被弾の滑りの最中でない・瀕死の後ずさりでない・ナイフを振っている最中でない兵士のうち、**一番近い1人**。
- 同時に進む蹴りは**1件だけ**。前の蹴りの命中から **8秒**(ゲーム時間)空ける(v2 の間隔をそのまま引き継ぐ=頻発しすぎないため・社長は未指定=値は調整可)。
- プレイヤーが生きていて、会話・一時停止・アテンションの最中でないこと。
- 判定は純関数(utils/escortToss.ts)、割り当て・進行は store の1本(通常ルートと洋館通路ルートの両方が同じ関数を呼ぶ)。

### 2. 兵士の動き(寄る→蹴る)
- 割り当てられた兵士は、隊列・追従・巡回の移動より優先して、**敵の背中側(プレイヤーから見て敵の向こう)**の点へ走る: 点=敵の中心から「プレイヤー→敵」の向きへ (敵の半幅+26px)。速さは普段の前進の **1.6倍**、走り出しは 0→1 を 200ms で立ち上げる(慣性)。位置は `clampRectToPlayableArea` を通す。
- その点の 18px 以内に着いたら(または敵の体の縁まで 48px 以内)、**蹴り**: 溜め 160ms(足を引く=低い構えの絵)→ 命中(この瞬間に敵が滑り出す)→ 戻り 240ms。蹴りの間は動かず、銃もナイフも出さない。向きは敵→プレイヤーの方。
- 中止: 敵が死んだ/気絶が切れた/対象外になった/兵士が倒れた・滑った/割り当てから 2.5秒 経っても届かない。中止したら普段の動きへ戻る(戻りも慣性)。
- 兵士の体の絵: 蹴り専用の絵は無い(素材は既存のみ)。溜め=近接の振りの「低い構え」のコマ、命中〜戻り=同じコマのまま体を蹴る向きへ 10px 踏み込む(位置の動き・歪みは使わない)。※蹴りの絵(2コマ)を社長に支給してもらえば差し替える。

### 3. 敵の動き(滑り込み)
- 命中の瞬間に `Enemy.escortToss`(v2 と同じ欄・ゲーム時間)を張る: from=敵の今の位置、to=プレイヤーの中心から敵の方へ 72px の点を、プレイヤーの向いている側へ最大35°回した点(v2 と同じ `escortTossLanding`)。
- **地面を滑る**(社長「滑り込んでくる」): **浮かない**(v2 の放物線の浮き・着地のバウンドは廃止)。速さは ease-out(初速最大→止まる所で0)、時間 420ms。
- 気絶は既存のまま(延ばさない)=近接は既存のとどめ。飛行中の扱い(気絶が外れたらその場で止まる・死体で欄を消す・壁は resolveMove)は v2 と同じ。

### 4. 見た目・音(派手さの絵=判定なし)
- **蹴りの命中**: 「クリティカルと同じような目立つ音」=会心の音(`headshot`)を**減衰なしでフル**+重い打撃(`heavy-impact`)を重ねる。敵の体に大きな白い衝撃の放射(蹴った向きへ)+黄色い会心の輪をもう一度大きく(気絶の窓が続いていると伝える)。画面の揺れ=registerImpact(近接の床)。
- **滑っている間**: 足元から地面を削る砂埃の筋(既存の突進の速度線=砂の色・足元の高さ)+後ろへ尾を引く小さな砂埃。
- **止まった時**: 滑ってきた向きの後ろへ尾を引く低い砂埃(v2 と同じ3つ)+気絶の輪のポップ(v2 と同じ)+体の落ちる鈍い音は出さない(浮いていないため・止まる時は砂を擦る音=既存の着地音を小さく)。
- 既存のエフェクトは消さない。赤は使わない。

### 5. 対象外
- 守護霊・分身・幻影・ボットは蹴らない(進軍の兵士だけ)。判定(当たり判定・気絶時間・ダメージ・会心率)は変えない。

### 負荷
- 1/10: 同時1件・兵士1人の目標点の差し替えと、敵1体の位置更新。割り当ての探索は気絶中の敵×兵士(8人)だけ=毎フレーム数十回の距離計算。

### 受け入れ条件(v3)
- 気絶中の敵の300px以内に兵士がいると、兵士が敵の向こう側へ走って蹴り、敵がプレイヤーの斜め前(近接が届く所)まで地面を滑って止まる。浮かない。
- 蹴りの瞬間に会心と同じくらい目立つ音がする。
- 滑ってきた敵に触れても被弾せず、近接するととどめになる。
- 8秒以内に2回は起きない。同時に2人は蹴らない。対象外の敵は蹴らない。気絶が切れたら蹴りに行くのをやめる。
- 兵士の会心の瞬間に飛ぶ旧挙動(v2)は無くなる。

## 仕様(v2・着手前の品質監査 A-1〜A-13/B-1〜B-7・クリエイティブ監査 #1〜#17 を反映)

### 1. いつ起きるか(すべて満たした時)
- 兵士の**会心**(銃・ナイフどちらでも)で、敵が**倒れずに気絶した**瞬間(既存の気絶の分岐の中だけで判定する=気絶しない敵には起きない)。
- **判定は純関数1本** `escortTossDecision`(utils/escortToss.ts・テストつき)、**実行は store の1本** `tossEnemyToPlayer(enemyId)`。弾の経路(useGameLoop)とナイフの経路(applyEscortMeleeHits)の両方がこの2つを呼ぶ(写さない・品質 A-6)。
- 対象外: ボス級・使者(もともと気絶しない)、押されにくい型(`resistsChipKnockback`=ボス級の会心を持つ型とパンプキン系)、イベントの囲いの敵(`fromEvent`)、リバティの取り巻き(`isHordeFollower`=専用の制御が隊列へ引き戻す)、**跳び・突進の最中**(`aiPhase` が jump/charge=技を完遂するまで位置が動かない)、死体・眠っている個体。
- 距離: 敵の中心からプレイヤーの中心まで **160〜640px**。兵士は画面の外の敵も撃つので、**画面の外から飛んでくることがある(許容=飛んで来る筋と砂埃で読める)**。
- 間隔: 前のトスから **8秒**(ゲーム時間)。時計は store の `lastEscortTossAt`(`resetGame` で 0 に戻す)。
- プレイヤーが生きていて、会話・一時停止・アテンションの最中でないこと。

### 2. 動き
- **専用の欄で動かす**(ノックバックの欄は使わない=他のノックバックの距離を1bitも変えない・品質 A-3/A-4): `Enemy.escortToss = { fromX, fromY, toX, toY, startAt, endAt }`(ゲーム時間)。敵の更新では**死体の処理の直後・他のどの処理よりも前**に、この欄がある間は位置を `from→to` の **ease-out(1-(1-t)^2)** で決めて(壁は `resolveMove`)、AI・ノックバックを通さずに返す。ゲーム時間で進むので、ヒットストップやスローで止まっても**着地点は変わらない**(品質 A-11 を構造で解消)。
- 飛ぶ時間 `ESCORT_TOSS_MS` = **420ms**。
- **着地点(クリエイティブ #1)**: 真正面に一直線だと「突進してくる敵」に見えるので、プレイヤーの中心から敵の方へ 72px の点を、**プレイヤーの向いている側へ最大35°回した所**に置く(近接が届く範囲のまま・振れば当たる側)。
- 飛ばした瞬間に、その敵の既存のノックバック(`knockbackUntil`)は今で打ち切る。ナイフの経路は同じ振りの押し返し(`pushes`)からその敵を外す(品質 A-1)。
- 着地(ゲーム時間が `endAt` を過ぎた最初のフレーム)で `escortToss` を消して `escortTossLandedAt` を打つ。着地の演出はそこで1回だけ出す。飛行中に倒された(死体になった)場合は死体への変換で欄を消し、何も出さない。**飛行中に気絶が外れた**(強個体に近接が入って倒しきれなかった等)場合は、その場で着地扱いにして通常の処理へ戻す。
- 気絶は既存の5秒のまま(延ばさない)。
- Y方向の5点(地平線のα・帯の外の減光・遠近スケール・可視域・行ける帯): 着地点はプレイヤーのすぐ隣=5点とも構造上プレイヤーと同じ条件。念のため位置は `resolveMove`(壁)に通す(品質 A-10)。

### 3. 近接の扱い
- 吹き飛んだ敵は気絶中なので、近接は**既存のとどめ**(雑魚=即死・強個体=重い一撃)。新しい分岐は作らない。飛行中に当たっても同じ。

### 4. 見た目・音(派手さの絵=判定を持たない。大きめに)— 実装の実態(検収のクリエイティブ監査 A-1〜A-7 を反映済み)
- **飛ばした瞬間**: 黄色の会心の輪は既存のまま(黄はこれ1つ)。当たった体の**血・肉片が背中側(飛ぶ向きと逆)へ抜ける**スプレー(撃破の粒の黄と分ける)。音=鞭の破裂音(`whip-hit` を低く・会心の刺さり音とは重ねない=弾の経路は既に会心音を鳴らしている)。
- **飛んでいる間**: 敵の絵は回さない。**道のりの進みに合わせた放物線**で浮く(頂点 28px・頂点は道のりの真ん中=時間に掛けると終盤が真下へ漂った)。突進と同じ速度線を、**浮いた体の高さから空気の白で**後ろへ引く。
- **着地**: 滑ってきた向きの**後ろへ尾を引く低い砂埃**(3つ・足元中心の円にしない=ジャンプの着地と分ける)+1回の小さなバウンド(160ms・6px・減衰)+気絶の輪を一度大きく出して収縮(320ms)+地面側の衝撃の揺れ(`registerImpact`・近接の床の大きさ)。音=体の落ちる鈍い音(`heavy-impact` を低く)。
- 既存のエフェクト(会心の輪・ダメージ数字・血)は消さない。赤い予告は使わない(敵の攻撃ではない)。
- (社長へ提案中)着地の瞬間に兵士が一言。今回は入れない。

### 5. 対象外
- 守護霊・幻影・ボットの射撃/近接には付けない(進軍NPCだけ)。
- ゲームの判定(当たり判定・気絶時間・ダメージ・会心率)は変えない。

### 負荷
- 1/10: 8秒に1回まで・1体ぶんの位置更新と短いエフェクト数個。

## 受け入れ条件
- 兵士の会心で気絶した雑魚が、条件を満たすとプレイヤーの目の前(近接が届く所)まで減速しながら飛んできて止まる。
- 飛んでくる敵に触れても被弾しない。着地後に近接するととどめになる(雑魚は即死)。
- 8秒以内に2回は起きない。ボス級・パンプキン系・囲いの敵・使者・取り巻き・跳び/突進中の敵には起きない。
- ナイフの会心でも弾の会心でも同じように飛んでくる。
- トスの後、その敵が普通に押された時の飛距離は従来と同じ(ノックバックの欄を使わない)。
- スマホの画面の寸法で判定が変わらない(画面の大きさに依存する値を使わない)。

## 実装後の積み残し(検収監査 B・別案件)
- ナイフ経路の `pushes.delete` と弾経路の配線を通す store テストが無い(純関数と tossEnemyToPlayer 以降はテスト済み)。
- 飛行中の位置は「解析位置+`resolveMove`」なので、細い木の向こう側へ抜けることがある(死体の飛びと同じ既存の流儀)。
