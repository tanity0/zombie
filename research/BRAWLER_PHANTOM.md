## 0. ゴール(社長の言葉のまま)
「幻影のシステム使って一匹ボスを作りたいんだけど、こいつは格闘のスキルをゲットできるボスで、中身は、幻影を利用して、格闘のスキル、サブウェポンを持った、ユニークなプレイヤーにします。で、見た目の絵については後で準備するんで、一旦、適当なプレイヤーの絵を使って流用しといてください。で、この人は幻影のシステム使ってるんで、装備は適当な格闘に向いてるものを装備させといて、サブウェポンは格闘のみ。で、スキルは、なんか格闘に向いてそうなやつ、つけといてください。で、名前も後で考えるんで、一旦適当に名前つけといて。で、彼は、もしくは彼女は、ステージ1、3、4、5の中で、ランダム出現します。幻影として。」

### 0-1. 「ではない」条件
- 見た目の新しい絵は作らない(既存のプレイヤーの絵を流用・後で差し替え)。名前も仮でよい。
- UI の新規作成は最小限(既存の幻影の出方・HP表示・バナー・アテンション等をそのまま使う)。
- 格闘そのものの仕様(段・技・浮き・空中コンボ・秘奥義の値と流れ)は変えない。主題は「幻影がプレイヤーと同じ格闘を使う」ための AI と配線。
- バランスの最終値は実機で詰める(ここの数値は叩き台)。
- 汎用の幻影(`?phantomnow`・変異体対策室の「決闘」枠・中身が毎回ちがう人)の挙動は変えない。汎用の幻影を本編のどこに出すか(SAME_ARENA ★未決 Q6)はこの案件に含めない。

### 0-2. 判断の物差し(CLAUDE.md)
- 「より面白くなる方」を選ぶ。推薦には「なぜ面白いか」を1行添える。
- 技を足す案件なので **★★赤い予告の4つの掟** を技ごとに満たす(§4-3)。
  1. 赤い予告は必ず流星(`telegraphStyle.ts` の `meteorPhase` 1本)。
  2. 出る時刻 = 溜めが始まる時刻。
  3. 消え切る時刻 = 当たる時刻。多段は段ごとに別々の時刻。
  4. 通る技は当たり得る間ずっと赤が在る(走行中の体幅の赤帯は却下済みの見せ方=使わない)。
- 色の文法: 赤=カウンター/回避の対象(判定と厳密一致)/紫=カウンター不可/弾は全ボス共通の赤い二重丸(絵替え禁止)。
- 慣性 MUST・Y方向の5項目・ズーム引き(`ZOOM_MIN_ABS`=0.40)でも破綻しないこと。

## 1. 結論(先に)
- **方式**: 既存の幻影(`guardian-phantom`)の**1種**として作る。中身は「固定のユニーク人格」1人(格闘のビルドを焼いた記録)。新しい敵の型は作らない(§3)。
- **戦い方**: 幻影の頭脳(移動・間合い・弾への対処)はそのまま、**近接と銃の代わりに格闘の状態機械(`utils/brawler.ts` の純関数)を幻影の上で回す**。相手はプレイヤー1人。技はすべて**赤い流星**を付け、プレイヤーのカウンター(近接の窓・格闘の構え)で返せる(§4)。
- **出現**: ステージ1・3・4・5の出撃で、**1出撃に1回まで・25%・出撃60〜240秒の間**に「乱入」する(§6)。
- **報酬**: 初めて倒した時に**格闘の設計図+格闘Lv1をその場で所持**(矢の雨と同じ型)。以後、格闘は開発施設の棚で Lv2・3 を買える(§7)。

## 3. 方式の推薦: 「既存の幻影の1種」として作る

| 案 | 中身 | 良い所 | 悪い所 |
|---|---|---|---|
| **A(推薦)幻影の1種** | 型は `guardian-phantom` のまま。新しいデータ表 `src/data/uniquePhantoms.ts` に「格闘の人」1人を置き、スポーン時に `setPhantomIdentity` でその人を入れ、敵に印 `phantomUnique: 'brawler'` を立てる | 幻影の約100か所の配線(被弾の関所7系統・対人×0.2・被弾無敵・対人体勢・窓パリィ・HPバー・絵・アバター・ズーム・バナー・宿敵除外・守護霊5系統の除外)が**そのまま全部乗る**。幻影の改善が今後もこの個体に自動で効く。社長の言葉「幻影として」に字義どおり | 型で引く所(遭遇・出現・報酬・一覧の絵・対策室の枠)だけは印で分ける必要がある(§2-2 k〜m の5か所) |
| B 別の型(変異体のような `phantom-brawler`) | 新しい EnemyType を作る | 遭遇・報酬・一覧が型で自然に分かれる | 幻影の判定(`type === 'guardian-phantom'` 系)が **src の約100か所**(gameStore 27・useGameLoop 16・phantomTick 10・enemyUtils 9・pixiScene 9 ほか)にあり、全部に足すか述語を作り直す=取りこぼすと「この型だけ対人×0.2が掛からない」等が潜る |

**推薦=A。** 理由(面白さ): この相手は「自分と同じルールで格闘を使う人」であることが芯で、幻影の対等の規則(被弾無敵・対人体勢・カウンターの後出し勝ち)が1つでも欠けると「ただの強い敵」になる。A は全部が初日から揃い、プレイヤーが**この相手で覚えた読み合いが、そのまま自分の格闘の上達になる**。

### 3-1. A の部品
- **ユニーク人格の表** `src/data/uniquePhantoms.ts`(新・data の葉): `UNIQUE_PHANTOMS: Record<'brawler', PhantomIdentitySpec>`。中身は `fixedGuardians.ts` の `fixedGuardian()` と同じ形の `PlayerProfile`(`snapshot` 付き)。**固定20人(`FIXED_GUARDIANS`)には入れない**(入れると守護霊の抽選に混ざり、格闘を使えない守護霊として呼ばれてしまう)。
  - `fixedGuardian()` は職の固有サブ(`classSubWeaponFor`)を必ず足すので使わない。社長の言葉「サブウェポンは格闘のみ」に合わせ `subWeapons: ['brawler']` で直接組む。
- **敵の印** `Enemy.phantomUnique?: 'brawler'`(types/game.ts)。スポーンの1か所で立てる。
- **人格の出どころ** `PhantomIdentity.source` に `'unique'` を足す。
- **疑似プレイヤー** `resolveGhostBuild(snap, live, { keepBrawler: true })` の口を足し、`phantomActorPlayerById`(`gameStore.ts:5981-5995`)が印を見て渡す。これで疑似プレイヤーの `isMeleeOnlyMode` が真になり、プレイヤーと同じく銃が止まる。
- **格闘の状態** `Enemy.phantomBrawler?: BrawlerState`(プレイヤーの `player.brawler` と同じ型)。状態機械の純関数(`brawlerStartAttack`/`brawlerStartTech`/`brawlerDueEvent`/`brawlerFinish`/`brawlerApplyHitstop`/`brawlerSecretStep`…)を**そのまま**呼ぶ(書き写さない)。

## 4. 格闘 AI

### 4-1. 毎tickの流れ(`runPhantomTick` の中の分岐)
1. 今の関所はそのまま(紫・気絶・拘束・浮き・格闘の固まり→何もしない)。**ここで格闘の行動中なら `brawlerCancel`**(出かかった技は消え、予告も消える=「溜めを止めている間は予告の位相も止める」掟を、止めずに「取り消す」側で守る。カウンターで弾かれた時も同じ)。
2. 頭脳 `decidePhantom` は今どおり毎tick呼ぶ(移動・間合い・弾の対処の判断)。**`decision.action === 'shoot'` と周期の近接は使わない**。
3. 格闘の状態機械を1歩進める(当たりの時刻 `brawlerDueEvent` → 判定を解く → 終わり)。
4. 行動中でなければ、次の行動を **純関数 `decidePhantomBrawler`(新 `utils/phantomBrawlerAi.ts`)** で1つ選ぶ。
5. 移動: 行動中は動かない(格闘の硬直=プレイヤーと同じ)。詰め・跳び・飛び蹴り・掌底・ステップの移動は、加速→最大速度の形(`accelLungeFactor`)で毎tick量を出し、**`sweepResolve` → 今の `resolveMove`(障害物→`clampRectToPlayableArea` の順)** を通す(`phantomTick.ts:610-613`)。座標を自前で書く経路を作らない。

### 4-2. 行動の選び方(`decidePhantomBrawler`・叩き台)
入力: 状態・技ポイント・プレイヤーとの縁距離・プレイヤーが振り始めたか(`pendingSwingAt`)・プレイヤーの弾の着弾予測(`phantomLunge.bulletEtaMs`)・人格の癖・乱数・時刻。反応は**人の下限250ms**(`HUMAN_REACTION_MS`)を必ず通す(幻影の既存の掟)。

| 優先 | 条件 | 出す行動 | 備考 |
|---|---|---|---|
| 1 守り | 弾の対処の判断(v10 の弾ごとの1回の判断)が「返す」で、着弾が構えの尺の内・ポイント3以上 | **構え(↑)** | プレイヤーの構えと同じく弾は全部返る。ポイント不足なら「食らう」に落とす |
| 1 守り | 判断が「避ける」 | **ステップ**(100px・加速→減速・無敵なし=§12-3)を弾の横へ | 今の幻影の踏み込み弾避けの格闘版 |
| 1 守り | プレイヤーが間合いに入って振り始めた(反応の下限を過ぎた) | 人格の `counterChance` の確率で構え | プレイヤーの近接の前隙200ms<反応250msなので**見てからは間に合わない**=読みで張る(プレイヤーと同条件)。構えの後は3秒は構えない(亀にしない) |
| 2 秘奥義 | ポイント ≥ 秘奥義の合計(タイムキーパーLv3で8)・前の秘奥義から20秒・プレイヤーが蹴りの届く距離 | **→飛び蹴り→↓大踏み潰し→←気功→↑構え** を、前の技の終わりから400ms×テンポ以内に順に出す | 1手目の蹴りが当たらなければ打ち切る(BRAWLER §10-1 と同じ条件)。当たった技からは技→技の取り消しで繋ぐ |
| 3 攻め | 縁距離 ≤ 近接距離(74・`huntingMeleeRadius`) | **通常5段**(当たった時だけ次の段) | 2〜3段目が当たった時、ポイントがあれば確率で飛び蹴り/大踏み潰しへ取り消す(人格の `meleeBias` で割合) |
| 3 攻め | 74 < 縁距離 ≤ 220 | **飛び蹴り**(1ポイント) | ポイント0なら歩いて詰める |
| 3 攻め | 220 < 縁距離 ≤ 420・見通しあり | **気功**(2ポイント) | ポイント不足なら歩いて詰める |
| 4 間 | 上のどれでもない/連続が切れた直後 | 歩いて詰める(頭脳の移動) | 連続が切れてから次の連続まで 300〜700ms(叩き台)の間を置く=人の息継ぎ |

- 技ポイント: **通常攻撃がプレイヤーの体に触れた1発ごとに+1**(被弾無敵で0ダメージでも数える=§4-6)。上限は格闘Lv3=20。構えで受けたら全回復(プレイヤーと同じ)。
- スキルの効き: タイムキーパー=`brawlerTimeKeeperDiscount`・オーバークロック=`brawlerOverclockRefunds` を人格のスキルLvで呼ぶ(どちらも純関数=配線は1行ずつ)。

- 赤の判定一致: 円と帯の形は**判定と同じ純関数**(`brawlerDistTo`/`brawlerBandTargets` の式)から作る。テストで「赤の内側 ⇔ 当たる」を点の格子で確かめる(§9)。

### 4-4. プレイヤーはこの格闘をカウンターできるか
**できる。全部。** 赤=カウンター可の文法どおり。
- **近接の窓(ナイフ等)**: 当たる瞬間にプレイヤーの窓が開いていれば成立(今の幻影の近接と同じ判定 `isCounterActive`=`phantomTick.ts:833-836`)。成立したら今の `counteredByPlayer`(`:751-783`)と同じ扱い(幻影のダメージ0・幻影はノックバック・体勢0.20)に加え、**幻影の行動を `brawlerCancel`**。秘奥義の途中なら秘奥義ごと打ち切り(技ポイント0)。
- **格闘の構え**: プレイヤーの構えは窓(`counterWindowEnd`)を張るので上と同じ道を通る(`brawlerGuardCounterFx` で白金の受けの絵)。
- **気功の弾**: 共通の弾なので、プレイヤーの打ち返しで返せる。返った弾は今の幻影の弾と同じく幻影の関所を通る。
- **被弾反撃**(全員が持つ仕組み)も今どおり効く。

### 4-5. 幻影の構え(↑)
- 構えの間(1300ms)は、プレイヤーの近接・弾を全部受ける(`phantomGate` の窓を「構えの終わりまで」開け、弾は全部返す=プレイヤーの構えの「弾は全て弾き返す」の鏡。パリィのCDは構えの間は掛けない)。
- 受けた時の結果は今の幻影のパリィと同じ(プレイヤーは振り中断+敵と同じノックバック+体勢0.20)。**プレイヤーを気絶させない**(プレイヤーの気絶の仕組みは無い=作らない)。幻影の技ポイントは全回復(プレイヤーと同じ)。
- 絵: プレイヤーの構えの絵(しゃがみ・体の光・腕ガードの影)をそのまま幻影に描く。

### 4-6. プレイヤーは浮かされるか・ハメにならない制限
- **浮き**: 推薦=**見た目だけ浮く(操作は奪わない)**(★未決 #3)。3段目のアッパー・4段目の着地で当たった時、プレイヤーの絵を格闘の浮きの弧で上げて落とす(判定・移動・カメラは地面のまま=§18 の追いかけの浮きと同じ作り)。幻影も追いかけて浮く(§18 の見た目)。
  - 理由(面白さ): 「打ち上げられた」手応えと空中コンボ風の見せ場は残り、浮いている間もプレイヤーは窓を開けて**空中から返せる**。本当に浮かす(動けなくする)と操作を奪う=理不尽側に倒れる。
  - 幻影の空中コンボ: 相手(プレイヤー)が見た目で浮いている間に当てた段は、プレイヤーの空中コンボと同じ数え方(拾える回数の予算=ボス級4)で**絵と止めだけ**続ける。ダメージは下の被弾無敵に従う。
- **被弾無敵**: 推薦=**ダメージはプレイヤーの被弾無敵(1秒)を守る。段の進みと技ポイントは「体に触れた」で数える**(★未決 #4)。
  - これで5段が出し切られても実際に通るのは1秒に1発(今の全ての幻影の攻撃と同じ「被弾は互いに1秒1回」)。一方で段・技は最後まで出る=格闘の見た目はプレイヤーと同じになる。
  - 事実(判断材料): v9後の裁定で**プレイヤーの近接は幻影の被弾無敵を無視する**(「近接にCDがあるので」)。格闘はCDが無いので同じ理由は当たらない。
- **その他の制限**
  1. 秘奥義はプレイヤーを止めない(§17 の「画面内の敵を止める」は敵だけ=プレイヤーと守護霊は止めない)。秘奥義は20秒に1回まで(叩き台)。
  2. 構えの後3秒は構えない(受けると全回復するので、張り続けると亀になる)。
  3. 被弾の固まりの間もプレイヤーの近接と窓は止まらない(今の作り=`playerHurt.ts:130-136`)=食らった直後でも返せる。
  4. 紫(対人体勢)の致命は今の式のまま対称(プレイヤーが幻影へ格闘で致命を入れる時と同じ式)。紫1回につき1度だけ(今の `pvpAfterFatal`)。
  5. 幻影の行動はプレイヤーの格闘の固まり・浮きで止まる(ボス級の止めの予算=§13 のまま)。止まったら出かかった行動は取り消す(§4-1)。

### 9-2. テスト(ユニット・同じコミットで)

10. 仮名が固定20人と重ならない。
