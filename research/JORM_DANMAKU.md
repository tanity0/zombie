# ヨルムンガルドの弾幕技(導入の叩きつけ+弾幕2種)

社長指示(2026-10-02・原文):
> ヨルムンガルドに新技。シューティングゲームみたいな弾幕技。少し離れないと避け切れない、
> カウンター狙いでも全弾跳ね返そうとすると間に合わない弾幕で、世の中にある弾幕で評価の高い弾幕を再現したい。2種類いれて。
> この技の台本用の技(導入技): 自分の範囲を中心に叩きつけを2連続と、3連続の2種類。それぞれでどの弾幕が来るかが分かる設計。
> 実質この技が予兆となる。導入技のモーションは薙ぎ払いと同じやつ。弾幕は口を広げる方。
> 3連続の方の弾幕は、むしろ離れない方が安全な弾幕にしたい。

判断の物差し: **より面白くなる方**(CLAUDE.md・2026-10-02)。

## 1. 全体の流れ(台本)
| 台本 | 1手目(導入) | 2手目(弾幕) | 弾幕の性格 |
|---|---|---|---|
| `slam2` | 叩きつけ **2連** | `wave`=**波と粒の境界**(東方妖々夢・八雲紫「境符『波と粒の境界』」の翻案) | **離れるほど安全**(近いと壁、遠いと粒の隙間を抜けられる) |
| `slam3` | 叩きつけ **3連** | `rain`=**降り注ぐ星弓**(東方紅魔郷・フランドール「禁弾『スターボウブレイク』」の降り注ぎを見下ろし視点へ翻案) | **近いほど安全**(弾は本体から離れた所に降って外へ散る) |

- 2手目は必ずその弾幕(台本表 `bossChoreography` の固定2手)。弾幕は**単独では抽選されない**(重み0)。
- **予兆=叩きつけの数**。叩きつけの赤い枠は**導入の頭で全部同時に出る**(2連なら2つ・3連なら3つの入れ子の枠・段ごとに大きい)
  =出た瞬間に「2つ→離れろ」「3つ→戻れ」が読める。
- 叩きつけの枠は**体の矩形を広げた矩形**(体の外へ 90 / 170 / 250px)。蛇は横長(519×90)なので円にすると脇と先端で逃げる距離が5倍違う
  (設計監査 A-2)=体の形で広げて**どこに居ても同じ距離で抜けられる**(1段目は体のすぐ脇から 90px=1秒で足りる)。
- **3連の肝**: 最後の枠(体の外250)まで逃げた所で「近いほど安全」な弾幕が来る=降り注ぐ弾の中を体のそばへ戻る。
  2連は枠(170)の外へ逃げた所で「離れるほど安全」な弾幕が来る=さらに少し離れて隙間を抜ける。
  1段目をカウンターした人は導入がそこで終わり(既存の決まり)、**間(2秒)のあいだに**弾幕に合わせて動く(2連なら離れる・3連ならそのまま)。

## 2. 導入: 叩きつけ(`slam2` / `slam3`)
- 絵: 薙ぎ払いのシート(`jormungand-sweep`)。溜め=0→7(尾を振り上げ切る)/叩く瞬間=8→9/次の段への振り上げ直し=5→7/締め=10→12。
- 状態: `jslam-windup`(1段目の溜め)→ `jslam-hit`(各段の叩く瞬間・判定を積む)→ `jslam-rewind`(次の段への振り上げ)→ … → `jslam-recover`。
  **本体は導入・弾幕の間ずっと止まる**(設計監査 B-1)。ノックバックで止まっている間は段の時刻表・光弾の着弾も同じだけ繰り下げる(B-3)。
- 時刻(既定・テーブルで可変): 1段目の溜め **1000ms**、段の間隔 **650ms**(叩く 180ms+振り上げ 470ms)。
  命中時刻 = 開始 + 1000 + (k−1)×650(k=1,2,3)。
- 判定: 各段の命中時刻に**体の矩形を reach だけ広げた矩形**を1件だけ積む(うねりと同じ `pumpkinBlasts` の帯判定 `distToBandRect`
  =爆風パリィ・カウンターの切りも既存のまま)。赤い枠も同じ `jormSlamBand` を読む=判定と一致。ダメージ=本体の `damage`。
- 赤い予告(★★4つの掟):
  1. 流星: 新設 `drawSweepRectFill`(円の流星と同じ帯関数 `circleSweepBand` を矩形で描く=外の縁→体の縁へ流れる)。
     ※帯(`drawAngelZoneCapsule`)の窓は**帯の長さ方向**に流れる=「薙ぐ」読みになるので使わない(撮った画で判明)。
  2. 出る時刻=溜めの開始: **全段の枠が導入の開始時刻に出る**(段kの溜め=導入開始→その段の命中時刻)。
  3. 消え切る時刻=当たる時刻: 段kの枠は段kの命中の**同じフレーム**で消え切る(段ごとに別々の時刻)。
  4. 通る技ではない(1点で当たる)。
  - **枠は導入の州(jslam-windup/hit/rewind)の間だけ描く**: カウンターで切られたら州が chase へ戻る=残りの段の枠も同時に消える(設計監査 A-4)。
- 派手さの絵: 各段の命中で、円の縁まで届く砂埃のリング+地面の揺れ(既存の踏み鳴らしの砂埃・画面の揺れを流用)。
- カウンター: 既存の爆風パリィに乗る。成立したら既存の「1手を終える」(`counterCut`)で導入を打ち切り、**台本の残り(弾幕)は間を置いて続く**(v0.25.4592の規則のまま)。
- 抽選: 重み(近接/近/中/遠)= slam2 **15/20/20/10**・slam3 **15/20/20/10**。**全フェーズで出る**。
  CD: 弾幕が終わってから **18秒**(2種で共有=弾幕の連発を防ぐ)。

## 3. 弾幕A: 波と粒の境界(`wave`)
- 絵: 威嚇のシート(`jormungand-roar`)。溜め `jwave-open` 700ms=0→7、撃つ間 `jwave` は 8〜15 を往復、締め `jwave-recover` で 7→0。
  (州名に語尾 `-windup` を付けない=語尾ルールが「カウンターできる赤い帯」と誤読するため・設計監査 C-1)
- 発射点=**口**(本体中心から向いている側へ `mouth.dx`、上へ `mouth.dy`。向きは溜めの頭で相手の居る側に固定し、**弾幕の間は絵も振り向かない**)。
- 撃ち方(原典の作り=「発射角を二次関数で回す」):
  - 100msごとに **5方向**へ1発ずつ(`arms`)。腕kの角度 = θ0 + 2πk/5 + φ(t)、φ(t) = ω0·t + ½·α·t²(**時計回り**・§6.28-7の「螺旋は時計回りで固定」に揃える)。
  - 既定: ω0 = **1.6** rad/s、α = **0.15** rad/s²(ω: 1.6→2.2)、撃つ時間 **4000ms**(=40回・200発)、弾速 **160**、**弾の寿命 5500ms**(=880px届く)。
  - θ0 = 溜めの頭で相手へ向けた角 + π/5(**相手は腕と腕の間から始まる**)。
- **なぜ「離れるほど安全」になるか(原典と同じ性質)**: 同じ腕の連続した2発は、発射の間に角が ω·0.1 だけ回っている。
  半径rでの粒の横の間隔 ≈ r·ω·0.1。抜けるには 自機28+弾16 = **44px** に余裕を足した間隔が要る。
  - 設計監査 A-1 の是正: 旧案(ω0=0.5・α=0.6・寿命4秒)は「序盤は全距離が壁/後半はどこでも抜けられる/560pxより外は無風」=
    **距離ではなく時間で決まる弾幕**になっていた。回転を最初から速く・加速は小さく・寿命を延ばして、**撃っている間ずっと**
    「口から150pxは壁(<44)・400pxは抜けられる(>55)」が成り立つようにした(テストで固定)。境目は口から約300px=「少し離れる」。
  - 近くの壁は r·ω ≈ 240〜330px/s で掃く=走って追い越せない(自機≈100px/s)=近くに居たら当たる。
- カウンター: 弾は全部ふつうの赤い二重丸(打ち返せる)。1秒に60発が流れてくるので、窓と近接の間隔では**全部は返せない**(社長指示の条件)。

## 4. 弾幕B: 降り注ぐ星弓(`rain`)
- 絵: 威嚇のシート。溜め `jrain-open` 700ms、撃つ間 `jrain` は 8〜15 を往復、締め `jrain-recover`。
- 撃ち方(原典の作り=「上へ打ち上げた弾が弧を描いて降ってくる」を見下ろしへ):
  - 口から光弾を **80msごとに1つ**打ち上げる(撃つ時間 **3600ms**=45個)。
  - 各光弾は **1000ms** かけて弧を描き、**体の矩形から 200〜560px** の帯のどこか(一様)へ落ちる。行ける帯の外には落とさない(クランプ)。
  - **打ち上げた瞬間の相手の位置から120px以内には落とさない**(設計監査 A-3: 足元に予告ゼロで弾が湧かない。落ちるまで1秒の影が出る)。
  - 落ちた瞬間、その場から**体の矩形から遠ざかる向き**(最寄り点→落下点)へ **5発**(外向き±50°に等間隔)を弾速 **115** で撒く。
  - 飛んでいる光弾と地面の影は**判定なし**(派手さの絵)。**赤い予告は付けない**(落ちた所自体は痛くない=「赤いのに当たらない」を作らない)。
    光弾は白〜淡い紫、影は白い縁取り(赤ではない)。
- **なぜ「近いほど安全」になるか**: 弾は体から200pxの外で生まれ、体から遠ざかる向きにしか飛ばない
  =**体から200pxの内側には1発も入らない**(凸な矩形からの距離は、離れる向きへ進む限り増え続ける=テストで固定)。
  安全なのは**体のまわり200pxの帯**(体そのものは接触で痛い)。3連の最後の枠(体の外250)から逃げた位置は降り注ぐ帯の真ん中
  =**外向きに飛んでくる弾の中を体のそばへ戻る**のが正解。
- カウンター: 落ちた所から撒かれる弾は打ち返せる(赤い二重丸)。降ってくる数が多いので全部は返せない。

## 6. 受け入れ条件
1. 2連の導入は枠が2つ・3連は3つ、**導入の開始と同時に**出て、各枠は**その段の命中と同じフレームで消え切る**(設計監査 C-3)。カウンターで切られたら残りの枠も消える。
2. 2連のあとは必ず `wave`、3連のあとは必ず `rain`。弾幕は単独で抽選されない。
3. `wave`: 本体の口から 5方向・100msごと・角は時計回りに加速して回る。最初は相手が腕の間に居る。
4. `rain`: 体から200px以内には弾が**生まれない・入らない**(外向きのみ)。相手の足元(打ち上げ時点から120px)には落ちない。
5. 叩きつけの枠は体の外へ40px以上届き、段ごとに大きくなる(テストで固定)。
6. 叩きつけのカウンターは既存どおり(1手を終える・台本は続く)。
7. 弾は全部ふつうのボス弾の見た目(赤い二重丸)。紫は使わない。
8. 負荷: 同時に飛んでいる弾は最大でおよそ200発(wave=5方向×10回/秒×寿命5.5秒・撃つのは4秒)。描画は既存の弾のプール。
9. 時間の実効値(設計監査 C-2): 導入の締めは後続があるので **300ms** に切られる(`choreographyRecoverMs`)。
   3連→星弓の猶予は 締め300+口を開く700 = 1.0秒、最初の着弾はさらに+1.0秒。

## 7. 未決(社長に確かめていない・叩き台で入れて実機で決める)
- ダメージ: 弾はボス弾の既定(20)、叩きつけは本体の `damage`(38)。弾幕で3発もらうと体力の半分近く。
- 出る頻度: 全フェーズで出る・弾幕の後18秒は出ない。

## 10. 弾幕C(HPが減ってから解禁): 叩きつけ1連 → 凍てつく牙(社長指示2026-10-02)
社長の言葉:「HPが減ってきた時に解禁される技で、1連叩きつけの後に発動。先の2つよりも難しい、楽しいやつで。」

### 10-1. 何を再現するか
**東方紅魔郷 十六夜咲夜「メイド秘技『殺人ドール』」**(評価の高い「止まって、狙い直して、飛んでくる」型)を、氷の海蛇へ翻案。
原典の肝は**ナイフが自機のまわりで止まる**こと。だからこの技も**牙は相手のまわりで凍る**: 相手を囲む輪の上に霜が結晶し、
牙が現れて凍りつき、一拍おいて**時計回りに順番に**相手めがけて飛ぶ。凍る=この蛇の氷の体色と同じ文脈。

### 10-2. 流れ(台本 `slam1 → freeze`)
- 解禁: **HP60%以下(フェーズ2)**だけ抽選に乗る(導入の段数=1つの枠=「凍てつく牙が来る」の予兆。2連/3連と同じ文法)。
- 導入 `slam1`: 叩きつけ1段(届き=1段目と同じ90)。絵・判定・赤い枠・カウンターは2連/3連と同じ部品。
- 弾幕 `jfreeze-open`(口を開く 600ms)→ `jfreeze` → `jfreeze-recover`。
- 1回(=輪)の流れ。**輪の中心=放った瞬間の相手の位置**(ヘイトの相手=守護霊を狙っている時は守護霊):
  1. **結晶(formMs 350)**: 半径170の霜の輪が外から締まり、20か所に六花が時計回りに開く。**ここは絵だけ(当たらない)**=牙がどこに来るかを先に見せる。
  2. **凍る(holdMs 450)**: 六花の位置に牙(赤い二重丸)が現れ、速さ0で止まる。**止まっていても触れれば当たる**(=輪から出る時は隙間を通る)。
     出る瞬間に相手の真上(30px以内)の枠は飛ばす(予告の無い所で当てない)。
  3. **飛ぶ**: 最初の牙=口の側から**時計回りに順番に**(1周 sweepMs 300)、**偶数番は相手の今の位置、奇数番は相手の動きから読んだ先**へ向き直り、
     accMs 300 で速さ320へ加速(慣性)。飛ぶ直前の150msは殻が軋んで明るむ(次に飛ぶ牙が読める)。
  - 輪は **1200msごとに3回**(回ごとに半発ずつ角をずらす)。2回目以降は**その時の相手の位置**を中心に作り直す=逃げた先にまた輪ができる。
- なぜ難しくて楽しいか(先の2つとの違い):
  - 弾幕A/Bは「立ち位置」で解く(A=離れる / B=寄る)。**Cは立ち位置で解けない**=輪が相手に付いてくる。
  - 解き方=**今の位置狙いと読み狙いが交互に来るのを、止まる→動くの切り替えで外す**(歩き続けると読み狙いに、止まり続けると今狙いに当たる)。
    ※輪の外へ歩いて出る解き方は**無い**(検収監査 A-1: 凍っている800〜1085msで歩けるのは約84px<半径170)。隙間の幾何は抜けられる幅だが、時間が足りない。
    移動系のサブ(刀の縮地・ダッシュ等)を持っていれば輪の外へ出られる=装備で開く別解。輪の外に出ても20本全部が自分を狙う(片側から来るだけ)。
  - 順番に飛ぶので牙が**ほぼ一筋に連なって来る**=上手いカウンターがまとめて返せる見せ場。ただし3つの輪が時間差で重なる=全部は返せない。
- 弾: 全部ふつうの赤い二重丸(掟)。カウンター可(凍った牙を打ち返しても止まったままにならない=反射の基準速度の下限を弾が持つ)。

### 10-3. 数字(叩き台・テーブル `freeze`)
open 600 / rings 3 / ringGap 1200 / count 20 / radius 170 / formMs 350 / holdMs 450 / sweepMs 300 / accMs 300 / speed 320 / spread 0.04rad / lifeMs 6000 / recover 1300。

### 10-4. 受け入れ条件
- 輪の隙間 2π·radius/count − 弾16 > 自機28(テストで固定)=凍った輪から歩いて出る道が必ずある。
- 結晶の間は弾が存在しない(当たらない)。弾が出るのは formMs 後・六花の位置ちょうど。相手の真上の枠には出ない。
- 凍った牙は速さ0。飛び出しは時計回りに i/count·sweepMs ずつ遅れ、速さは speed·(経過/accMs)² で上がる(テストで固定)。
- 奇数番は相手の速度×届くまでの時間ぶん先を狙う(テストで固定)。守護霊を狙っている時は読み無し(守護霊の速度は持たない)。
- 凍った牙をカウンターすると、反射弾は speed×反射倍率で飛ぶ(止まったままにならない)。
- 弾幕の州を抜けたら飛んでいない牙が砕けて消える/本体が倒れたら止まっている牙が消える。飛び出した牙は(ノックバックで時計がずれても)減速しない。
- 掟: 赤い予告の掟は導入の叩きつけ(既存部品)だけが持つ。弾幕は弾=赤い二重丸の文法(新しい赤い予告は足さない)。

### 10-6. 着手前監査(Fable 5.1)を受けて作り直したこと
初版(口から輪を放って260pxで止める)は、①輪の外を歩くだけで全弾外れる ②口の近くが予告なしの壁 ③凍った弾を打ち返すと止まったまま残る
④本体が倒れると凍った弾が残る、の指摘(いずれも(A))。原典どおり**輪を相手のまわりに作る**形へ作り直し、③は反射の基準速度の下限、④は本体の生死で消す。
(B)記録: 狙いはヘイトの相手を通す(対応済み)。

### 10-7. 検収監査(Fable 5.1)・クリエイティブ監査(Fable 5.1)を受けて直したこと(v0.25.4767)
- 検収 (A)3: A-1 輪の外へ歩いて出る解き方は時間的に無い → 文言(設計書・更新情報)を実態へ / A-2 ノックバック停止で時計をずらすと飛んでいる牙が空中で止まった →
  飛び出した牙は減速させない(描画も殻を描き直さない)/ A-3 州を抜けた時に放すと、崩した直後に全弾が自分へ来る → 飛んでいない牙は砕けて消える(推薦(a))。
- 検収 (B) 記録: B-1 隙間テストは弦の長さだけ(実物は自機の判定箱18.7pxのAABB=対角で余裕3px)。B-2 は A-3 で消滅。
- クリエイティブ 15件: 殻を弾の外側だけに(弾の上を塗らない=紫に沈まない)/ 霜の輪は牙が現れてから薄れて消える / 相手の真上で飛ばした枠は結晶が砕ける /
  軋みは次に飛ぶ数本だけ / 周期の瞬きをやめて枠ごとの濃淡 / 刺は放射の向き / 破片は片ごとに違う / 輪は切れ切れの弧で口の側から濃く / 口から輪へ冷気の筋 /
  飛び出した牙に冷気の尾 / 輪を吐くたびに頭ごと沈む吐息 / 音は輪ごとに1回(輪が進むほど高く・乱数なし)/ 凍てつく牙だけ口の光を白く絞って息の筋。
  州を抜けた時の放しの慣性(#2)は、A-3 で「砕けて消える」になったので不要に。
