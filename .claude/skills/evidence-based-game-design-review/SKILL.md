# 正本の引き方(the ONE / zombie)

**判断・監査・提案の型は `CLAUDE.md` が正本。ここでは複製しない。**
このSkillは**「どの文書を読むか」だけ**を扱う。

## 手順

1. **現在の会話で足りるなら読まない。** 既に出ている正本の記述・コード断片で答える。
2. 足りない時だけ `references/source-map.md` を開き、**どのファイルの何を読むか**を先に決める。
3. **原則1分岐**(1〜2本)に絞る。大きい文書は全読みせず、該当節・★未決事項・先頭数エントリだけ。
   - 例外: **原因不明のバグ診断**は横断してよい(浅い1本読みで結論を出さない)。
4. 読んだら、**出典(ファイル名・節)を添えて**答える。文書に無いことは「未確認」と書く。
   コードに書いてあることは、発火条件まで追って初めて「実装済み」と書く。

## 画像を扱う時(既存素材の禁則)

差し替え・生成・加工を提案/実施する時、**指示が無い限り元素材と同じに保つ**:
**部位 / 個数 / ポーズ / 構図 / 縮尺**。
変える必要があるならそれは仕様変更なので、先に確認を取る(`CLAUDE.md` の仕様変更ルール)。
